# 3Dサウナ試験実装の進捗

2026-09-23更新。フェーズ1〜4の試験実装とフェーズ5の回帰・継続利用・全周画像検証を進行中。**計画全体、各フェーズの完了条件を満たした状態ではない。**

## 試す

```sh
bun install --frozen-lockfile
bun run dev
```

`/sauna-simulator/?view=3d` を開いて入室する。または「3Dを試す」を押す。
初期選択は2D。設定は保存され、`?view=2d` で明示的に戻せる。
サウナ・水風呂・外気浴の全ステージで3Dを表示し、同一モデルを保持したまま着席視点を切り替える。
背景をドラッグ／スワイプ、または背景にフォーカスして矢印キーで見回す。
UI非表示中も右上の復帰ボタン、左上のモード切り替えを利用できる。

## 実装済み

- Three.js 0.186.0を直接ラップする方式を採用。React側は設定・ロード状態だけを持つ。専用チャンクを遅延ロードし、描画ループは共有React状態を変更しない。
- 元のサウナ・中庭形状、画像木目・石・布をGLBへ変換。ガラスを簡易透過へ変更。元シーンを保存せず、書き出し前後で入力SHA-256が一致することを検証。
- 材質別の結合、細かな庭要素の省略、モディファイア／ポリゴン削減、画像1024px化。GLBは17,322,516 bytes。形状293,638三角形／71メッシュ（実描画数とは異なる）。
- 着席視点、水平・制限付き上下回転、Pointer Events・矢印キー、リサイズ、ユーザーの動きを減らす設定に応じた蒸気移動の抑制。
- サウナの着席、水面付近、リクライニングの体験用視点を `scripts/web_scene.py` に集約。水面の波紋・注水をブラウザ側に実装し、元の水形状との二重描画を回避。
- `pendingStage` と単一の1秒タイマーへ遷移を統合。UI・2D背景・3D背景を同時に暗転し、ステージ・音・視点を同じ期限で変更。二重押下による時間・回数の上書きを防止。
- ロウリュ操作から一度だけ音と通知を発生。ロード前・2D中・前のステージのイベントは保持せず、過去の蒸気を再生しない。
- 読み込み中の2D継続、モデル／チャンク失敗・30秒タイムアウト・WebGL初期化失敗・コンテキスト喪失時のフォールバック。アンマウント時にfetch中断、ループ・イベント・ResizeObserver・GPUリソースを解放。
- 素材クレジット、Git除外、入力・出力ハッシュと変換条件の記録。
- CIへ型検査・テスト・ESLintを追加。ESLintはTS/TSXも検査。既存の型不備を修正し、古いCopilot規約は正本への参照に置換。

## 書き出しを再実行する

元データは公開リポジトリに同梱しない。プロジェクト所有者からSUI元データ一式を受け取り、`blender/scene/SUI_Retreat.blend` と `blender/assets/textures/CREDITS.md` を配置する。正規ダウンロードURLは現時点でない。画像はblendへパック済みであることを前提とする。
入力の識別子は [export-report.json](../public/models/export-report.json) のファイル名・更新日時・SHA-256を照合する。異なるハッシュの入力は別バージョンとして扱う。

```sh
/Applications/Blender.app/Contents/MacOS/Blender \
  -b blender/scene/SUI_Retreat.blend \
  --python-exit-code 1 --python scripts/export_web_glb.py
cp blender/assets/textures/CREDITS.md public/models/CREDITS.md
bun run build
```

Blender 4.5.11 LTSで実行。別OSではBlender実行ファイルだけ置き換える。
スクリプトは自身の場所からリポジトリを解決する。元のblendを上書きしない。
`public/models/sauna.glb`、`sauna.scene.json`、`export-report.json`を生成する。
座標はBlender `(x,y,z)` → glTF `(x,z,-y)`、単位メートル。
圧縮設定はスクリプト末尾にまとめてあり、Dracoは未適用。
元シーン内に複数シーンがあるため `use_active_scene=True` は外さない。

材質はベイクしていない。木目／法線画像と簡略化PBRへ置換し、苔・シダ・石・デッキの色を明示補正した。地面の苔・シダの座標ノイズの色調ランプだけは設定を記録し、ブラウザで再現する（「庭の地面の模様」参照）。その他の色調ランプ、濡れ、体積蒸気、間接照明は再現していない。省略したオブジェクトと手直し対象のプロシージャルノード数も出力記録に含む。
