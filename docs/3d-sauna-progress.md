# 3Dサウナ試験実装の進捗

2026-10-28更新。3ステージの3D表示は試験版として利用できるが、既定は2Dのまま。**計画（[3d-sauna-plan.md](3d-sauna-plan.md)）の各フェーズの完了条件を満たした状態ではない。** 日付ごとの作業・検証の記録は [作業記録](3d-sauna-log.md) に移した。

## 現在の状態

- **表示**：サウナ・水風呂・外気浴の3ステージを同じモデル・描画ループのまま視点だけ切り替える。季節（春夏秋冬）・時間帯（自動／昼／夕暮れ／夜）・天気（晴れ／雨／雪）を設定から選べる。庭の木々（別GLB）、低木・草花・せせらぎ・灯籠・蝶、遠景の林と山並みを含む。画質は標準で、動的解像度が画素比を下げる。サウナは下段ベンチの中央寄りへ着座位置を移し、ストーブまで水平約2.46m（以前約4.35m）。入室時は各視点を少し下へ向け、主役（ストーブ・水面）を操作パネルの上に出す（比較用は `?camera=review`）。描画・材質・照明の詳細は [src/components/3d/CLAUDE.md](../src/components/3d/CLAUDE.md)。
- **照明**：照度・反射プローブは夏の昼夕夜を焼き込み、春・秋・冬は中庭・外周の2グリッドを各季節の元シーンの近似から焼き直して配信（選んだときに取得。室内・水中はBlenderで測ったRGBエネルギー比を掛ける近似）。室内照明は床・背面壁・上下段ベンチ・左壁・天井下面を対象に、昼の室内照明およびベンチの蹴込み（側面・裏面）・遮光リップ・背もたれ・板溝（4mm）・右側ガラス際まで局所直接光・遮蔽を補正し、Cycles参照とのコントラスト差を解消（[記録](3d-qa/room-surfaces/README.md)）。日光・月の影はPCSS（夕夜の日光は4＋6標本）、影の半解像度マスク、深度プリパス、見回し中の時間方向の蓄積（TAA）を使う。
- **葉・細い縁の明滅**：TAAの履歴制限幅を1.0→1.25へ小さく広げた。Chromeの固定フレーム・比較用視点のABBAで、面残差は標準DPR1.5で約2.7〜5.2%、高画質DPR2で約2.4〜4.9%低減。静止画の前後差0、停止後の画像・復帰など7対象回帰が成功。知覚的なちらつき・残像や実機の合格ではない（[記録](3d-qa/temporal-variance/README.md)）。
- **林のカードの葉の房**：中景の樹冠が大きな平たい多角形（夜は角の欠けた長方形の影絵）に見えていた。原因はカードの長方形が遠景の埋め・ぼかしで塗りつぶされることだったため、マスクの20枚の葉を中央と輪の5つの房にまとめ、縁の波打つ葉の房の塊にした。見回しの面の残差は0.85〜0.93倍（別ビルドの比較）。夜・高画質・描画費用・実機は未確認（[記録](3d-qa/leaf-card-sprigs/README.md)）。
- **林の樹冠の色**：昼の樹冠が空の映り込みで青灰色に見えていたため、林のカードの反射プローブの映り込みを昼だけ0.25倍にした（色相約145°→100°前後の黄緑）。夕夜は従来どおり。昼の制御見回しの残差は1.02〜1.08倍に増えた（暗い緑と空の明暗差）。描画間隔は不変（[記録](3d-qa/crown-specular/README.md)）。
- **奥の森**：帯（54m）の手前の樹冠を、Blenderで焼いた密な葉の樹冠の板（インポスタ、広葉樹5・常緑樹3、`public/models/forest-impostors.webp` 約0.29MB）に置き換えた（2026-10-27）。楕円体の葉群の綿の玉の重なりが、上の明るい葉の塊の広葉樹と尖った常緑樹の並びになった。焼いた法線に固定の日光を当て、季節・時間帯・霞は従来どおり。静止画・夜・秋冬で確認、見回し中のちらつき・高画質・実機は未確認（[記録](3d-qa/forest-impostors/README.md)）。
- **水風呂**：水面の平面反射、側面の全反射の鏡像、水底の部分反射、水面に映る寝椅子灯の像と真上のV7の帯の像（Cyclesでは輪郭が鋭いが、ぼかした光のにじみにした、[記録](3d-qa/lounge-glow/README.md)・[V7](3d-qa/water-strip-glow/README.md)）、疑似コースティクス（夕・夜・曇天では弱める、[記録](3d-qa/caustic-light/README.md)）、波の傾きによる水越しの像の揺らぎ、注水口の樋から放物線で落ちる水膜と着水点の泡・水滴（`waterSpout.ts`）。
- **ロウリュの湯気**：点群の湯気（6秒）に加え、室内に残って約30秒で薄れる湯気（最終パスで深度から視線の室内区間に掛ける）と、ストーブ上の熱のゆらぎ（画像の読み出し位置を揺らす）を足した。2026-10-27に湯気を室内6灯の一回散乱で照らし（閉じた式、ノイズなし）、夕夜は琥珀色、灯の方向ほど明るい湯気にした（湯気のある間の描画間隔1.02〜1.03倍）。体積の描画ではなく、日光の筋・影はない。旧版とのABBAで描画間隔は0.99〜1.01倍（表示間隔の量子化の範囲）、夕夜の白飛び・見回し後の深度の境目のにじみはない。見回しの最中・GPU単体・実機は未確認（[記録](3d-qa/steam-haze/README.md)）。
- **サウナの小物**：ストーブを金属帯・厚みのある石かごと大小の割石へ、桶を内壁・底・下がった半透明の水面を持つ18枚板の木桶へ、柄杓をくぼみ付きの木製の匙へ更新。書き出し時だけ元の76部品を置換し、元blend・カメラ・蒸気／音源位置は維持。48枚の静止画ABBA、3ステージ×昼夜の負荷比較、14対象回帰、全周216枚の撮影が成功（[記録と目視範囲](3d-qa/loyly-props/README.md)）。
- **手前の植生**：シダの葉の両側を反らせて法線を更新し、既存の緑を少し暗くした。草は丈・先端の明るさ・枯れ色を抑え、密度を小さなまとまりにした（21,138→15,009枚）。標準DPR1の前後ABBAで92枚を撮影し、同方式の再撮影差は0〜1画素。連続見回しや実機の評価ではない（[記録](3d-qa/ground-foliage/README.md)）。

- **実環境**：モバイル実機（タッチ・発熱・性能）、Windows、遅い端末、非HDRの実機、実Safariでの継続的な確認。Firefoxは起動障害で未確認（[記録](3d-qa/firefox-launch-20261010/README.md)）。音の実聴（空間音響を含む）。
- **性能**：GPU単体時間・GPUの実確保量・実機のFPSは未計測（フレーム間隔の比での比較のみ）。室内照明の拡張（2,928三角形）によりベンチ・左壁の反復描画間隔は変更前HEAD比で約1.02〜1.07倍。
- **読み込み**：0.8 Mbpsでも準備完了するようになった（約37秒）が、庭の木々が届くまでは約1分15秒かかり、読み込み中の進み具合（割合）は出していない。本体GLBのテクスチャ（JPEG 0.94MB）はWebPへの再圧縮では縮まず、形状の段階的な読み込みは未着手（[記録](3d-qa/network-loading-20261026/README.md)）。遅延3Dチャンクの850kB警告も継続。
- **初回のシェーダー準備**：分割温め（`?warmup=split`）は試験オプションのままで、既定は従来どおり。
- **画質**：奥の森（光は焼いた法線と曇天の明るさからの近似で、樹冠の間の影はない、[記録](3d-qa/forest-impostors/README.md)。冬の常緑樹の間の帯の境目は2026-10-28に周りの樹冠の色へ寄せて解消、[記録](3d-qa/graphic-followup-20261028/README.md)）、林の樹冠の輪郭が空を背に葉の粒の集まりに見えること（遠いカードの埋めと、昼だけ外殻の葉を空を透かした明るさへ寄せる近似で縁の点は和らぎ、昼の見回しの残差は0.93〜0.96倍。夕夜の縁の点は影絵として残す、[記録](3d-qa/crown-rim/README.md)）、葉・細い縁の見回し中のちらつき（2026-10-21の確認で直近の変更による悪化はなく、残りは林の樹冠に集中。見回し中だけのずらしは制御撮影で増えたため不採用、[記録](3d-qa/motion-jitter/README.md)。知覚的な合否は未確認。2026-10-26の切り分けでは残りは樹冠の内側の1画素の粒で、影の寄与は小さく、TAAの制限幅2.0で面の残差0.94倍だが、2026-10-27の時刻をそろえた撮影で水面の残像が1.14〜1.28倍に増えたため不採用、[記録](3d-qa/crown-shimmer-20261026/README.md)・[残像](3d-qa/taa-ghosting/README.md)。制限幅を広げる方向は打ち切り。2026-10-27に遠景のカードのアルファをぼけたミップから読むようにし、面の残差0.91〜0.99倍、[記録](3d-qa/leaf-alpha-bias/README.md)。同日の切り分けで、木ごとの色味・陰は粒に効かず、ぼかしを手前へ広げても1〜3%しか減らない。残りはカードの形そのもの、[記録](3d-qa/crown-grain/README.md)）、水の反射像の形・部分遮蔽の差が残る（2026-10-26の見直しでは水底の斑の形は変えず、窓ガラスに映らなかった寝椅子灯・V9を足した、[記録](3d-qa/glass-lights/README.md)。2026-10-28に鏡像を縦に平均し、縁石の像で切れた寝椅子灯の三角形を柔らかいにじみにした。Cyclesの鋭い映り込みとの差はその分広がる、[記録](3d-qa/graphic-followup-20261028/README.md)）。
- **回帰の範囲**：2026-10-26に通常回帰の全件（80件成功）・全周撮影の四季と雨雪・高画質の全周（4回で全画素一致）を実行した（[記録](3d-qa/regression-20261026/README.md)）。見回し中・実時間の連続視聴・継続利用・GPU時間は含まない。

## 試す

```sh
bun install --frozen-lockfile
bun run dev
```

`/sauna-simulator/?view=3d` を開いて入室する。または右上の「設定」で「3Dを試す」を押す。初期選択は2D。選択は保存され、`?view=2d` で明示的に戻せる。背景をドラッグ／スワイプ、または背景にフォーカスして矢印キーで見回す。UI非表示中も右上の表示復帰・音・設定の操作は残る。計測用に `?quality=<low|standard|high>` で画質を指定できる。

## 書き出しを再実行する

元データは公開リポジトリに同梱しない。プロジェクト所有者からSUI元データ一式を受け取り、`blender/scene/SUI_Retreat.blend` と `blender/assets/textures/CREDITS.md` を配置する。正規ダウンロードURLは現時点でない。画像はblendへパック済みであることを前提とする。
入力の識別子は [export-report.json](3d-export/export-report.json) のファイル名・更新日時・SHA-256を照合する。異なるハッシュの入力は別バージョンとして扱う。

```sh
bun install
/Applications/Blender.app/Contents/MacOS/Blender \
  -b blender/scene/SUI_Retreat.blend \
  --python-exit-code 1 --python scripts/export_web_glb.py
cp blender/assets/textures/CREDITS.md public/models/CREDITS.md
bun run build
```

Blender 4.5.11 LTSで実行。別OSではBlender実行ファイルだけ置き換える。
スクリプトは自身の場所からリポジトリを解決する。元のblendを上書きしない。
比較用の別出力先は `SUI_WEB_EXPORT_DIR=/tmp/sui-web-export` のように指定できる（既定は `public/models/`。別出力先の指定時はレポートも同じ場所に出力する）。
配信物の `public/models/sauna.glb`・`sauna.scene.json` と、配信しない記録の `docs/3d-export/export-report.json`・`compression-report.json` を生成する。Node.jsもPATH上に必要。
座標はBlender `(x,y,z)` → glTF `(x,z,-y)`、単位メートル。
書き出し末尾で `scripts/compress_web_glb.mjs` を呼び、`KHR_meshopt_compression`（bitstream v1）で圧縮する。位置・法線・UVは許容誤差（0.1mm・0.1°・1/8192）内の最小ビット数のEXPONENTIALフィルター、インデックス・色・画像は復号一致を検査する（[記録](3d-qa/glb-filter/README.md)）。その後、本体法線を8bit octへ変換する（ローカル許容1.5°、[検証と採用記録](3d-qa/body-attributes/README.md)）。庭も8bit oct。Draco・位置やUVの整数化は未適用。
元シーン内に複数シーンがあるため `use_active_scene=True` は外さない。

材質はベイクしていない。木目／法線画像と簡略化PBRへ置換し、苔・シダ・石・デッキの色を明示補正した。地面の苔・シダの座標ノイズの色調ランプだけは設定を記録し、ブラウザで再現する（「庭の地面の模様」参照）。その他の色調ランプ、濡れ、体積蒸気、間接照明は書き出しでは再現していない（雨の濡れは `rainWetness.ts`、ロウリュ後の室内の湯気と熱のゆらぎは `steamHaze.ts`・`heatShimmer.ts` がブラウザ側の近似で描く）。省略したオブジェクトと手直し対象のプロシージャルノード数も出力記録に含む。
