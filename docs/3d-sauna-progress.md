# 3Dサウナ試験実装の進捗

2026-10-21更新。3ステージの3D表示は試験版として利用できるが、既定は2Dのまま。**計画（[3d-sauna-plan.md](3d-sauna-plan.md)）の各フェーズの完了条件を満たした状態ではない。** 日付ごとの作業・検証の記録は [作業記録](3d-sauna-log.md) に移した。

## 現在の状態

- **表示**：サウナ・水風呂・外気浴の3ステージを同じモデル・描画ループのまま視点だけ切り替える。季節（春夏秋冬）・時間帯（自動／昼／夕暮れ／夜）・天気（晴れ／雨／雪）を設定から選べる。庭の木々（別GLB）、低木・草花・せせらぎ・灯籠・蝶、遠景の林と山並みを含む。画質は標準で、動的解像度が画素比を下げる。サウナは下段ベンチの中央寄りへ着座位置を移し、ストーブまで水平約2.46m（以前約4.35m）。入室時は各視点を少し下へ向け、主役（ストーブ・水面）を操作パネルの上に出す（比較用は `?camera=review`）。描画・材質・照明の詳細は [src/components/3d/CLAUDE.md](../src/components/3d/CLAUDE.md)。
- **照明**：照度・反射プローブは夏の昼夕夜を焼き込み、他の季節はBlenderで測ったRGBエネルギー比を掛ける近似。室内照明は床・背面壁・上下段ベンチ・左壁・天井下面を対象に、昼の室内照明およびベンチの蹴込み（側面・裏面）・遮光リップ・背もたれ・板溝（4mm）・右側ガラス際まで局所直接光・遮蔽を補正し、Cycles参照とのコントラスト差を解消（[記録](3d-qa/room-surfaces/README.md)）。日光・月の影はPCSS（夕夜の日光は4＋6標本）、影の半解像度マスク、深度プリパス、見回し中の時間方向の蓄積（TAA）を使う。
- **葉・細い縁の明滅**：TAAの履歴制限幅を1.0→1.25へ小さく広げた。Chromeの固定フレーム・比較用視点のABBAで、面残差は標準DPR1.5で約2.7〜5.2%、高画質DPR2で約2.4〜4.9%低減。静止画の前後差0、停止後の画像・復帰など7対象回帰が成功。知覚的なちらつき・残像や実機の合格ではない（[記録](3d-qa/temporal-variance/README.md)）。
- **奥の森**：平面の帯が露出していた18か所に小さな立体樹冠を補い、局所的な肩の陰影と重なりを増やした（+2,592三角形、描画回数は同じ）。水平3方位・昼夕夜と秋冬の昼の静止画ABBA、実旧ビルドとの制御見回し／負荷比較、13対象回帰が成功。変化は控えめで、帯全体の平面感は残る（[記録](3d-qa/forest-back-crowns/README.md)）。
- **水風呂**：水面の平面反射、側面の全反射の鏡像、水底の部分反射、水面に映る寝椅子灯の像と真上のV7の帯の像（Cyclesでは輪郭が鋭いが、ぼかした光のにじみにした、[記録](3d-qa/lounge-glow/README.md)・[V7](3d-qa/water-strip-glow/README.md)）、疑似コースティクス（夕・夜・曇天では弱める、[記録](3d-qa/caustic-light/README.md)）、波の傾きによる水越しの像の揺らぎ、注水口の樋から放物線で落ちる水膜と着水点の泡・水滴（`waterSpout.ts`）。
- **サウナの小物**：ストーブを金属帯・厚みのある石かごと大小の割石へ、桶を内壁・底・下がった半透明の水面を持つ18枚板の木桶へ、柄杓をくぼみ付きの木製の匙へ更新。書き出し時だけ元の76部品を置換し、元blend・カメラ・蒸気／音源位置は維持。48枚の静止画ABBA、3ステージ×昼夜の負荷比較、14対象回帰、全周216枚の撮影が成功（[記録と目視範囲](3d-qa/loyly-props/README.md)）。
- **手前の植生**：シダの葉の両側を反らせて法線を更新し、既存の緑を少し暗くした。草は丈・先端の明るさ・枯れ色を抑え、密度を小さなまとまりにした（21,138→15,009枚）。標準DPR1の前後ABBAで92枚を撮影し、同方式の再撮影差は0〜1画素。連続見回しや実機の評価ではない（[記録](3d-qa/ground-foliage/README.md)）。
- **頭上の葉**：同じ大きさの菱形が並んでいた葉を、読み込み時に大きさ・向き・縦横比の違う卵形の葉へ置き換えた。水風呂・外気浴の頭上の960枚（1,920→15,360三角形）、建物の奥の庭の77,760枚（軽い6頂点の形、155,520→311,040三角形）、林のカードのマスク（テクスチャのみ）。既定視点のフレーム間隔は+1〜3%、背後の見上げで最大+11%（外気浴の夜7.8→8.7ms）。見上げ・背後26視点の前後ABBAで再撮影差0〜1画素。見回し中のちらつき・実機は未確認（[記録](3d-qa/canopy-leaves/README.md)）。
- **庭のモミジ**：正面のモミジ3体の5裂の葉（2,112枚）がすべて水平で、目の高さから細い横線の集まりに見えていたため、読み込み時に1枚ずつ約20〜63°傾けた。三角形・描画数は不変。静止画ABBAで再撮影差0。見回し中・実機は未確認（[記録](3d-qa/maple-leaf-tilt/README.md)）。
- **空気遠近**：照度プローブを使う屋外の面と遠い森を、カメラから20m以遠で距離に応じて山並みと同じ空気の色へ寄せる。林の樹冠の青黒い粒が奥へ退き、林・奥の森・山並みの重なりが分かれた。静止画ABBAで再撮影差0。GPU時間・見回し中・実機は未確認（[記録](3d-qa/forest-air/README.md)）。
- **雨の映り込み・サウナの床**：雨の間はデッキ上面の高さに低解像度の鏡像を描き、濡れたデッキ・石にぼけた像（夕夜は灯りの縦の映り込み）を、所々の水たまりに鋭い像と雨粒の波紋を映す。飛び石上面と室内はテクスチャユニットの上限で対象外。サウナの床に板目と溝、ストーブ・桶の足元に接地の陰を付けた。静止中の雨の費用は1.00〜1.02倍。見回し中の鏡像の費用・実機は未確認（[記録](3d-qa/wet-deck/README.md)）。
- **水風呂の水深・林の樹冠**：水越しの視線に元にない吸収と散乱を足し、タイルに1枚ごとのむら・釉だまり・壁際の陰を付け、疑似コースティクスの表示を0.6倍にした（プール感を抑える）。遠い林のカードは被覆の閾値を下げて葉の塊として描く。静止視点の費用は0.97〜1.006倍。見回し中のちらつき・実機は未確認（[記録](3d-qa/plunge-woodland/README.md)）。
- **失敗時**：モデル・チャンクの取得失敗、30秒の読み込み期限、WebGLコンテキスト喪失、シェーダーのリンク失敗では3Dを解放して2Dで続ける（[src/components/CLAUDE.md](../src/components/CLAUDE.md)）。
- **配信量**：本体GLB 2.50MB、庭GLB 5.98MB（meshopt圧縮・法線8bit）、プローブ等 約1.8MB。2D入口のJS 230.92kB（gzip 73.80kB）、遅延3Dチャンク 911.33kB（gzip 252.50kB、850kBの警告が出る）。
- **検証の仕組み**：通常回帰・継続利用・静止画・回線制限・GPUの各Playwright設定（[e2e/CLAUDE.md](../e2e/CLAUDE.md)）、Cyclesとの同視点比較、全周216枚の撮影と集計スクリプト。QA記録は [3d-qa/](3d-qa/)。直近の室内照明は437単体テスト、48枚の前後ABBA比較、Cycles参照9組でのΔE改善が成功（[範囲と制限](3d-qa/room-surfaces/README.md)）。

## 未完了事項

各回の作業記録で「未確認」として繰り返し残っているものをまとめた。

- **実環境**：モバイル実機（タッチ・発熱・性能）、Windows、遅い端末、非HDRの実機、実Safariでの継続的な確認。Firefoxは起動障害で未確認（[記録](3d-qa/firefox-launch-20261010/README.md)）。音の実聴（空間音響を含む）。
- **性能**：GPU単体時間・GPUの実確保量・実機のFPSは未計測（フレーム間隔の比での比較のみ）。室内照明の拡張（2,928三角形）によりベンチ・左壁の反復描画間隔は変更前HEAD比で約1.02〜1.07倍。
- **読み込み**：約4.7Mbps未満の回線では30秒の期限に間に合わず2Dに戻る。GLBの分割・段階的な読み込み・容量削減は未着手（[記録](3d-qa/network-loading/README.md)）。遅延3Dチャンクの850kB警告も継続。
- **初回のシェーダー準備**：分割温め（`?warmup=split`）は試験オプションのままで、既定は従来どおり。
- **画質**：季節ごとの方向性・遮蔽の再ベイクは未実施（夏のデータに比を掛ける近似）。奥の森の帯の平面感（18樹冠の局所補正・空気遠近の後も残る）、林の樹冠の輪郭が空を背に葉の粒の集まりに見えること（遠いカードの埋めを強めて塊に近づき、見回し中のちらつきも0.79〜0.93倍になったが、樹冠の縁の葉の点は残る、[記録](3d-qa/crown-fill-far/README.md)）、葉・細い縁の見回し中のちらつき（2026-10-21の確認で直近の変更による悪化はなく、残りは林の樹冠に集中。見回し中だけのずらしは制御撮影で増えたため不採用、[記録](3d-qa/motion-jitter/README.md)。知覚的な合否は未確認）、水の反射像の形・部分遮蔽の差が残る。
- **回帰の範囲**：最近の作業では対象を絞ったブラウザ回帰のみを実行している。通常ブラウザ回帰の全件、高画質と他の季節・天気の全周、実時間の連続視聴をまとめて再実行する必要がある。

## 試す

```sh
bun install --frozen-lockfile
bun run dev
```

`/sauna-simulator/?view=3d` を開いて入室する。または右上の「設定」で「3Dを試す」を押す。初期選択は2D。選択は保存され、`?view=2d` で明示的に戻せる。背景をドラッグ／スワイプ、または背景にフォーカスして矢印キーで見回す。UI非表示中も右上の表示復帰・音・設定の操作は残る。計測用に `?quality=<low|standard|high>` で画質を指定できる。

## 書き出しを再実行する

元データは公開リポジトリに同梱しない。プロジェクト所有者からSUI元データ一式を受け取り、`blender/scene/SUI_Retreat.blend` と `blender/assets/textures/CREDITS.md` を配置する。正規ダウンロードURLは現時点でない。画像はblendへパック済みであることを前提とする。
入力の識別子は [export-report.json](3d-export/export-report.json) のファイル名・更新日時・SHA-256を照合する。異なるハッシュの入力は別バージョンとして扱う。

```sh
bun install
/Applications/Blender.app/Contents/MacOS/Blender \
  -b blender/scene/SUI_Retreat.blend \
  --python-exit-code 1 --python scripts/export_web_glb.py
cp blender/assets/textures/CREDITS.md public/models/CREDITS.md
bun run build
```

Blender 4.5.11 LTSで実行。別OSではBlender実行ファイルだけ置き換える。
スクリプトは自身の場所からリポジトリを解決する。元のblendを上書きしない。
比較用の別出力先は `SUI_WEB_EXPORT_DIR=/tmp/sui-web-export` のように指定できる（既定は `public/models/`。別出力先の指定時はレポートも同じ場所に出力する）。
配信物の `public/models/sauna.glb`・`sauna.scene.json` と、配信しない記録の `docs/3d-export/export-report.json`・`compression-report.json` を生成する。Node.jsもPATH上に必要。
座標はBlender `(x,y,z)` → glTF `(x,z,-y)`、単位メートル。
書き出し末尾で `scripts/compress_web_glb.mjs` を呼び、`KHR_meshopt_compression`（bitstream v1）で圧縮する。位置・法線・UVは許容誤差（0.1mm・0.1°・1/8192）内の最小ビット数のEXPONENTIALフィルター、インデックス・色・画像は復号一致を検査する（[記録](3d-qa/glb-filter/README.md)）。その後、本体法線を8bit octへ変換する（ローカル許容1.5°、[検証と採用記録](3d-qa/body-attributes/README.md)）。庭も8bit oct。Draco・位置やUVの整数化は未適用。
元シーン内に複数シーンがあるため `use_active_scene=True` は外さない。

材質はベイクしていない。木目／法線画像と簡略化PBRへ置換し、苔・シダ・石・デッキの色を明示補正した。地面の苔・シダの座標ノイズの色調ランプだけは設定を記録し、ブラウザで再現する（「庭の地面の模様」参照）。その他の色調ランプ、濡れ、体積蒸気、間接照明は再現していない。省略したオブジェクトと手直し対象のプロシージャルノード数も出力記録に含む。
