# 平らな水の層でタイル光沢を切り分ける（2026-09-30）

[水なしの較正](../water-gloss-calibration/README.md)に続き、光源側・視線側の屈折とCyclesのクランプ／光沢フィルタを切り分ける。製品コード・配信物は変更しない。

## 条件と測定

`scripts/diagnose_water_gloss_slab.py` が元blendを読み、独立シーンにコピーした寝椅子灯（42W・2m円盤）、高さ0.202mの黒いタイル、下面0.215m・上面0.765mの平らな水の層を置く。元blendは保存せず、前後のSHA-256一致を検査する。

- Blender 4.5.11 LTS / Metal、96×96、16384 samples × seed 17 / 53。デノイズ・適応サンプリングなし。黒いWorld、縁石・波・バンプ・吸収なし。
- タイルは元材質の下地と発光を0にし、単散乱GGX（粗さ0.3・IOR 1.5・Specular IOR Level 0.5）にする。水はIOR 1.333・粗さ0・白。透過のみのRefraction BSDFと、Fresnel反射も含むGlass BSDFを比較する。元の水材質全体を再現するものではない。
- 光源・正投影のカメラは水なしの較正と同じ。7×7の49画素で測る。水なしのPositionパスから、水越しで同じ画素に見える床の位置を平行な2面のスネル則で計算する。両端は空気なので床での視線方向は元と平行だが、位置は移る。
- 円盤に届く方向を401×401で立体角積分（201×201とも比較）。タイルは厳密Fresnel。Glassの解析には、光源側の2面の透過率を方向ごとに、視線側の2面の透過率を視線の角度で掛ける。水の内部反射を経由する追加経路は解析に含めない。
- `Combined_lamp` の線形RGBを使用。Glass条件ではタイルのSpecular IOR Levelを0にした画像を同じseedで別に描き、差を取る。光源を光沢レイから隠すだけでは「水面を透過→底面で反射→水面を透過→灯り」の像が残るため、この対照が必要。差にはタイルを経由する高次の反射経路も残る。
- 7条件×2 seed＋Glassの4条件×2 seedの対照＝22枚。全49点・各seed・対照・条件・スクリプトのハッシュは `slab.json`。EXR・NPYは `blender/diagnostics/water-gloss-slab/`（Git管理外）。

## 結果

49点の線形RGB合計の Cycles ÷ 解析。相対L1はseed平均と解析の差の絶対値合計 ÷ 解析合計。

| 条件 | seed 17 | seed 53 | 相対L1 |
| --- | ---: | ---: | ---: |
| 水なし | 0.999919 | 0.999851 | 0.0243% |
| 光源側の屈折だけ | 1.000212 | 0.999848 | 0.0631% |
| 光源側＋視線側の屈折 | 1.000054 | 1.000021 | 0.0683% |
| 水のFresnel反射も含む | 1.071578 | 1.071056 | 7.1317% |

| 元シーンのバウンス数・RRも使用 | 1.058413 | 1.056859 | 5.8541% |

- 透過だけの屈折では合計差は最大0.022%、相対L1は0.069%未満。光源への屈折経路の積分と、水越しで同じ画素が見る床の位置の計算は、この条件でCyclesと一致する。201→401の積分解像度による合計差は最大0.024%。
- Glassでは解析より約7.13%強い。解析が含めない水の内部反射・タイルを再訪する経路が候補だが、今回その寄与を個別に切り分けてはいない。合計比の2 seed間の差は0.053ポイント以下。初回4096 samplesでタイルの対照を引かずに出た2.69倍は、水底反射の像が混入した値として破棄した。
- 間接光クランプ10の追加は合計で0.00003%未満の差。Filter Glossy 1を加えると約0.86%減、元のバウンス上限・ロシアンルーレットも加えるとそこから約0.42%減。元設定では解析より約5.76%強い。元設定の最大バウンス10・透過8・光沢4・min_light_bounces 0に対し、対照は16・16・16・8。どちらも反射／屈折コースティクスは有効。
- [画像一覧](contact.png)（ローカルのみ）：seed 17、上段はそのまま、中段はタイル光沢0、下段は差。共通の線形露出2倍→sRGB、96²を192²へ拡大。最初の3条件の中段は水底反射がないことを示す黒い表示で、別レンダーではない。水底反射の円盤が差分から除かれ、タイルのぼけたハイライトが残ることを画像でも確認した。

## 判断と残件

この独立シーンでは、前回の「解析が水越しのCyclesの1.5〜1.6倍」という差を再現しなかった。屈折の計算・光源の換算・寝椅子灯に対するクランプや光沢フィルタだけを原因とする根拠は得られず、製品へ明るさの補正は入れない。

ただし、これは波・側面・縁石・着色・吸収を除いた単一の正投影視線の測定。元シーンでクランプが効かないことや、全視点で解析が正しいことを保証しない。次は元の切り出しで、各画素が実際に見るタイルの位置・法線・視線方向をCyclesの診断用AOV等で取り、平らな水の仮定による対応と比べる。水の着色・吸収と、縁石以外の遮蔽も別項として揃える。今回残ったGlassの約7%は、内部反射回数を制限した対照での切り分けが未実施。
