# 見回し中の2倍MSAAの市松模様とTAA（2026-10-05、確認・判断変更なし）

[4倍・DPR 1.25と2倍・DPR 1.5](../msaa-vs-ratio/README.md)の範囲外「見回し中の市松模様の瞬きと、時間方向の蓄積（TAA）がどこまで均すか」。製品コードの変更はない。

## 結論

**2倍MSAAの段は採らない（前回の判断のまま）。** TAAは2倍の見回し中のちらつきも4倍と同程度の割合（面の残差0.66倍）でしか減らさず、市松模様を特に消すわけではない。TAA有効の製品の状態で、2倍・1.5の面の残差は4倍・1.5の1.36倍、動的解像度の1段下の4倍・1.25（1.24倍）と比べても1.11倍（99百分位1.19倍）大きい。2倍・1.5は4倍・1.25より7〜18%重い（前回）うえに、見回し中も落ち着かない。

## 方法

- `e2e/resolution-shimmer.visual.ts`（1200×800・DPR 1.5・標準画質・動作抑制、3ステージの既定視点×昼・夕暮れ、段1.5と1.25、1フレームに1 CSS pxずつ12ステップ、各ステップ2フレーム）を、4倍（`840b5c1`）と2倍（同じコミットのworktreeで `hdrOutput.ts` の `samples` だけ2）で撮った。
- 順序は4倍→2倍→2倍→4倍（TAA有効）、続けて4倍・2倍を `?temporal=off` で各1回。6回とも成功（各約2分、156枚）。
- `scripts/summarize_resolution_shimmer.py` で回転の射影変換で前のフレームを重ね、L*の残差を画素と12×12画素（8 CSS px）の面で出した。別ビルドの別の段と比べるため `--baseline-ratio` を追加した（例：2倍の1.5を4倍の1.25と比べる）。
- 同じビルドの再撮影は面の残差で±0.6%以内（4倍0.996〜1.006、2倍0.989〜1.005）。

```sh
SHIMMER_RATIOS=1.5,1.25 bun run test:browser:visual e2e/resolution-shimmer.visual.ts --reporter=json > x4.json
# 2倍：worktreeで hdrOutput.ts の samples: 4 → 2 にして同じコマンド（x2.json）
python3 scripts/summarize_resolution_shimmer.py x4.json test-results/visual/<フォルダ> out/x4
python3 scripts/summarize_resolution_shimmer.py x2.json <2倍のフォルダ> out/x2-vs-x4-125 --baseline out/x4/shimmer.json --baseline-ratio 1.25
```

## 結果（6視点の最小・中央値・最大、[値](values.json)）

| 比較 | 面の残差 | 面の99百分位 | 画素の残差 |
| --- | --- | --- | --- |
| 2倍・1.5 ÷ 4倍・1.5（TAA有効、2組） | 1.30・1.36・1.41 | 1.36・1.40・1.44 | 1.25・1.31・1.33 |
| 2倍・1.5 ÷ 4倍・1.25（TAA有効、2組） | 1.03・1.11・1.17 | 1.18・1.19・1.25 | 1.51・1.59・1.71 |
| 2倍・1.25 ÷ 4倍・1.25（TAA有効） | 1.28・1.35・1.40 | 1.39・1.40・1.43 | 1.23・1.31・1.34 |
| 2倍・1.5 ÷ 4倍・1.5（TAA無効） | 1.26・1.28・1.32 | 1.26・1.31・1.34 | 1.28・1.33・1.35 |
| 4倍・1.5 TAA有効 ÷ 無効 | 0.62・0.63・0.65 | 0.60・0.63・0.66 | 0.60・0.62・0.63 |
| 2倍・1.5 TAA有効 ÷ 無効 | 0.64・0.66・0.69 | 0.63・0.68・0.73 | 0.59・0.60・0.61 |

- TAAは2倍でも面の残差を約0.66倍にするが、4倍（0.63倍）よりわずかに効きが弱く、TAA有効では2倍と4倍の差が無効時（1.28倍）より広がる（1.36倍）。履歴を今の画素の周囲5点の箱に制限するため、隣り合う画素で明暗が入れ替わる市松模様の画素は箱が広く、瞬きがそのまま残りやすいとみる（機構は未検証）。
- 2倍・1.5と4倍・1.25は、面の平均で2倍がやや悪く（1.11倍）、まとまった明滅の強い所（99百分位）で1.19倍悪い。水風呂（1.13〜1.17）・外気浴の夕暮れ（1.13）で差が大きく、窓越しの林だけのサウナ（昼1.03・夕暮れ1.06）で小さい。
- 画素の残差は1.5の方が補間誤差（4倍の往復の誤差が1.5で0.24〜0.32、1.25で0.10〜0.13）を多く含むため、段の違う比較（1.59倍）は面の値で判断する。
- 残差の分布（`tiles-*.png`、ローカルのみ）は従来どおり林・庭の葉と柱・縁石の細い縁に集中し、2倍で新しい場所が増えるのではなく同じ場所が強くなる。
