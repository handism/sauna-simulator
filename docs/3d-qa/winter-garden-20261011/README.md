# 3D庭の冬景色（2026-10-11）

表示設定の季節に「冬（雪景色）」を追加。`sui-season` に保存し、未選択時は従来どおり夏。天気は独立していて、冬＋晴れも冬＋雪も選べる。2D背景には反映しない。

## 表現

- 本体・遅れて届く庭の対象広葉樹／モミジの葉メッシュを非表示にして枝を残す。常緑の植栽は維持し、夏／秋への復元時は元の表示状態を戻す。
- `winterSnow.ts` の材質拡張で、対象の地形・石・木・枝の上向きの面へ薄い積雪の色と粗さを重ねる。地形の一部が裏面描画のため、両面材質では表示側の法線を使う。
- ノイズ色・画像ランプの後、照明の前に雪を重ねる。既存のコンパイルフックとキャッシュキーを合成し、冬の選択は共有uniformを変える。モデル再取得・新規のモデル／テクスチャは不要。
- 室内・水風呂・屋根の下のデッキはワールド座標の範囲で除外する近似。ガラス・水・タイル・布・灯りには拡張を付けない。
- 季節変更時に静的影を再描画し、鏡像キャッシュを無効化してTAA履歴を捨てる。葉の子にある深度／影マスクのコピーも、親の非表示に従う。

雪の厚み・シルエットの変化・降雪による積雪量の増加・融雪は含まない。間接光と鏡像を使わない反射は夏の既存プローブを使用し、季節の再ベイクはしていない。
