# メインの描画先のMSAAを2倍に（2026-10-04、不採用・記録）

[GPUメモリ](../gpu-memory/README.md)の残件「残りの大きいもの」のうち、シーンを描く4倍MSAAの半精度ターゲット（`hdrOutput.ts`、1280×800・DPR1で色31MiB＋深度16MiB）。[水面の鏡像](../mirror-msaa/README.md)と同じく標本数を4→2にする候補を、見た目・GPU時間で比べた。

## 結論

**不採用。** 約1割速くなるが、標準画質が実際に描くDPR 1.5の等倍でも、林のカード（`alphaToCoverage`）の葉の縁・デッキの板・寝椅子の脚・枝の輪郭の段がはっきり分かる（[DPR 1.5の切り抜き・中庭](crops-dpr15-01.png)・[外気浴](crops-dpr15-07.png)、左が4倍・右が2倍。[DPR 1の切り抜き](crops-dpr1-01.png)は2倍に拡大。画像はローカルのみ）。庭の見える視点では葉が画面の大半を占め、鏡像（水面に映る小さな像）とは差の量が桁違いだった。60fpsに届かないときは動的解像度が画素比を下げるため、速さの受け皿はすでにある。

## 画像の差

`stage-compare.visual.ts`（水風呂12視点、1280×800）と `cycles-compare.visual.ts`（Cycles 6視点×昼夕夜、1200×800）を `CAPTURE_PNG=1 CAPTURE_QUERY='&resolution=fixed'`、標準画質で、4倍（`936f04d` のworktree）と2倍を交互に2回ずつ撮った。水風呂の24枚とDPR 1.5の全画像は同じ版の2回が全画素一致した。DPR 1のCycles視点の一部（01・04・05）は読み込み間でわずかに揺れたが、平均ΔE 0.0003以下・ΔE>2の画素0.004%以下で、下の差より4桁小さい。4倍に対するCIELAB ΔE76（1回目どうし）：

| 01 中庭（昼／夕／夜） | 2.43／2.00／1.30 | 20.4／17.4／12.2% | 1.75／1.43／0.92 | 15.3／12.9／8.9% |

| 07 座った目線・水と暖 | 1.56／1.48／0.95 | 11.5／10.8／8.5% | 1.18／1.12／0.71 | 8.9／8.4／6.5% |

## GPU時間

`frame-cost.gpu.ts`、標準画質・DPR 1.5・`FRAME_COST_REPEAT=2`・`?resolution=fixed`、1200×800、3ステージ既定視点×昼夕夜。4倍と2倍を順を入れ替えながら交互に4組（各回 `warmup,product`）。1フレームの費用（ms、4回の範囲）：

| | 4倍 | 2倍 | 比（中央値） |
| --- | ---: | ---: | ---: |
| サウナ 昼 | 11.72〜11.85 | 10.27〜10.43 | 0.877 |
| サウナ 夕暮れ | 14.96〜15.03 | 13.40〜13.79 | 0.902 |
| サウナ 夜 | 15.81〜15.99 | 14.27〜14.39 | 0.904 |
| 水風呂 昼 | 14.48〜14.64 | 13.22〜13.55 | 0.918 |
| 水風呂 夕暮れ | 17.62〜17.79 | 15.93〜16.32 | 0.914 |
| 水風呂 夜 | 18.19〜18.46 | 16.60〜16.81 | 0.909 |
| 外気浴 昼 | 8.77〜8.81 | 8.33 | 0.949 |
| 外気浴 夕暮れ | 12.29〜12.32 | 11.02〜11.35 | 0.905 |
| 外気浴 夜 | 13.02〜13.16 | 11.81〜12.29 | 0.908 |

全視点で範囲が重ならず、約1.2〜1.7ms（9〜12%）減った（外気浴の昼は2倍側が60fpsに張り付いた）。canvasのMSAAをやめたとき（1〜2%）より大きく、標本ごとの深度・色の書き込みと解決が主パスの費用のかなりの部分を占めている。

## メモリ（推定、未計測）

色・深度のマルチサンプルのレンダーバッファが半分になり、1280×800・DPR1で約23MiB、DPR 1.5で約53MiB、DPR 2で約94MiB減るはずだが、`gpu-memory.e2e.ts` では測っていない。
