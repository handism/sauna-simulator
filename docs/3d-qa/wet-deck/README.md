# 雨の濡れた面への映り込みとサウナの床（2026-10-20）

## 課題

- 雨の天気で、デッキ・石は暗くなって少し艶が出るだけで、周りの柱・灯り・庭が映らなかった。濡れているより、ほこりっぽく見えた。反射プローブはL2でぼけた空しか持たない。2026-10-12の濡れの導入時（[rain-wetness](../rain-wetness/README.md)）は、粗さを下げると一様な灰色の艶になり、水たまりも灰色の斑になるため見送っていた。
- サウナ室の床は書き出しでUVが一定の一枚板になり（上面は2三角形、`du/dx = 0`）、板も溝もない茶色の面に、表面の質感の細かな木目だけが出ていた。ストーブと桶は床に陰を落とさず、浮いて見えた。室内の細かい照度（`roomIrradiance.ts`）はベンチの下（z < −2.38）だけで、ストーブ周り（z −1.28）には焼き込みの遮蔽が届かない。

## 変更

- **デッキの鏡像**：雨の重みが0.001を超える間だけ、デッキ上面の高さ（0.075m）で鏡映した2枚目の平面反射（`planarReflection.ts` を再利用）を描く。
  - 近クリップ面は0.085m。板と3mm高い舗石の上面が鏡像の平面上にあるため、高さを引数 `clip` で分けた。
  - 解像度は水面の鏡像の0.5倍で、標準画質では描画バッファの0.25倍（1280×800・DPR1で320×200）。
  - 再描画キーは水面の鏡像から動く草の125msのキーを除いたもの。軽量画質・HDR出力のない端末では作らない。
- **濡れた面**（`rainWetness.ts`）：デッキ・石の平らな上面（0.075m±1.2〜3cm・上向き）は、`lights_fragment_end` の直前で反射プローブの `radiance` を鏡像で置き換える。
  - 水膜は入射面に沿って伸びる7点のぼけた像。粗さは鏡像があるときだけデッキ0.4→0.3・石0.3→0.22にする。
  - ノイズのしきい値（デッキ0.75・石0.68）を超えた所は水たまり：粗さ0.04・色×0.85・法線を平らにし、水風呂と同じ雨粒の波紋を足して、鋭い像を映す。
- **対象外**：飛び石上面（`deckIrradiance.ts`）と室内の受光面（`roomIrradiance.ts`）。
  - どちらも既にフラグメントのテクスチャユニット16を使い切っており、鏡像の1枚でリンクに失敗した（`texture image units count exceeds MAX_TEXTURE_IMAGE_UNITS(16)`）。シーンはこれを2Dへのフォールバックとして扱い、ログを出さないため、撮影テストでシェーダーのログを出すようにした。
  - 室内はもともと濡れない。
- **床**（`surfaceDetails.ts` の `SUI_ROOM_FLOOR`、`roomIrradiance.ts` が床の受光面の材質に定義）：
  - 幅14.5cm・長さ2.4mの板をワールドZ方向に敷く。継ぎ目は板ごとにずらす。
  - 5mmの溝は箱フィルタし、画素より細ければ平均の被覆にする。色×0.35・粗さ+0.15・2mm凹ませる。
  - 板ごとに木目の種と濃淡を変える。
- **接地の陰**：ストーブ（半径0.39m、0.42mで消える、最大0.7）と桶（0.2m、0.15m、0.55）の足元で拡散色を暗くする。中心は `refine_loyly_props.py` が維持する座標。

GLB・プローブ・描画パス数（雨以外）は変更しない。

## 不採用・調整

- 水たまりを色×0.6にした最初の候補は、暗い浴槽の壁やパーゴラを映す所で染みに見えた。×0.85にし、水たまりの数も減らした（デッキ0.73→0.75・石0.62→0.68）。
- ストーブの陰は最初の候補（0.34m・0.6）では弱く、0.42m・0.7にした。

## 確認

- `e2e/wet-contact.visual.ts`（Chrome 155.0.8059.85、標準DPR1・1280×800・動作抑制・固定解像度）で、変更前のdist（`7642a33`）と変更後をABBA撮影した（各21枚、計84 PNG）。結果は [comparison.json](comparison.json)。
  - 同方式の再撮影差は変更前0〜2画素、変更後0画素。
  - 1階調を超えて変わった画素は、サウナの晴れ10〜11%（床の板目）、足元の見下ろし25〜26%、外気浴の雨22〜27%。
  - 水風呂の入室視点は0%（デッキが映らない）。
- 比較画像（ローカルのみ、左が変更前）：`compare.jpg`（外気浴の夕暮れのデッキ・右へ向けた昼・サウナの夕暮れの足元）、`floor.jpg`、`side-night.jpg`。
  - 夕暮れ・夜はデッキに庭の灯りが縦に伸びて映る。
  - 昼は柱の像と、曇天の空の艶が出る。
  - 床は板目・溝が見え、ストーブと桶の足元が暗くなる。
- `frame-cost.gpu.ts`（`FRAME_COST_WEATHER=rain FRAME_COST_REPEAT=3 FRAME_COST_VARIANTS=warmup,product`、標準・1200×800・DPR1・固定解像度）を変更前→後→後→前で測った。結果は [cost.json](cost.json)。
  - 静止した入室視点のフレーム間隔÷3の後/前（2組の中央値）は、サウナ1.007〜1.011、水風呂0.995〜1.002、外気浴1.014〜1.021。
  - 主パスの描画数・三角形数は同じ。静止中は鏡像を描き直さないので、この増分は濡れた面のシェーダー（7点の参照）の分。
- 型検査・453単体テスト・Lint・整形・本番ビルド、`scene-lifecycle`・`scene-no-hdr`（HDR出力なし＝鏡像なし）・`season`・`garden-details` の31回帰が成功。

## 範囲

- 静止画での確認。見回し中の鏡像の更新、水たまりの波紋の動き、実機は確認していない。
- 動作抑制なしでは水たまりの波紋が動く。鏡像そのものは視点が止まっている間は描き直さない。
- 見回し中は雨の間、毎フレーム鏡像のパス（外気浴で約100描画、影マスクを含む）が増える。この費用は測っていない。
- 鏡像は水面の鏡像と同じく、近クリップより下（デッキの下の地形）を映さない。
- 飛び石上面には映り込み・水たまりがない。
- 初めて雨を選んだときに、水面の鏡像に写らない材質のパイプラインが作られ得る。
