# 水の側面の全反射を鏡映した像で描く（2026-09-26）

[元blendの水の側面・底をフラットにした](../water-flat-sides/README.md)後、Cyclesでは水風呂の奥・左の側面が全反射で底のタイルを映す明るい面になったが、ブラウザでは玄武岩の内壁が暗く見えていた。前回の「次」は「箱の中の1経路・8〜16本」を試すことだったが、それは到達点の鏡面（タイルではCombinedの0.5〜1.2%）のための近似で、見た目の差の主因は**視線そのもの**が側面で全反射することだった。また到達点も全反射の経路で決まる。そこで先に視線の全反射を製品に入れた。**鏡面の8〜16本の近似は未着手。**

## 方式

- 平らな水面（0.765m）で屈折した水中の視線は |d.y| ≥ cos(臨界角48.6°) = 0.66 なので、底（下は空気の隙間とタイル）では全反射せず、側面では入射角が48.6°を超えれば全反射する（側面にほぼ垂直な水平に近い視線だけが透過する）。視線は下向きに0.55m以内で底に着き、水平方向に最大0.62mしか進まないため、幅2.67m・奥行3.19mの浴槽では**x側面・z側面で各1回まで**しか反射しない。
- 平らな鏡は、鏡面で折り返した場所に像を作る。水中の三角形（元の形状の水の範囲 `WATER_BOX` で水面より下の全三角形）を側面4面・角4つで鏡映した8つの複製を、鏡映した点の「水越しの像」の位置へ既存の頂点屈折で描く。全反射した経路を展開すると、屈折した直線がそのまま鏡映した点に届くため、平らな水面・平らな側面なら像の位置は正確になる（単体テストで、実際に側面で反射させて追った光線の到達点と一致することを確認）。
- 各フラグメントは、画素の視線を水面で屈折させて元の水形状の箱（x=[−0.155, 2.515]、z=[−4.095, −0.905]、底0.215、`diagnose_water_paths.py` の範囲）を追い、全反射した側面の組と一致しない像と、全反射した側面の裏の点（そのままでは側面のすぐ裏の内壁の鏡像が手前に立つ）を `discard` する。本物の内壁も、視線が全反射する画素では捨てる。
- 水面での屈折には現行の波の法線（`WAVE_NORMAL`、水面と同じ時刻）を使う（過去の診断で全反射領域のIoUが平面0.889、波0.958）。像の位置は平らな水面のまま。
- 照明・プローブ・影・コースティクスは真の位置のままで、視線方向だけを鏡映する。
- 描画費用の削減：複製はレイヤー2（水面の鏡像パスに写らない）・影なし・実物の後に描く（`renderOrder` 1、手前の縁石に隠れる画素を深度で捨てる）。カメラが水面より下、水面が視野外、カメラがその側面の外側（屈折しても視線の水平方向は変わらないので反射しない）のときは複製を隠す。
- 省略：側面から透過する視線の部分反射（入射角41〜48.6°でFresnel反射率約7〜100%）と透過の損失。全反射か透過かの二値。像の位置の波による揺らぎ。

## 結果

### Cycles同視点（カメラ03）

Cycles同視点撮影（1200×800、標準画質）を600×400のCIELABで比較（`summarize_water_side_images.py`）。水面の範囲は前回と同じ定義（V11→修正後でCyclesのL*が2より大きく変わった画素）で、前回の値（昼L* 38.1・ΔE 9.4、夕16.4・8.8）を再現した。

| 03 昼・水面の範囲 | 7.5% | 41.9 | 38.1 | 40.9 | 9.4→**7.2** |
| bh-03 夕・水面の範囲 | 6.4% | 22.5 | 16.4 | 16.7 | 8.8→**8.0** |

[compare-03.jpg](compare-03.jpg)・[compare-bh-03.jpg](compare-bh-03.jpg)（上からCycles・変更前・変更後）：奥・左の暗い内壁が、全反射したタイルの像に置き換わった。右奥の注水口の下は全反射しない領域で、波の法線による縞がCyclesの見え方に近い。Cyclesではこの領域にも部分反射が重なるため、ブラウザの方が内壁が濃い。

複製は水中の材質4つ×8で32メッシュ、1複製あたり16,862三角形（全体で134,896）。属性バッファは元と共有し、インデックスだけが増える。描画順を変える前（複製を他の不透明物と並べて描いた版）は、一時的な同じ計測で水風呂の既定視点が昼+14%・夕+7%だった。サウナでは窓越しに水面が視野に入るため複製が描かれるが、深度で大半を捨てる。記録は [gpu-time.json](gpu-time.json)。

この方式は標本を使わない決定的な描画なので、8〜16本の近似で懸念していた粒状の雑音は生じない。

## 限界・残件

- 部分反射（透過する視線の反射7〜100%）と側面の透過損失を省いた。透過する領域はCyclesより内壁が濃く、境界が硬い。
- 像の位置は平らな水面の屈折のまま（波による像の揺らぎはない）。全反射の判定だけが波に従う。
- 経路の判定は元の水形状を軸平行の箱とみなす。水中の物（基壇など）による経路の遮りは判定に入れず、深度の前後だけで決まる（未検証）。
- 到達点の鏡面（水から出る光）の近似は未着手。
- 比較はカメラ03・水風呂の既定視点の4方向・静止した波（動作抑制）・標準画質。動く波・軽量／高精細画質での見た目、モバイル実機、GPU総メモリは確認していない。

```sh
Blender -b blender/scene/SUI_Retreat.blend --python-exit-code 1 --python scripts/blender_stage_reference.py -- day
Blender -b blender/scene/SUI_Retreat.blend -S "SUI • Blue hour" --python-exit-code 1 --python scripts/blender_stage_reference.py -- evening
# 変更前は HEAD の worktree で同じ撮影を行い、cycles-*.jpg・stage-water-*.jpg を別のディレクトリへ集める

  --stage blender/renders/stage-water --stage-before <変更前のstage撮影> --stage-after <変更後のstage撮影>
bun run test:browser:gpu --reporter=json   # 前後それぞれで。添付 gpu-time を gpu-time.json にまとめた
python3 -m unittest discover -s scripts -p 'test_*.py'
```
