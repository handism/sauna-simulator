# 高画質の分割準備後の自動照明と見回し（2026-10-09）

Chrome・macOS headless、1280×800・高画質・動作抑制なし・`frameRate=full`。入室前に高画質を保存し、本体と庭の分割準備完了から検査する。製品コード・配信物の変更はない。

水風呂の昼→夕暮れ（12〜15分）、外気浴の夕暮れ→夜（27〜30分）を各195秒観察。開始前の保持時間だけをDate.nowのオフセットで省き、以後は時計・rAF・タイマーを実時間で進める。50〜70秒と110〜130秒に左右約±0.5radの見回しを行う。

全標本で高画質・自動照明・庭ready・分割完了・本体／庭の未描画グループ0を要求。照明値の単調増加と終点到達、目標との差0.025未満、時計差250ms未満、標本間隔5秒未満、同一canvas維持・2D復帰・エラーなしを検査する。集計は画質・方式・ブラウザの混入、失敗・欠落・入力ハッシュ変更を拒否し、WebMとMP4を全デコードする。

```sh
MOTION_QUALITY=high MOTION_WARMUP=split bun run test:browser:motion --reporter=json > /private/tmp/sauna-high-split-motion.json
python3 scripts/summarize_auto_motion.py /private/tmp/sauna-high-split-motion.json docs/3d-qa/warmup-auto-motion-high --warmup split --browser chromium --quality high
```

録画には符号化負荷があり、動画のfpsはアプリのfpsではない。抽出画像は短時間のちらつきや連続再生の知覚的な合否を保証しない。通常／分割の動画の画素比較、全方向、サウナの動的視点、非HDR実機、WebKit高画質・実Safari・Windows・モバイル・遅い端末、GPU確保量、音の実聴は対象外。既定2Dと分割準備の試験オプションを維持する。
