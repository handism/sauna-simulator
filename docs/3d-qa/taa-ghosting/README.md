# 動くものの残像とTAAの履歴制限幅（2026-10-27、製品の変更なし）

[林の樹冠のちらつきの切り分け](../crown-shimmer-20261026/README.md)で、TAAの履歴制限幅を1.25→2.0にすると樹冠の面の残差が約6%下がる（0.94倍）と分かったが、動くもの（水・草・雨）の残像が未確認で保留していた。その確認。

## 撮影

`e2e/taa-ghosting.visual.ts`。Chrome 155.0.8059.85、1200×800・DPR1.5・標準・固定解像度・`camera=review`、**動作抑制なし**。水風呂・外気浴×晴れ・雨の昼で、1フレームに2 CSS px（ヨー0.008rad）ずつ12ステップ（各2フレーム）見回し、離してから2・10・30フレーム後を撮る（1条件16枚）。

- 時刻は1フレーム1/60秒ずつ進める。条件ごとに時刻を同じ値へ進めてから720フレーム整定し（雨の出入りが収まる）、`Math.random` も固定値から始める。σ=1.25の再撮影は全条件で残差の比1.000、画像も雨の水風呂で平均0.04 L*以外は一致した。
- 時刻は前にしか進めない。既存の `refraction-frame-control.ts` は保留を解くとブラウザの時刻へ戻るため、条件の間で時刻が過去へ飛び、`frameMetrics` の負のdeltaで `lighting.update` の平滑化が NaN になって外気浴の雨が真っ黒になった（撮影側の問題。実際のrAFの時刻は単調）。集計は撮影時の `data-rain` などに NaN があれば拒否する。
- 5回の読み込み：`still-off`（時刻を止めたTAAなし）、`off`（TAAなし＝真のフレーム）、`sigma1.25`（製品）、`sigma2`（検証ブラウザ内でシェーダーの `historySigma` だけ2.0へ）、`sigma1.25-repeat`。

## 集計

`scripts/summarize_taa_ghosting.py`。`off` と `still-off` のL*差が2を超える画素を「動く画素」とし、そこでの各TAAの |L* − off| を真のフレームからの遅れとする。条件・段階（見回し中／離した後）ごとの中央値。

| 条件 | 動く画素 | σ=1.25 | σ=2.0 | 比 | 99百分位の比 | 静止部の比 |
|---|---|---|---|---|---|---|
| 水風呂・晴れ・見回し | 5.8% | 0.97 | 1.19 | **1.28** | 1.28 | 1.05 |
| 水風呂・晴れ・離した後 | 3.2% | 1.24 | 1.59 | **1.27** | 1.30 | 1.07 |
| 水風呂・雨・見回し | 11.0% | 1.97 | 2.25 | 1.14 | 1.09 | 1.08 |
| 水風呂・雨・離した後 | 10.6% | 1.88 | 2.17 | 1.15 | 1.07 | 1.14 |
| 外気浴・晴れ・見回し | 0.2% | 4.68 | 4.75 | 1.01 | 1.01 | 1.03 |
| 外気浴・晴れ・離した後 | 0.3% | 2.65 | 2.72 | 1.03 | 1.02 | 1.02 |
| 外気浴・雨・見回し | 6.4% | 4.91 | 5.16 | 1.05 | 1.03 | 1.05 |
| 外気浴・雨・離した後 | 6.7% | 4.43 | 4.64 | 1.06 | 1.03 | 1.10 |

水面に映る葉の像の輪郭が、σ=2.0では真のフレームより少しにじんで遅れる（水風呂・晴れ・見回し8ステップ目の拡大で目視）。

## 判断

σ=2.0は採用しない。樹冠のちらつきの低減（面の残差0.94倍）に対し、水面の残像が1.14〜1.28倍に増える。制限幅を一律に広げる方向はここで打ち切り、樹冠の粒は発生源（葉のカードの縮小・アルファ）で扱う。

## 範囲

標準画質・昼・2ステージだけ。サウナ（湯気・熱のゆらぎはロウリュの時刻が `performance.now()` で制御できない）、夕夜、高画質、実時間の連続映像・知覚的な合否、実機は見ていない。PNGはローカルのみ。`ghosting.json` に全フレームの値と画像のSHA-256。

## 再実行

```sh
bun run build
bunx playwright test --config playwright.visual.config.ts e2e/taa-ghosting.visual.ts --reporter=json > /tmp/ghost.json
# test-results/visual/taa-ghosting.* を別の場所へ複製してから
python3 scripts/summarize_taa_ghosting.py /tmp/ghost.json <複製先> docs/3d-qa/taa-ghosting
```

`GHOST_SIGMAS=1.25,3` で比べる制限幅、`GHOST_PX` で1ステップの移動量を変えられる。差し替えたシェーダーは最初の読み込みでMetalのキャッシュが冷えているため、読み込みの待ちは120秒にしてある。
