# 天気（雨・雪）追加後の通常ブラウザ回帰と天気の撮影（2026-10-11）

前回の通常回帰（[UI変更後](../browser-regression-20261011/README.md)）の後に、天気（`4094433`・`bf1b8a6`・`e924862`：`SaunaScene.tsx`、`rain.ts`、`lighting.ts`、`sky.ts`、`waterEffects.ts`、`waterBottom.ts`、`glossyLights.ts`、`irradiance.ts`、`SceneMode.tsx`、`useAudioEngine.ts`、`index.css`）とUIの再構成（`e99937e`・`8fb923e`）が入ったため、現ソース（`8fb923e`）で通常回帰の全体と天気の撮影を実行した。Chrome 154.0.8037.98・headless・1 worker。[入力・画像ハッシュ付き記録](validation.json)。

## 通常回帰

- `bun run test:browser --reporter=json`：20ファイル70件中68件成功、2件失敗、所要1107.75秒。skip・flaky・再試行なし。
- 失敗は `reduced-motion.e2e.ts` の2件で、どちらもサウナで `.heart-rate-icon` を待ち続けて90秒のタイムアウトになった。`e99937e` でサウナから心拍表示を外した（サウナは温度・湿度・滞在時間だけを出す）のに、検査が追従していなかった。製品の不具合ではない。
- 検査を直し、心拍の脈動の確認を水風呂（心拍を出す唯一のステージ）へ移した。動作抑制ありでは `animation-name: none`、なしでは `breathe` を確かめる。修正後の `reduced-motion.e2e.ts` は2件成功。製品コードは変えていないため、他の68件は再実行していない。

## 天気の撮影

- `bun run test:browser:visual weather`：1件成功（21.5秒）。3ステージの入室視点で、昼・夕暮れ・夜それぞれの晴れ・雨・雪を撮る（1280×800、27枚、ページエラーなし）。動作抑制ありのため、雨筋・雪片は止まった状態で撮れる。
- 一覧を目視した。全27枚で曇り空への切り替え、雨筋・雪片の表示、照明の段階を確認し、大きな形状欠落・黒抜けはなかった。サウナ室では雨・雪がガラス越しの屋外だけに見える。夜の雪片はほとんど見えない。水風呂の夕暮れ・夜の左下に出るクリーム色の像は、晴れでも出ている既知の水面の反射像。
- 基準画像との照合やCyclesとの比較ではない。雨の水面の波紋の見え方、動いている雨・雪（動画）、実機・GPU時間、雨音の実聴は確認していない。
