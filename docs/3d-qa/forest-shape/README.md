# 遠景の樹冠の輪郭と内部の明暗（2026-10-15）

## 変更

全周撮影で見つかった、横方向に露出する遠景の尖った輪郭と切り絵状の暗い面を対象に調整した。`farForest.ts` の常緑樹の頂部を丸め、常緑樹・広葉樹とも固定乱数に対応する左右非対称の小さな張り出しを追加。既存の高さ・幅の上限を維持し、54mの帯と47〜51mの手前の樹冠へ共通適用する。

樹冠中心に対する横位置の頂点属性を追加し、正面の丸みと片側の肩の陰影を近似する。既存の上下の陰影と葉群の濃淡も調整し、細かな濃淡は画素微分から平均へ寄せる。太陽の方位から解く法線照明ではなく、既存の季節色・時間帯・曇天の色乗算に従う静的な近似。実木・葉カード・動的光源は追加しない。GLB・照度／反射プローブ・既定2Dを維持する。

## 比較方法

変更前と後を別ディレクトリでビルドし、同じ公開アセットと検証コードを使う。描画入力の差は `src/components/3d/farForest.ts` のみ。ポートは通常検証との競合を避け4287を使う。

Chrome channel、晴れ夏・動作抑制。前→後→後→前で、各回に次を撮る。

- 標準・DPR1.5・1200×800 CSS px・固定解像度・TAA有効。初期視点から右へ20キー分（約91.7°）向いた3ステージ×昼夕で、1 CSS pxずつ12ステップ、各2 rAF。各系列の開始前に70フレーム整定。各回78 PNG。
- 標準・DPR1・1280×800の全周216 JPEG。3ステージ×昼夕夜×8方向×上下水平。こちらは通常の画面演出と動的解像度を使い、70フレーム整定する画素一致比較ではない。

各回の最終成功報告・条件・画像寸法・入力と画像のハッシュを照合する。前後の比較画像は `comparison-0.jpg`〜`comparison-4.jpg`（左：前、右：後。ローカルのみ）。外気浴昼／夕／夜の約91.7°、水風呂昼320.9°、サウナ昼45.8°を原寸で比較する。

```sh
SHIMMER_HEADING_STEPS=20 SHIMMER_FIXED=1 SHIMMER_RATIOS=1.5 \
  bunx playwright test --config playwright.visual.config.ts \
  e2e/resolution-shimmer.visual.ts e2e/scene-survey.visual.ts --reporter=json > <run>.json
python3 scripts/summarize_resolution_shimmer.py <run>.json <run-captures/resolution-shimmer-folder> <output/shimmer-run>
python3 scripts/summarize_visual_survey.py <run>.json <output/survey-run>
```

次の実行前に `test-results/visual/` を回ごとに保存する。全周集計時の報告内 `outputDir` は保存先へ合わせる。`SHIMMER_FIXED=1` は最大倍率での撮影専用で、動的解像度の段変更の検証ではない。

最初のsandbox内実行はサーバー起動失敗、次の試行は既存ポートとの競合で失敗。その後の初回は見回し撮影の画質切り替え待機で失敗した。これらは成功数へ含めず、固定解像度・画質を入室前から指定する最終比較を採用する。
