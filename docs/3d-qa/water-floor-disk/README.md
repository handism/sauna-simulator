# 水底反射の斑の平均の不足：床のハイライトを円盤で積分する候補（2026-09-30、不採用）

[water-bottom-gloss](../water-bottom-gloss/README.md) の残る差「斑の平均がCyclesより2.5〜5低い（タイル自身の光沢が表示値でCycles約8.8、ブラウザ約5.5）」を調べた。製品のハイライト（`waterBottom.ts` の `suiWetSpecular`）の近似を直す候補を2つ試したが、Cyclesとの差は縮まらなかったため**製品は変更していない**。

## 近似の誤差（解析、Blender不要）

`scripts/diagnose_water_floor_disk.py`：床の40×48格子で、水風呂の視点（空気層の視線はカメラの向きと同じ）から見たタイルのGGXハイライト（粗さ0.3・F0 0.04、遮蔽なし）を、屈折経路が円盤に当たる方向で厳密に積分した値と比べた（[disk.json](disk.json)）。

| 方式 | 寝椅子灯 合計比 | 寝椅子灯 L1誤差 | V9 合計比 | V9 L1誤差 |
| --- | ---: | ---: | ---: | ---: |
| 製品（中心への直線の向き、α'²=α²+0.25(r/d)²） | 0.674 | 0.411 | 0.977 | 0.080 |
| 中心への屈折経路の向き | 0.856 | 0.401 | 0.998 | 0.071 |
| 候補：中心＋6点（等面積）を各点の屈折経路の向き（Newton 2回）で | 0.984 | 0.092 | 0.971 | 0.029 |
| 19点・厳密な向き | 1.000 | 0.024 | 0.968 | 0.033 |

- 床から光源への屈折経路は水中で急に上るため、空気中の向きは直線より低い。寝椅子灯（2m円盤、床から約6.5m）では直線の向きのハイライトが厳密値の0.67になる。V9（ほぼ真上）はほとんど変わらない。
- 各点の照度は直線の距離・余弦のまま（厚い水の層で円盤が近く見える分と向きが低くなる分がほぼ打ち消す。中心の照度は厳密値の0.96〜1.00）。

## 解析とCyclesの画素比較（ローカルの一時スクリプト）

`diagnose_water_bottom_gloss.py` の切り出しで、Cyclesのタイル光沢（寝椅子灯のライトグループの そのまま − Specular IOR Level 0、線形）と、同じ画素の床の点（平らな水面で屈折、側面の全反射は折り返し）での解析値を比べた（光源の値は 42W・色の平均・透過色と各面のFresnel）。

| 切り出し | 厳密（遮蔽なし） | 厳密（縁石の遮蔽） | 製品（中心の遮蔽） | 候補A | 候補B |
| --- | ---: | ---: | ---: | ---: | ---: |
| 見下ろし：平均÷Cycles | 1.81 | 1.48 | 1.32 | 1.84 | 1.42 |
| 見下ろし：相関 | 0.64 | 0.69 | 0.67 | 0.65 | 0.67 |
| 見出し2：平均÷Cycles | 2.46 | 1.60 | 1.59 | 2.32 | 1.57 |
| 見出し2：相関 | 0.46 | 0.63 | 0.57 | 0.50 | 0.58 |

- 縁石の遮蔽を入れた厳密な値でもCyclesの1.5〜1.6倍、分布の相関は0.6〜0.7にとどまる。Cyclesの光沢は切り出しの左上ほど明るく広く、細い影の線が1本入る。解析はそれより右寄りの丸い山になる。
- 撮影ではブラウザのタイル光沢がCyclesの約6割なのに、解析では製品の式がCyclesの1.3〜1.6倍になる。解析とCyclesの間に、この切り出しの画素と床の点の対応（波・側面の像）、光源の値の換算、Cyclesでこの経路（視線が水を2回通った先の光沢→水→光源）に掛かるロシアンルーレット・クランプのどれかでまだ説明していない約2倍の差がある。これを切り分けない限り、ハイライトの式だけを厳密にしてもCyclesに近づくとは言えない。

## 判断と次の候補

- 製品は変更しない。ハイライトの向き・円盤の近似は解析上は大きく外れている（寝椅子灯で0.67）が、撮影では他の誤差に埋もれ、直すと悪化した。
- 次は、Cyclesで床のタイルの光沢を直接測る（水をカメラから隠し、タイルを1バウンス目にする、または `diagnose_water_floor_highlight.py` の正投影を寝椅子灯・斑の範囲で）ことで、解析の式・光源の値の換算がCyclesと合うかを先に確かめる。合えば、残る差はクランプ・視線側の経路にある。
