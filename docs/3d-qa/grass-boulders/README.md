# 岩から生えて見えた草（2026-10-12）

## 課題

外気浴の既定視点の左手前で、丸い岩のてっぺんから細い草の葉が突き出し、岩から毛が生えたように見えた。サウナの視点でも、水風呂の奥の縁の上に同じように突き出していた。

元GLBの `Ornamental_grass_blade`（材質 `Evergreen foliage`、高さ約0.85m）の5つの束が、どれもデッキ縁の基礎の上に置かれた丸い岩（`Foundation_floating_edge` に結合された `mineral charcoal stone`、高さ約0.48m）の中心に根元を持っていた。元のCyclesのレンダー（03・05）にも岩の陰から草が伸びる構図があり、配置は元のままである。

## 変更

`gardenDetails.ts` の `tuckGrassBehindBoulders()` を、本体の読み込み時（材質準備の前）に `addGardenDetails()` から呼ぶ。

1. **対象の束を決める**：`restingStones()` が分けた石のうち、平らでない半径0.12〜0.75mの岩を候補にする。外形から0.5m以内の草の頂点のうち、1つでも岩の箱の中に入るものがあれば、その頂点の集まりを1つの束とする。
2. **ずらす向きを決める**：中庭の中心（原点。サウナ・水風呂・外気浴の間にあり、どのステージも岩の手前側を見る）から見て外向きを基準にする。外向き・±45°・±90°の順に、束の広がり＋岩の半径の0.9倍＋5cmの範囲に障害物がない最初の向きを選ぶ。障害物の判定は、根元から0.3mと0.6mの高さの水平のレイで行う。(6.7, −3.8) の束は外向き0.23mに漆喰の壁があるため、−z側へ回る。
3. **移動する**：束全体を岩の半径の0.9倍だけ平行移動し、移動先の支え（地形か、平たい石の天面）へ下ろす（上げることはしない。下げ幅は最大0.5m）。基礎の縁に載り溝の上へ張り出した岩では、束は溝の砂利（−0.39m）へ下りる。
4. **障害物の判定を軽くする**：候補の岩の周り1.5mの三角形だけを、ワールド座標の一時メッシュへ抜き出して判定する。葉・草・地面は障害物にしない。石は、その束自身の岩の箱の中での当たりだけを無視する。

実モデルでは5束すべてが動いた。`data-tucked-grass` に数を記録する。読み込み時の増分は、bunで `addGardenDetails()` が約2.6秒から約2.65〜2.69秒（交互3回）になった。最初の実装はモデル全体へレイを飛ばしていたため、さらに約0.2秒かかっていた。

## 確認

- `compare.jpg`：左が変更前（`docs/3d-qa/evergreen-woodland/`）、右が変更後（`garden-details.e2e.ts` の撮影）。上から外気浴の夏、外気浴の冬、サウナの昼の部分拡大。
  - 外気浴：草は岩の陰に回り、岩の左下に数本見えるだけになった。
  - サウナ：水風呂の縁の上に突き出していた草が見えなくなった。
- 単体テスト：岩の奥の縁への移動、下の支えへの下降、岩の外の草を動かさないこと、2回目の処理で何も動かないこと、壁を避けて向きを変えること、どの向きも塞がれていれば動かさないことを検査する。
- 型検査、370単体テスト、Lint、整形、本番ビルド、通常のブラウザ回帰79件（22.7分）が成功した。

## 範囲

元GLB・ベイク済みのプローブは変更しない。草の束は形を変えずに平行移動するだけで、移動先で岩とわずかに重なる部分は岩に隠れる。静的な影は移動後の位置で描かれる。フレームの費用は変わらない（三角形・描画数は不変）。全周撮影・実機は確認していない。
