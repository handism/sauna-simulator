# ロウリュ後の室内の湯気と、ストーブ上の熱のゆらぎ（2026-10-26）

## 変更前

ロウリュの3D表現は、ストーブの石から立つ160点の湯気（`steam.ts`、6秒）だけだった。湿度が上がっても室内の見え方は変わらず、熱い石の上の空気の揺らぎもなかった。元blendには体積の蒸気がない（書き出しの記録）。

なお「雨の日の濡れ」（暗くなる・つや・水たまりの映り込み）は `rainWetness.ts` と `docs/3d-qa/wet-deck/` で実装済みだったため、今回は手を入れていない（[外気浴の雨の撮影](existing-rain-wetness-totonou.png)）。

## 変更

- **室内の湯気**（`steamHaze.ts`）：ロウリュ1回で濃さ0.5（上限1）を約2.5秒で広げ、28秒で1/eに薄める。`hdrOutput.ts` の最終パスで、シーンの深度から視線の終点を求め、室内の箱（ガラスまで）を通る長さと高さ（天井下ほど濃い）で湯気の色へ寄せる。色は時間帯で昼1・夕0.32・夜0.22倍。
- **熱のゆらぎ**（`heatShimmer.ts`）：ストーブ上の空気の柱を画面に投影し、最終パスでその範囲だけ読み出し位置を上へ流れるノイズでずらす。常時0.9px（800px高）、ロウリュから6秒は最大+2.4px。動作抑制では出さない。

不採用：最初は湯気を照度プローブを使う材質ごとに掛けたが、夕方は一定の明るさの湯気が白く飛び、照度プローブを使わない遠景の森・山並みだけが霞まずに残った（[撮影](rejected-material-haze-evening.png)）。最終パスで深度から一律に掛ける形に改めた。

## 確認

Chrome headless・1280×800・DPR1・標準画質・`frameRate=full`。サウナの既定視点で、ロウリュ前とロウリュの3秒後を撮影（画像はローカルのみ）：

- 昼：[変更前](before-day-loyly-3s.png)／[変更後](after-day-loyly-3s.png)。夕：[変更前](before-evening-loyly-3s.png)／[変更後](after-evening-loyly-3s.png)。変更後の撮影は1回の濃さ0.6のときで、その後0.5に下げた。
- 濃さ0.6での領域ごとの輝度の標準偏差（ロウリュ前→3秒後）：昼はガラス越しの庭29.1→20.2・水風呂36.9→27.9・手前のベンチ42.6→34.4、夕は庭16.1→14.3・ベンチ41.0→39.0、夜は庭17.7→17.4。夕夜は淡いベール、昼は景色が白っぽく霞む程度。
- 熱のゆらぎ：静止した視点で120ms間隔の2枚の差（[差分×8](shimmer-frame-diff.png)）は、柱の範囲で平均0.89、柱の外で0.05（8bit）。
- 単体テスト：`steamHaze.test.ts`（室内の区間だけ・天井下ほど濃い・広がりと減衰・室外のカメラでは0・時間帯の色）、`heatShimmer.test.ts`（柱の投影・ロウリュでの増加・動作抑制とカメラ後方で0）。

## 限界

- 体積の描画ではない：湯気は均一に照らされ、光の筋・影・灯りのにじみはない。ストーブ上の湯気の点群とは別の近似で、両者の量は連動しない。
- GLSLの湯気の式とTSの参照実装（`hazeAmount`）は同じ式だが、GPUとの数値照合はしていない。
- 熱のゆらぎは深度を見ないため、柱の手前にあるものも揺れる。
- 最終パスの費用（ノイズ評価・湯気のある間の深度の解決）は測っていない。見回し中の見え方・実機・Safariは未確認。

## 追加の確認（2026-10-27）

`e2e/steam-haze.gpu.ts`（`playwright.steam.config.ts`）。Chrome headless・1280×800・DPR1・標準画質・固定解像度・`frameRate=full`・動作抑制なし（熱のゆらぎを出す）。サウナの既定視点で、ロウリュなしの静止（昼夕夜）を測ってから、各時間帯でロウリュを2回押し、3秒後・7〜11秒（点群の湯気が消えた後）・左へ12キー・さらに上へ10キー（天井下）・25秒後を撮る。旧版（`8c22137` の親、`STEAM_BASELINE_DIST` で配信）と現行を after→before→before→after で比べた。4回とも成功、ページ・コンソールのエラーなし。

- **費用**：1回のrAFで3回描いた間隔÷3。旧版平均→現行平均は、静止 昼10.99→10.95・夕17.13→16.95・夜16.06→16.09ms、ロウリュ後（湯気の濃さ0.64〜0.65）昼17.13→17.02・夕15.90→16.03・夜15.80→15.84ms（0.99〜1.01倍）。同じ版の2回の差と同程度で、湯気の深度の解決・最終パスの計算・常時の熱のゆらぎによる増加は見えない。ただし間隔は表示間隔の倍数に量子化されるため、段をまたがない小さな差は検出できない。GPU単体の時間・実機ではない。
- **夕夜の白飛び**：濃さ0.86（3秒後）・0.65（11秒後）とも白く飛ばない。夜は屋外の暗部が灰色に持ち上がる淡いベール（ガラスの曇りに近い）、昼は景色が白っぽく霞み、見上げると天井下ほど濃い。
- **見回し後**：左（ガラス・水風呂側）と天井下の視点で、深度の境目（ベンチ・壁・パーゴラと空）に湯気のにじみや線は見当たらない（原寸の拡大で確認）。撮影はキー操作から1.2秒後の静止で、見回しの最中のフレームではない。
