# 水から出た鏡面を少数の方向で引く場合の本数と誤差（2026-09-26）

前回の[全周参照の色の誤差](../water-capture-radiance/README.md)の次の課題「水中の到達点で少数の方向を水面で屈折させ、箱で補正して引いた場合の本数と誤差」を、同じ真値で測った。**Blenderでの新たな描画はなく、製品・配信データは変更していない。暗い帯の修正は未完了。**

## 測定条件

- 真値は前回のCyclesの描画をそのまま使う。到達点67点（水から出る終端がない2点を除く65点）の鏡面ローブ64本を元の水形状に通し、水から出た終端ごとに描いた放射輝度の積分 (1/64)Σ重み×放射輝度。前回除いたPositionのずれた終端175本（重み2.87%）は、今回はその終端の参照の値で埋めた（モデル側は遮蔽を区別できないため）。
- 前回の鏡面ローブは乱数種から完全に再現できることを確かめた（全点で `lobe_total` の差0）。
- **シェーダーで書ける近似（箱の中の1経路）**：到達点から配信GLBの粗さのGGX方向を引き、水を軸平行の箱（元の水形状の側面・底、上面は製品の平らな水面0.765m）とみなして進める。
  - 到達点が箱の外（底の1.3cm下のタイル、側面の外の壁）なら、入るときに屈折させてFresnelの透過率を掛ける。
  - 箱の中では反射側だけを最大6境界まで追う。上面を透過した分を「水から出た光」として2段の箱（浴槽の箱の上面を縁石1.035m、中庭の箱）で補正し、参照（浴槽中央・水面10cm上、昼夕2seedの平均）を双線形で引く。側面・底を透過した分は浴槽側（水中の成分）として捨てる。全反射は重みを保つ。重み1e-3未満で打ち切る。
  - 上面の法線は平ら（`flat`）と、製品の静止波の法線（`wave`、`waterEffects.ts` のt=0、`diagnose_water_paths.py` と同じ式）の2通り。
  - 水中の遮蔽（くぼみ・段）は扱わない。水面0.765mより上の到達点1点は屈折なしで直接引く。
- 標本：Hammersley点列に試行ごとのランダム回転（Cranley–Patterson）を掛けたN本（1〜64、到達点×Nごとに32試行）。4096本を収束値（モデルの偏り）とした。誤差は到達点ごとにRGB絶対差の合計を真値のRGB合計で割り、到達点の中央値・90百分位を試行の中央値で示す。
- 参照は幅128（キューブ1面32相当、前回の採用候補）と2048。以下は幅128の値（2048との差は中央値で1ポイント前後）。
- 材質群：タイル（`Teal glazed pool tile`、49点）、青銅（`Blackened bronze`、11点）、石（`quiet honed stone`、5点）。

## 結果

### 収束時（4096本）の偏り

到達点ごとの誤差（水から出た成分の真値に対する割合、中央値／90百分位、昼／夕）。

| | 全65点 | タイル49点 | 石5点 | 青銅11点 |
| --- | --- | --- | --- | --- |
| 参考：終端ごとに正確な方向で引く（前回のMC） | 6.4%/23% ／ 5.4%/23% | | | |
| 箱の中の1経路・平ら | 9.6%/115% ／ 10.0%/112% | 6.9%/32% ／ 7.1%/34% | 15%/53% ／ 12%/51% | 125% ／ 120%（90百分位 68〜107倍） |
| 箱の中の1経路・静止波 | 9.6%/122% ／ 8.6%/118% | **6.0%/25% ／ 6.5%/32%** | 27%/32% ／ 25%/30% | 138% ／ 130% |
| 同・出る量だけ真値に合わせた場合（平ら） | 7.4%/57% ／ 8.1%/40% | | | |

- **タイルでは、箱の中の1経路は正確な追跡とほぼ同じ誤差**（中央値6〜7%）。今回、最初に側面を考えず平らな水面だけを通す形で試すと、水から出る量が中央値で真値の4%しかなく、誤差は96%だった。到達点の多くはカメラからの経路が側面で全反射してから底に届いており、鏡面ローブも同じ経路を逆にたどるため、**側面の全反射は必須**。
- **青銅の基壇は大きく過大**。追跡ではローブの92〜98%が基壇のくぼみの周りのタイルに当たって水中に戻る（[到達先の分類](../water-reflection-targets/README.md)の `pool_overhead`）が、箱には遮蔽がないため、青銅11点中5点で水から出る量を10〜34倍に見積もる（残りは0.7〜2.9倍）。モデルと追跡の出る量の比は全体で中央値1.01、90百分位1.45、平均2.40で、平均を押し上げるのは青銅。
- 出る量を真値に合わせると（遮蔽が完全に分かった場合の目安）全体の中央値7〜8%・90百分位40〜57%。残る90百分位は、側面と壁の隙間の空気から抜ける経路（到達点39：追跡でローブの47%が水上へ出るが、箱ではほぼ0）や側面透過後の壁の点など、箱で表せない経路。
- 静止波の法線はタイルの90百分位をやや改善するが（昼32%→25%）、石5点の中央値は悪化する（15%→27%）。点が少なく、差の向きは決められない。

## 判断

- 「箱の中の1経路（側面の全反射を含む）→上面で屈折→2段の箱で補正→幅128の参照」は、**タイル・石では採用候補**。本数は **8〜16本**（タイルで中央値12%→9%、偏り6〜7%）。16本を超えても偏りが残るため効果は小さい。1画素の雑音はN=8で約11%あり、時間方向の蓄積やぼかしのない製品では粒状に見える可能性がある（未評価）。
- **青銅（基壇のくぼみ）はこのままでは使えない**。水中の遮蔽を表す量（例：到達点ごとの、ローブが水面まで遮られずに届く割合をBlenderで焼き込んだ値）が必要。次は、この遮蔽率を場所の関数として焼き込んだ場合に、青銅・側面近くのタイルの誤差がどこまで下がるかを測る。材質ごとの一律係数では、くぼみの内外の差を表せないと考えられる（未検証）。
- 静止波の法線を使うかは、この点数では決められない。製品の現行の波の法線を使うなら同じ式でよい。

## 限界

- 到達点67点・カメラ03の静止した元形状だけ。65点を等重みで集計した。19点は層化標本。
- 真値・ローブの重みは前回までと同じ近似（単散乱GGX・スカラーF0・幾何法線・滑らかな水・光源は交差させない）。前回の19点のうち2点（11・8）の「予測が鏡面パスより3〜8倍大きい」問題は未解決。
- 真値は64本の積分で、4096本の収束値との比較には真値側の標本の誤差（ローブの離散化）も含まれる。
- 空気の隙間を抜ける経路・側面から壁に出た後の光・動く波・GPU費用・時間方向の雑音・別視点は評価していない。V9・夕暮れの暖色灯5灯のハイライトは真値・参照の両方から外したまま。
