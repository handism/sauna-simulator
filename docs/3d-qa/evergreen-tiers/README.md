# 林の常緑樹の段と向き（2026-10-29）

利用者の「1の対応お願い」。同日のHEAD（`b66119b`）の静止画で、冬の雪原の手前の常緑樹が、円錐に並べ直した後も、大きな葉の札がまばらに積まれた柱に見え、空が透け、先端の上に葉の塊が浮いていた（夕暮れの影絵でさらに目立つ）。

## 原因

- 常緑の木（58本）のカードは1本約130〜350枚（多くは約200枚）、一辺約0.5m（`EVERGREEN_CONE.CARD` 0.75倍で約0.36m）。高さ8〜11mの木では円錐の側面積約75m²に対しカードの面積は約26m²で、被覆0.41のマスクを考えると面の1〜2割しか覆っていなかった。
- `shapeEvergreenCones()` はカードの元の傾きを保つため、半分ほどのカードが視線に横向き（細い線）になり、覆う面積をさらに減らしていた。
- 木ごとのカードの高さを見ると、多くの木で半分ほどが地面近く（1〜2m）にあった（幹の高さ2m未満の若木の分が最も近い幹に割り当たる）。高さの順位で並べ直すため密度には影響しない。最も高いカードと97%点の差は0.5〜1.5mで、円錐の高さの外れ値が原因ではなかった。

## 変更（`evergreenWoodland.ts` の `EVERGREEN_CONE`・`shapeEvergreenCones`）

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| 円錐の下端 | 高さの16% | 30%（林の針葉樹らしく下は幹だけ、面を詰める） |
| 底の直径 | 高さの0.3倍、1.3〜2.4m | 0.26倍、1.1〜2.1m |
| カードの大きさ | 一律0.75倍 | 根元1.05倍→先端0.6倍（先端を尖らせる） |
| 段 | なし | 1.1mごと（段の下端で最も張り出し、次の段まで0.3だけ短く） |
| 向き | 元の傾き | 外向き＋上へ0.45±0.25radへ0.8だけ回す（両面なので近い側の面で判定、法線も回す） |

三角形・描画数・材質は不変。樹冠の法線（`roundWoodlandCrowns`）・林床の足跡・カードの複製（`woodlandCrowns.ts`）は従来どおり並べ直した後の形に従う。

最初の実装は回転を `turn.copy(none).slerp(turn, …)`（自分自身との補間）にしていて、カードが回っていなかった。単体テストに向きの検査を足して見つけた。

## 確認

Chrome 156、1280×800・標準DPR1・固定解像度・動作抑制。

- 静止画：`REVIEW_RUN=<回> REVIEW_STAGES=totonou bunx playwright test --config playwright.visual.config.ts e2e/graphic-review2-20261029.visual.ts`（撮る前に `bun run build`）で、変更前（HEAD）・段と大きさだけ（回転なし）・最終の外気浴9視点を並べて目視した（画像はローカルのみ）。
  - 冬の昼・夕暮れの正面：手前の常緑樹が、細い穂先と段のある詰まった針葉樹の形になった。夕暮れの影絵でも針葉樹と分かる。
  - 冬の右：近い常緑樹（10〜20m）が、空の透けた葉の柱から詰まったトウヒの塊になった。回転を直した版は、回転なしより面が詰まる。

  - 残り：先端に1〜2枚のカードが離れて見える木がある。遠い木の輪郭は針葉の小枝ではなく、ぼけた卵形の葉の集まり。
