# 水面に映る V7 の帯のぼかし（2026-10-20）

## 課題

- 季節・天気の全周撮影（夏・春・秋・冬の晴れ、夏の雨、冬の雪、各216枚）の目視で、夕夜の水風呂を見下ろすと、足元に縁の硬い灰色の板が浮いているように見えた（`water-*-{0..4,7}-down`）。
- 正体は水面の鏡像に写る光沢専用の面光源 `V7 water reflection soft strip`（2.2×1.6m、高さ5mで水風呂の視点のほぼ真上、昼夕夜とも65W、`glossyLights.ts`）。低画質（鏡像なし）では消える。
- Cyclesの参照（`blender/renders/stage-water/night-1-down.png`・`day-1-down.png`）にも同じ形で写っており、元シーンの再現。夜は周りが暗く、照明ではなく置かれた物に見える。

## 変更（元blendにない補正）

- `SOFT_GLOSSY` を長方形にも使えるようにした。距離は形の半分の大きさ（円盤は半径、長方形は短い辺の半分 `softUnit`）を単位とし、長方形は長い方向の余り（`softInner`）の箱からの角の丸い距離で測る。円盤では従来と同じ式。
- V7：`core 0.7, falloff 0.25, reach 1.6`。内側（各辺から0.24m内側、角の半径0.56m）は一定、その外は0.2mごとに1/eで落とし、各辺の外0.48mまで描く。電力は元のまま（中心は1.26倍、寝椅子灯は1.29倍）。
- 最初に試した `core 0.5, falloff 0.3` は中心が1.62倍になり、夜に明るい光の玉として浮いたため採らなかった。
- 電力の補正（`softScale`）は、箱から距離rの帯の長さ `4(a+b)+2πr` による1次元の積分（読み込み時の計算を軽く保つ）。単体テストは2次元の格子積分と照合する。
- 断片段は `inner` 属性と `softness.w`（reach）を追加し、reach の外は0にする（円盤は描画範囲が reach と一致するため従来と同じ）。
