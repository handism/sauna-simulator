# ブラウザのタイル光沢をCyclesと線形で比べる：側面で反射した灯り（2026-09-30）

[元シーンの切り分け](../water-gloss-scene/README.md)の残件「ブラウザで同じ切り出しのタイル光沢だけを撮り、Cyclesの `source` と画素ごとに比べる」に対応した。ブラウザでは斑の手前半分（水を真っすぐ見下ろす部分）にタイル光沢が**まったく出ていなかった**。Cyclesではそこを、水の側面で全反射した寝椅子灯が照らしている。この経路を製品に足した（`waterBottom.ts` の `suiWetImage`）。

## 撮影と比較

- `e2e/water-gloss-capture.visual.ts`：水風呂ステージの夕暮れ・見下ろし（見出し1）・見出し2（`stage-compare.visual.ts` と同じ操作、標準画質・1280×800・動作抑制）。検証ブラウザ内だけで `shaderSource` を書き換え、HDR出力の全画面パス（`hdrOutput.ts`）をAgXの代わりに線形値×0.5（露出なし）にしてsRGBで保存する。`off` は寝椅子灯の `suiWetSpecular`（と、あれば側面の像）を外す。on − off がブラウザのタイル光沢。`on` を2回撮り、ページ読み込み間の差も測る（今回は全画素一致、飽和0）。
- `scripts/summarize_water_gloss_capture.py`：Cyclesのタイル光沢（[`diagnose_water_gloss_scene.py`](../water-gloss-scene/README.md) の `source`、寝椅子灯のライトグループのSpecular IOR Levelオン／オフの差）、Combined（`diagnose_water_bottom_gloss.py` の `base`）と、同じ切り出し（見下ろし 680–940×0–180、見出し2 120–420×520–720）で画素ごとに比べる。各画素は平らな水の箱で視線を追い、**真っすぐ**（床まで側面に当たらない）と**側面の像**（側面で1回反射）に分ける。
- 値は輝度（線形）。「斑」はCyclesの寝椅子灯成分の上位20%、「自分の斑」はそれぞれの全体（Combined／ブラウザのon）の上位20%。

## 分かったこと

変更前（HEAD `56253ef`）：

| | 見下ろし ブラウザ／Cycles | 見出し2 ブラウザ／Cycles |
| --- | ---: | ---: |
| 斑のタイル光沢 | 0.0704 / 0.0850 | 0.0587 / 0.0794 |
| 真っすぐの部分の光沢（切り出し全体） | 0.0003 / 0.0186 | 0.0004 / 0.0238 |
| 真っすぐの部分の光沢（斑の中） | 0.0014 / 0.0801 | 0.0009 / 0.0678 |
| 側面の像の光沢（切り出し全体） | 0.0407 / 0.0393 | 0.0344 / 0.0353 |
| 側面の像の光沢（斑の中） | 0.0916 / 0.0865 | 0.0872 / 0.0851 |
| 自分の斑の全体の明るさ | 0.4167 / 0.4534 | 0.3971 / 0.4404 |

- 斑の奥の半分は水の側面（x最小、`V4` の平らな側面）で反射した床の像で、手前の半分は真っすぐ見た床。Cyclesでは両方に同じくらいの光沢があるが、ブラウザは**真っすぐの部分が0**だった（Cyclesの細い暗い帯は側面と床の境目で、影ではない）。側面の像の部分はCyclesと±6%以内で合う。
- 真っすぐの部分から見た寝椅子灯（+x）は、視線と同じ側にあって光沢の向きから外れる（半ベクトルと法線の内積0.43、粗さ0.3のGGXではほぼ0）。Cyclesのこの部分の光沢は、x最小の側面で全反射した寝椅子灯（側面に映った灯りの像）によるもの：平らな層の積分で、実物の灯りは0、側面で鏡映した灯りでCyclesの0.75／0.64倍（遮蔽・着色なしの解析なので、[前回](../water-gloss-scene/README.md)の側面の像側の0.62／0.61倍と同程度）。側面を越えた後の経路は臨界角より浅く全反射する。
- 前回までの「斑の平均がCyclesより2.5〜5低い」の主因はこれで、光沢の式・光源の換算ではなかった。以前の「ブラウザの斑はCyclesの約6割」は、この欠けた半分を含む平均だった。
- 斑の位置（自分の斑同士の重なり69〜71%、重心は5px程度ずれる）と、真っすぐの部分以外の像の明るさ（光沢を除いた全体でブラウザ0.338／0.333、Cycles 約0.36）の差は今回扱っていない。

## 方式（`waterBottom.ts`）

- V9・寝椅子灯それぞれについて、x・zの各軸で灯りから遠い側の側面に映った像を考える。床の点を側面で鏡映した点から灯りへの屈折経路（空気層→水→水面の上）の空気中の向きをNewton法4回で解く（像は灯りから遠く、直線の向きでは屈折経路より大きく上を向くため。直線の向きのままだとハイライトが右下にずれた）。経路が側面より先に水面を出る・水の箱の外で出る・その先で縁石（1.035m）より低く箱を出る場合は届かない。
- 灯りの色は像の点での `getSpotLightInfo`（距離と余弦配光）、側面のFresnel反射率（多くは全反射で1）を掛け、向きを側面で折り返して `suiWetSpecular` に渡す（出口の判定は済んでいるので省く）。
- 影マップは引かない。最初の版は出口の点でPCSSを引いたが、この視点では値がほぼ1で画像が変わらず、スポット光の展開ループ内に灯り×2軸の分だけPCSSが展開されてサウナ（対象外）まで約1割遅くなった。像の計算はループの後に1回だけ行う（ループでは灯りの番号だけを記録）。消灯中の灯り（夕暮れ・夜のV9、昼の寝椅子灯）は計算しない。
- `wetImage` がTSの参照実装で、`waterBottom.test.ts` が折り返した経路が灯りに届くこと・全反射・側面より先に水面を出る場合を検査する。

## 残る差

- 真っすぐの部分の光沢が斑の外で1.5倍強い（切り出し全体0.030／0.036 対 Cycles 0.019／0.024）。像の経路の遮蔽（天蓋の梁・ルーバー、[前回](../water-gloss-scene/README.md)の直接の経路で約18%）・水の着色の差を入れていない。影を引いても値がほぼ変わらなかったので、ブラウザの影マップにこの細い遮蔽物が入っているかは未確認。
- 斑の標準偏差がCyclesより約1小さい（光沢がなだらか）。夜は平均が1.5程度明るくなった。
- 角（x・z両方の側面で反射）の像、側面の像の中の像（ブラウザの側面の像はすでに鏡映した視線で実物の灯りの光沢を持つ）は扱わない。バンプは光沢の経路に入れていない。

## 再実行

```sh
bun run test:browser:visual e2e/water-gloss-capture.visual.ts --reporter=json > <dir>/report.json   # PNGを test-results/visual/*/ から <dir> へ
python3 scripts/summarize_water_gloss_capture.py <before dir> <after dir> --out docs/3d-qa/water-gloss-capture
python3 -m unittest discover -s scripts -p 'test_water_gloss_capture.py'
```
