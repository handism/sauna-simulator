# 遠い森の帯（2026-10-12）

## 課題

林（`V6 woodland leaf N card`、原点から半径10〜44m、樹冠の上端は約11m）は細い幹に房が付いた木の並びだった。木と木の間からは地平線まで空が見え、外気浴・水風呂から見ると、林ではなく丘にまばらな木が立つ景色に見えた。樹冠のカードをさらに増やす案は、前回（`../crown-fill/`）2枚目の複製で屋外の費用が+17〜26%になり、採用していない。

## 変更

`farForest.ts` を追加し、`gardenDetails.ts` から呼ぶ。林と山並み（半径72m〜）の間の半径54mに、照明を受けない1メッシュの森の帯を置く。

- **樹冠**：2.2〜4m間隔で並べる。丸い広葉樹（半径1.6〜3m）と、約35%の円錐形の常緑樹（半径1.3〜2.1m、高さは半径の2倍）にする。
- **高さ**：上端はy=6〜13mで、数十m周期で高い林分と低い林分が入れ替わる。低い所では山並みがのぞく。
- **輪郭**：約1m周期の凹凸を付ける（常緑樹は半分）。
- **塗り**：
  - 0.7mと2mの葉群のむらを付ける。
  - 各樹冠は上ほど明るく、下ほど暗くする（重なった樹冠を見分けるため）。
  - 足元の下草は暗くする。
  - 山並みと同じ霞色を0.08〜0.22だけ混ぜ、裾ほど強くする。
- **季節**：頂点色を季節ごとに塗り替える（秋は赤・橙・黄土・茶、冬は灰褐の枯れ木と常緑樹、春は若葉）。
- **光**：材質色で掛ける。昼は0.45、夕夜は山並みと同じ比率で暗くし、曇りでは最も近い山並みの割合へ寄せる。
- 影は投射せず、受けもしない。描画数は+1（三角形約5,700）。

## 不採用

- **最初の案**（上端5〜10m、霞0.3〜0.5、昼の光1.0、常緑樹の高さは半径の3.2倍）：灰色の三角形と丸の切り絵が、山並みと同じ明るさで並ぶ書き割りに見えた（`rejected-first-try.jpg`）。
- **輪郭の凹凸を0.2〜0.9m周期・振幅0.65m**にした案：のこぎりの歯のように見えた。

## 確認

`garden-details.e2e.ts`（標準・1280×800）で撮影した。

- `compare-zoom.jpg`：外気浴の夏。上が変更前、下が変更後。林の奥が森で埋まり、密な林に見える。右手の常緑樹は円錐の連なりに見える。
- `stages-seasons.jpg`：サウナの昼、外気浴の秋・冬・夜。
  - 秋は落ち着いた赤・黄土の帯。
  - 冬は灰褐の枯れ木の中に常緑樹が残る。
  - 夜は暗い森になる。
- 型検査、377単体テスト、Lint、整形、本番ビルド、通常のブラウザ回帰79件（22.9分）がすべて成功した。

## 範囲

帯は奥行きのない1枚の輪郭で、見回すと手前の林との視差はあるが、帯自体の奥行きはない。プローブ・水面の鏡像の照明は従来どおりである（帯は鏡像にも写る）。林の足元の暗い帯（下草の影）は変えていない。雨雪の帯の色は、曇りの割合で山並みと同じように寄せるだけである。見回し中のちらつき、全周撮影、実機は確認していない。
