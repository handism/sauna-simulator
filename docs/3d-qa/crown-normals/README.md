# 林の樹冠の法線（2026-10-13）

## 課題

林の葉カード（`V6 woodland leaf N card`）は、向きのばらばらな平面として照らされていた。両面材質は視点側へ法線を反転するので、どのカードも見えている面の向きで明暗が決まり、樹冠は明るい点と暗い点の散らばりに見えた。日なた側と陰の側、上と下の差が出ず、枝に房が付いただけの木に見えていた。

## 変更

`crownNormals.ts` の `roundWoodlandCrowns()` を、庭の読み込み時に `splitEvergreenWoodland` の前に呼ぶ。

- 各カードを、常緑樹と同じく最も近い幹（`trunkBases`・`trunkFinder`、5m以内）の木に割り当てる。
- 木ごとに、カードの中心の平均を樹冠の中心、広がりの半分を楕円体の半径（下限0.6m）とする。
- 頂点の法線を、楕円体の外向きの勾配へ `CROWN_NORMAL_WEIGHT`（0.9）だけ寄せる。残りはカード自身の法線を外向きにそろえたもの。
- この法線はカードのどちらの面でも外向きなので、材質に `SUI_CROWN_NORMAL` を定義し、視点側への反転を省く：`normal_fragment_begin`（グローバルに差し替え）、影マスク（`shadowMask.ts` の照明パスとマスク材質）、雪の上向きの判定（`winterSnow.ts`）。条件は `TURNS_TO_VIEWER`。
- 幹から5m超のカードは元の法線のまま（反転はしない）。
- `Material.copy` は `defines` を写さないので、常緑樹の材質の複製で明示的に写す。

描画数・三角形数・テクスチャは変わらない。

## 候補

- 重み0.7（`compare-w07.jpg`、上が変更前）：差が小さく、外気浴の夏で平均|ΔL|1.7（8段階超の画素5.8%）。
- **重み0.9（採用、`compare.jpg`、左が変更前）**：秋の外気浴で、樹冠の上面が明るく下が暗い塊として読める。夏は林がわずかに明るく均一になる。

## 範囲

ベイク済みの照度・反射プローブは元の樹冠のまま。樹冠の内側の遮蔽（奥のカードほど暗い）は入れていない（林のカードは頂点色を持てない：深度プリパスの切り抜きの条件）。近景のモミジ・低木は対象外。見回し中のちらつき・実機は確かめていない。
