# 動的解像度の段と見回し中のちらつき（2026-10-02、確認）

[段の見た目](../resolution-steps/README.md)の残件「見回し中の葉のちらつき」。製品コードの変更はない。

## 方法

- `e2e/resolution-shimmer.visual.ts`：Chrome headless・M1 Max・1200×800・DPR 1.5・標準画質・動作抑制・庭の準備完了後、`bba496a` の本番ビルド。
  3ステージの既定視点×昼・夕暮れの各段（1.5・1.25・1、`resolution-control.ts` で保持）で、1フレームごとに1 CSS px（ヨー0.004rad）ドラッグして
  13フレームを画面の画素（1800×1200 PNG）で撮る。
- 純粋な回転なら、奥行きに関係なく前のフレームを次のフレームへ射影変換で重ねられる（回転順YXZ、俯角と垂直画角は `sauna.scene.json` の視点）。
  `scripts/summarize_resolution_shimmer.py` が3次補間で重ね、L* の残差（動きで説明できない変化：縁の画素の段差、葉の出入り）を12組の平均で出す。
  - 画素：残差の絶対値の平均。
  - 面：12×12画素（8 CSS px）の平均の絶対値の平均と99パーセンタイル。葉の出入りは面の平均を変え、補間の誤差はほぼ打ち消し合う。
  - 対照：往復（k→k+1→k）の誤差＝同じ像での補間誤差の2回分。
- 重ね方の確認：最初の組で、重ねる前の差 3.0〜4.9、ヨーの符号を逆にすると 4.4〜6.6、正しい符号で 0.64〜1.22（系列平均）。往復の誤差は画素0.10〜0.45・面0.005〜0.013で、
  同じ系列の面の残差（0.10〜0.27）の8.5%以下（補間1回分ならその半分）。

## 結果（6系列×3段、[値](shimmer.json)）

| 1.5に対する比（同じ視点） | 画素（最小・中央値・最大） | 面（最小・中央値・最大） | 面の99パーセンタイル |
|---|---|---|---|
| 1.25 | 0.75・0.80・0.82 | 1.16・1.21・1.24 | 1.11・1.13・1.18 |
| 1 | 0.82・0.84・0.88 | 1.45・1.50・1.52 | 1.28・1.39・1.44 |

- 画素の残差は低い段ほど小さい（拡大のぼけで縁の段差が柔らかくなる）。一方、8 CSS px 四方の面の残差は1.25で約1.2倍、1で約1.5倍に増える。
  画素が粗いほど葉1枚の出入りが占める面積が大きく、面の明るさの揺れとして大きくなる。
- 面の残差の分布（`tiles-*.png`、左から1.5・1.25・1、ローカルのみ）は林・庭の葉と細い縁（柱・縁石の線）に集中し、水面・タイルにはほとんど出ない。
  サウナの窓越しの林、外気浴、水風呂の庭側のいずれも同じ傾向。
- 夕暮れは昼より残差が小さい（暗い分）が、段ごとの比はほぼ同じ。

## 判断

前回の「下げるとぼけでちらつきが減る可能性」は、面の尺度では逆だった。1.25・1では細かいギザギザは柔らかくなるが、葉のまとまった明滅は増える。
動的解像度は60fpsを保つための手段で、下げた段は1.5より見回し中の葉が落ち着かない。費用に余裕があれば1.5を保つ現在の設計（上げの試行）を変える理由はない。
葉のちらつき自体は1.5でも残る。近景の葉は小さな三角形、遠景の林は alpha to coverage のカードで、どちらもすでに4×MSAAの描画先で描いている。
減らすには葉の表現（遠くの葉の間引き・まとまりの粗さなど）を変える必要があり、別の課題（未着手）。

## 範囲

L* だけの静止フレーム列の比較で、知覚的なちらつきの合否ではない。PCSSの標本の回転など画面に固定された模様の流れも残差に含まれる（分布からは葉が主）。
1フレーム1 CSS px のゆっくりした見回しのみ。他の端末・表示倍率・動作抑制なし（水の動き）は対象外。
