# 3D庭の春（2026-10-11）

表示設定に「春（若葉と花）」を追加。選択は既存の `sui-season` に保存し、未選択時は夏のまま。2D画像は変更しない。

## 表現・構成

- `season.ts` が本体と遅れて届く庭の広葉樹／モミジに黄緑の若葉色を適用する。常緑樹・苔・シダの元色は維持する。
- `springFlowers.ts` は本体の苔・庭土・砂利の地形をレイキャストして、小径周辺の10箇所に各7輪の白・淡いピンクの小花を置く。世界座標で高さを調べ、rootの逆行列でメッシュをローカル座標に戻す。
- 茎・5枚の花弁・黄色い中心を頂点色の静的な1メッシュに結合する。外部素材・新たなテクスチャ・インスタンスバッファ・毎フレームのアニメーションは使わない。
- 花は本体に追加してから材質・照度プローブ・反射・深度プリパス・影マスクの準備を行い、本体と一緒に解放する。春以外では親メッシュを隠し、深度／影マスクの子も追従する。
- 冬→春では積雪を解除して葉と花を表示。春→夏／秋／冬では花を隠す。色と表示の変化時に影・鏡像キャッシュ・TAA履歴を更新し、モデルは再取得しない。

桜の木への置き換えや舞う花びらは含まない。間接光と鏡像を使わない反射には、他の季節と同じ夏の既存プローブを使う。
