# 晴れの昼の日差し（2026-10-12）

## 課題

天気「晴れ」の昼が曇りの日のように見えた。元のDaylight（Cyclesと一致させてきた値）は、空に約4割の青灰色の雲があり、日光（3.2）が照度プローブの補助光に対して弱いため、日向と日陰の差が小さい。外気浴・水風呂の既定視点は日光をほぼ正面に受ける逆光で、上向きの面にしか日が当たらない。

## 変更（元にない、ブラウザ側の見え方の補正）

- 空（`sky.ts` の `CLEAR_DAY_SKY`）：雲の閾値を low +0.09・high +0.06 にして晴れ間を広げ、雲の陰の色を明るく（×1.55/1.42/1.22）、天頂を少し濃い青に。夕暮れ・夜・雨雪の曇天は元のまま。`sky.e2e.ts` が照合する `SKY_GLSL` は元の空を保持する。
- 日光（`lighting.ts`）：昼の重み×晴れの割合で、日光とV9（寝椅子の陽だまり）を `CLEAR_DAY_SUN` = 2.2倍にし、露出を `CLEAR_DAY_EXPOSURE` = −0.1段。照度・反射プローブは変更しないので、日光の比率が上がる。雨雪の重みに応じて元の値へ戻る（その後は従来どおり消える）。
- 最初の 1.6倍・−0.2段では、逆光の視点で日向がほとんど増えず全体が暗くなっただけだったため、2.2倍・−0.1段へ。

## 確認

- `garden-details.e2e.ts`（標準画質・1280×800・動作抑制）の昼3ステージを `../garden-variation/` と比較。`diff-after.png` は右列が明るさの差（灰色が不変、明るいほど増加）。草地・石・デッキ・樹冠の日向が明るくなり、丘に木の影が出た。日の当たらないサウナ室内は露出の分わずかに暗い。白飛びは目視で見られない。
- `auto-lighting.visual.ts` の外気浴 0・12・13.5・15・30分と `weather.visual.ts` の雨の昼（`transition.png`）：昼→夕暮れ→夜はなめらかで、雨の昼は従来どおり。
- 型検査、55ファイル360単体テスト、Lint、整形、本番ビルド成功。Chromeで `sky`（Cyclesの空との照合）・`garden-details`・`season`・`scene-no-hdr`・`scene-shader` の31件、天気・自動時間帯の撮影2件成功。

## 範囲

Cyclesとの照明比較（`cycles_tone_stats.py`）の昼の値は意図して変わる（再計測していない）。反射プローブの空は元の雲のままなので、鏡像のない端末の水面の映り込みは曇り気味。GPU時間は変わらない見込み（uniformと定数のみ）だが未計測。実機・全周撮影は未実施。
