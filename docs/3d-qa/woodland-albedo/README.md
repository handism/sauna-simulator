# 林の葉の色と光沢（2026-10-20）

## 課題

- 外気浴から見る林（10〜44m）の樹冠が、日なたの上部まで暗い葉の粒と青灰色の面に見えた。
- 昼の既定視点の樹冠上部の画素は3群に分かれた。
  - 空：sRGB（166, 180, 199）
  - 暗い粒：（39, 50, 46）。濃い緑の葉
  - 中間：（103, 121, 122）。葉と空が混ざった青み

## 切り分け

- 影：林のカード（`V6 woodland leaf`）だけ影を受けない一時ビルドでも、暗さ・青みはほぼ同じだった。影は主因ではない（`diag-noshadow.png`、ローカルのみ、上が現行・下が影なし）。
- 材質：元の色はリニアの緑0.065〜0.157。手前のモミジ（0.19〜0.32）の半分以下で、粗さは0.54。
  - 暗い拡散色に空の光沢（反射プローブ）が乗り、青灰色に見えていた。
  - 実際の樹冠は葉を透過・多重散乱した光で、1枚の葉の反射率より明るく緑に見える。元blendの葉に透過はない（`foliage.ts`）。
- 一時ビルドで2案を撮影した。
  - A：粗さ0.8だけ。青みが減るが、全体は暗いまま。
  - B：粗さ0.8＋色1.7倍。日なたが緑の塊として読めた。Bを採用。

## 変更（元blendにない補正）

- `crownNormals.ts` の `WOODLAND_ALBEDO`（1.7）・`WOODLAND_ROUGHNESS`（0.8）。
- `roundWoodlandCrowns()` で、林のカードの材質に適用する。
  - 常緑樹の分割（`evergreenWoodland.ts`、色×(0.58, 0.7, 0.6)）より前なので、常緑樹も加工後の色を引き継ぐ。
  - 季節の色の登録（`season.ts`）より前なので、夏の色は加工後の色になる。春・秋は固定の色表のまま（粗さは変わる）。
- 本体GLBの `V6 woodland leaf 0〜4`（カードでないもの）、頭上の葉、庭の葉は対象外。

## 範囲

- 空を背にした樹冠の輪郭が葉の粒の集まりに見えること、奥の森の帯の平面感は残る。
- 夕暮れ・夜の林は暗いまま（照明に支配されるため、変化は小さい）。
- 費用は計測していない（材質の値の変更だけで、プログラムは変わらない）。
