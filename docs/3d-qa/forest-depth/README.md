# 中景と遠景の森のつなぎ（2026-10-15）

## 変更

54m先の森が一枚の帯で、手前の林との距離差が乏しく見えていた。`farForest.ts` に47〜51mの樹冠73個を間欠的に重ねる。奥の樹冠を1.1m低くした形で、山の稜線を覆う高さにはしない。手前は暗く霞を薄くし、54mの帯との前後差を作る。季節色・時間帯・曇りの変化と輪郭のほつれは共用する。

同じ1メッシュ・材質へ結合し、森の描画数は1回、追加テクスチャなし。森の三角形は5,492→7,828（+2,336）。GPU時間・実機FPSの計測はしておらず、費用ゼロや性能改善とはしない。元GLB・照度／反射プローブ・既定2Dの経路は変更していない。

## 画像確認

[前後一覧](comparison.jpg) は左が変更前、右が変更後。画像はローカルのみ。Chrome channel、標準画質・固定解像度・1280×800・DPR1・動作抑制。`garden-details.e2e.ts` で変更前後各9枚を取得した。水風呂の昼、外気浴の夏秋冬・夕暮れ・雨の一覧を目視し、木々の隙間に暗い樹冠の重なりが増えたこと、冬の雪原・夕暮れで新しい黒抜けがないことを確認した。大きな構図変更ではなく、林の隙間の奥行きを補う変更。

このテストはUI演出・タイマーを含む通常のスクリーンショットで、位相固定・再撮影一致やCyclesとの画素比較ではない。雨の画像は春・夜で、動作抑制のため雨粒の動きは確認していない。全画像・全方向の画質合格を意味しない。
