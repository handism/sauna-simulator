# 中景の草地のむら（2026-10-12）

## 課題

外気浴・サウナから見える起伏の苔地（`Mossy woodland terrain`、材質 `V9 | layered living moss`）は、元のノイズ色が約1m周期のため、数m先では画素より細かくなって平均の一色に寄り、庭と林のあいだが平板に見えた。

## 変更

- `surfaceDetails.ts` に `ground` を追加し、`V9 | layered living moss` と `V3 | moss and woodland earth` に適用。入口脇の `V7 | shaded moss garden` と砂利は対象外。
- ワールド座標で、約5〜14m周期の乾いた黄緑／湿った濃緑の斑（元の色を中心に釣り合わせる）、高い所ほどやや乾く傾き、頂点のワールド法線から求めた急斜面の土色、約0.6m周期の草むらと数cm周期の草の筋（画素より細かくなると平均へ）を色に掛ける。粗さのむらと微小バンプも少し加える。
- 追加テクスチャ・sampler・形状なし。雪は後から色を覆う。元GLB・ベイク済みプローブは変更しない。
- 暗い緑はAgXのトーンマッピング後に差が縮むため、最初の振れ幅（乾き×1.28）では画面平均の差が0.66/765で見分けられなかった。地面を一時的に赤くして適用範囲を確かめた（`debug-target-red.png`）後、乾き×1.7・湿り×0.6〜0.76へ強めた。

## 確認

- `garden-details.e2e.ts`（標準画質・1280×800・動作抑制）の撮影を `../deck-stone/` の同名画像と目視比較。外気浴の昼・春・秋・夕・夜・雨・冬、サウナの昼。中景に乾いた斑と濃い斑が出て、冬は雪が覆う。等倍で縞・格子状のモアレなし。
- `surface-details.visual.ts`（高画質・DPR 2）の9枚で、デッキ・石の近接は変化なし。
- 型検査、55ファイル357単体テスト、Lint、整形、本番ビルド成功。Chromeで `garden-details`・`season`・`scene-no-hdr`・`scene-shader` の30件成功。
