# プローブ補間元の可視性診断（2026-09-24）

**診断のみ。可視性による重み付けは製品に採用していない。** 前回の14測定点で、現行の法線オフセット0.5格子の補間元を追跡した。元blend・fixture・照度プローブのハッシュは `visibility.json` に記録。

`probe_sampling.py` はグリッドの選択・8隅の重み・符号付きSH評価を返す。SHは各隅ではなく補間後にグリッドごとに0へクランプする。Blenderの評価済み形状に対し、測定面から法線方向へ2cm／5cmずらした点から各プローブまでレイを飛ばす。遮られた隅の重みを0にし、残りの重みをグリッド内で正規化する候補をCPUだけで計算した。

以下は2cm位置、Rec.709輝度で「補間値／前回の面近傍パノラマ余弦積分」。1に近いほどこの点の測定値に近い。

| 点 | 遮られた重み | 昼：現行→候補 | 夕：現行→候補 | 最初の遮蔽物 |
| --- | ---: | ---: | ---: | --- |
| サウナ床 `02-floor-dark` | 0% | 1.335→1.335 | 1.024→1.024 | なし |
| 寝椅子付近 `04-400-290` | 34.1% | 0.670→0.914 | 0.615→0.820 | V9 weighted linen towel 1 |
| 地面 `01-ground-dark` | 11.9% | 1.735→1.289 | 1.806→1.360 | Woodland fern.033 |
| 地面 `05-ground-dark` | 30.8% | 1.233→1.174 | 1.321→1.258 | V8 moss garden anchor stone.002 |
| 草付近 `05-270-300` | 99.959% | 0.720→1.301 | 0.717→1.277 | Woodland fern.078 / .033 |

- 寝椅子付近は5cmでも同じ34.1%が遮られ、昼0.672→0.918、夕0.618→0.825。見えない方向の低照度プローブを混ぜることが、この点の不足に関係している。
- サウナ床は全補間元が見えるため、可視性だけでは昼の過剰は解消しない。面上照度の追加診断・ベイクなど、別の候補が必要。
- `05-270-300` は2cmでは残った重みが0.000408しかなく、正規化でごく小さい寄与を増幅する。5cmでは残りが0.680になり、昼0.712→0.924・夕0.706→0.916。硬い二値判定をそのまま導入すると、位置依存の不安定さが懸念される。
- 地面の改善も残差があり、前回の裏面比率・面近傍測定のばらつきは解消していない。全14点中、遮蔽が検出されたのは4点。残り10点は変わらない。

## 限界と次の判断

これは**形状との線分交差**であり、光の透過率ではない。ガラス・葉も遮蔽物に数える。`hide_render` とカメラ不可視のオブジェクトは飛ばすが、依存グラフはviewport評価であり、レンダー専用のモディファイア・可視性との差は含まれうる。配信プローブの無効点を埋めた元の位置情報も残っていない。ブラウザへ簡略化した形状との差、全画面の画質・GPU負荷は測っていない。

次は寝椅子付近を対象に、距離情報を使った滑らかな可視性の重みと、残存重みが小さい場合の安定した扱いを検討する。サウナ床は別に面上の照度を評価する。直接光・反射への一律AO乗算は行わない。
