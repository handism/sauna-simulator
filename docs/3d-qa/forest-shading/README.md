# 奥の森の方位に応じた陰影（2026-10-16）

## 変更

基準は `717cbfb`。`farForest.ts` の奥54mの帯に、シーンの固定日光方向（`lighting.ts` の −0.556, 0.6178, 0.556）に対する樹冠の丸い肩・上面の近似法線から明暗を付ける。従来は全方位の樹冠で同じ左肩が明るかった。側縁には弱い暗がりを残し、隣の房との区切りを付ける。実際の樹木間の遮蔽・影・再ベイクではなく、既存の時間帯・曇天の色乗算を受ける固定方向の形状表現。

手前の立体葉群は `gardenBand=0` として従来の陰影を維持する。帯は1。形状・輪郭discard・細部ノイズ・霞・季節色の仕組み・材質数・描画パスは維持。新たなテクスチャ・光源・影パスなし。GLB・照度／反射プローブ・2D既定と復帰経路は変更しない。

`geometry.json` は独立した前後のモジュールを生成し、四季すべてで既存の全属性（位置・色・輪郭・奥行き等）のSHA-256一致を照合した結果。82,356頂点・27,452三角形を維持。帯16,656頂点／立体葉群65,700頂点を区別するfloat属性を1つ追加し、属性配列は329,424 bytes増える。ドライバーのGPU総メモリ量ではない。

## 再実行

変更前後を別ディレクトリに配置し、同じ依存関係で `bun run build`。各版で次を変更前→後→後→前の順に実行する。検証専用設定はポート4293・Chromeの `--disable-audio-output` のみを上書きする。製品の音は変更しない。

```sh
SHIMMER_HEADING_STEPS=20 SHIMMER_FIXED=1 SHIMMER_RATIOS=1.5 bunx playwright test --config review.config.ts e2e/resolution-shimmer.visual.ts e2e/scene-survey.visual.ts --reporter=json
python3 scripts/summarize_visual_survey.py <report.json> <survey-output>
python3 scripts/summarize_resolution_shimmer.py <report.json> <capture-dir> <shimmer-output>
FRAME_COST_REPEAT=3 FRAME_COST_VARIANTS=product bunx playwright test --config cost.config.ts e2e/forest-cost.gpu.ts --grep 'frame cost' --reporter=json
```

負荷用の `forest-cost.gpu.ts` は `frame-cost.gpu.ts` の各ステージで右20キー分を向くコピー。各版の初回は `warmup,product` を使用。計測中は撮影・画像解析を同時に走らせない。画像はローカルのみ、JSONと本記録をGit管理する。

## 限界

固定方向の近似陰影であり、森の帯を完全な立体樹木へ置き換えたものではない。冬の灰褐色の塊、季節ごとの間接光・反射プローブの差は残る。全周の離散撮影を全角度の目視合格・実時間のちらつき・実機FPSの保証とは扱わない。
