# 林の樹冠の空の映り込み（2026-10-21、採用）

外気浴・水風呂から見る林（10〜44m）の樹冠が、昼の日なたまで青灰色に見え、手前のモミジ（黄緑）と別の素材のように浮いていた。

## 切り分け

外気浴の昼の既定視点で、樹冠上部の画素の色相（sRGB、明るさ順の30%・50%点）は145〜148°（青緑）、葉の材質色（`V6 woodland leaf`）は約100°（黄緑）。一時ビルドで、林のカードの反射プローブの映り込み（`indirectSpecular`）だけを外すと、上部の色相は106〜113°、彩度は0.19〜0.36→0.47〜0.51になった。縁の持ち上げ（`LEAF_RIM`）を外しても青みは残った。主因は空の映り込み。

暗い葉（線形の緑0.11〜0.27）の上では、粗さ0.8でも空の映り込みが光の大半を占める。反射プローブは開けた空を持つが、実際の樹冠の内側の葉の鏡面方向はほとんど他の葉に塞がれる（鏡面の遮蔽）。

## 変更（元blendにない補正）

- `crownNormals.ts` の `WOODLAND_SPECULAR`（0.25）。`SUI_CROWN_TINT` の材質（林のカードと常緑樹の複製）の `aomap_fragment` で、`reflectedLight.indirectSpecular` に `mix( 0.25, 1, suiIrradianceEvening )` を掛ける。昼だけ効き、夕夜は従来どおり。
- 日光は元から光沢を持たない（`lighting.ts`）。スポット光の鏡面は変えない。プローブ・材質・描画パス・テクスチャは増やさない。

候補（[値](values.json) の `hue`・`motion.rejected`、比較画像はローカルの `variants-day.png`・`variants-evening.png`・`outer-shell-kept.png`、上から変更前・候補）：

- 映り込みなし：0.25倍と見た目の差は小さく、夕暮れの樹冠が平らな黒の影絵になった。
- 昼夕とも0.25倍：夕暮れでカードの面ごとの灰色の光りは消えたが、制御した見回しの残差が夕暮れで面の99百分位1.11〜1.17倍に増えた（空を背にした影絵が暗くなり明暗差が増えた）。不採用。
- 外殻（`LEAF_SHELL_LEVELS`）のカードだけ映り込みを残す：残差の増分は半分程度に減ったが、樹冠の上部が青灰色に戻った（中央値の色相175°）。不採用。

## 確認

変更前は `97eb722` の実ビルド（dist）。Chrome 155.0.8059.85。値は [values.json](values.json)。

- 静止画（`forest-leaf-masses.visual.ts`、1280×800・標準DPR1・固定解像度・動作抑制、3ステージ×昼夕夜×水平3方位＋外気浴の春秋冬の昼、30枚×前→後→後→前）：全4件成功、ページ／console errorなし、同じ版の再撮影差は全画像で0。変化は林の樹冠だけで、昼はΔE>2の画素が1.8〜11.6%。夕夜の18枚は最大ΔE 0.9（1枚の1画素）以外は一致。外気浴の昼の1画素だけ、縁の持ち上げ（暗い画素の輝度を空気へ合わせる）で黄緑の点になった（ΔE 85、30枚で1画素）。
- 制御した見回し（`resolution-shimmer.visual.ts`、1200×800・DPR1.5・段1.5固定・`&camera=review`・既定視点、3ステージ×昼夕）：昼の回転補償残差の比は画素1.020〜1.040・面1.034〜1.056・面の99百分位1.049〜1.084、夕暮れは1.000。同じ版の再撮影は1.000。樹冠が空より暗い緑になり、葉の縁の明暗差が増えた分と考えられる（切り分けていない）。知覚的なちらつきの合否ではない。
- 描画間隔（`forest-back-crowns.gpu.ts`、標準DPR1・右20キー・描画3回反復、ABBA 2組）：0.996〜1.003倍。
- 単体テスト：組み立てた標準材質の断片シェーダーで、`RE_IndirectSpecular` の後・`totalSpecular` の前に掛かること。
