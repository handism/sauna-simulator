# 水の到達先の鏡面を製品のプローブで近似できるかの診断

前回の[局所HDR色参照](../water-radiance/README.md)で、鏡面は別方向の画像から使い回せないと分かった。今回は鏡面だけを「実際の最後の光線方向」で製品の反射プローブから近似する方式を、Cyclesのpathの鏡面と比べる。**CPU上で製品の数式を再現した点の診断であり、ブラウザ描画・GPU費用の検証ではない。製品・配信データは変更していない。暗い帯の修正は未完了。**

## 測定条件

- 入力は前回の `radiance.json`（19点×昼夕、16384サンプル・2seed平均）。Blenderは再実行していない。
- 製品の水中の面の鏡面を `diagnose_water_specular.py` がNumPyで再現する：配信中の `reflection.bin` の水中グリッド（`reflection.ts` の粗さによる帯域減衰、threeの支配方向）× three 0.186の split-sum（`DFGLUTData.js` の16×16 LUTを双線形で読み、`computeMultiscattering` と金属度の混合を再現）＋多重散乱項×照度プローブ/π。材質値は配信GLBから読む（タイル：F0 0.04・粗さ0.3、石：`KHR_materials_specular` 0.56・粗さ0.79、青銅：金属度0.72・粗さ0.3）。水中では日光・スポット光を当てない（`DRY_ONLY`）ため直接光の鏡面はない。
- 幾何法線のみ。石の法線マップ、微分による粗さの加算、水面のFresnel・吸収は含めない。両面材質は視点側の面で評価する。
- 候補：`omit`（鏡面なし）、`probe_camera`（元カメラからの未屈折の視線。現行の製品）、`probe_path`（最後の光線方向の視線）、`hann_path`（同、帯域1・2にHann窓0.75／0.25を追加してリンギングを抑える）、`irradiance_path`（反射プローブの代わりに照度/πを支配方向で読む）。
- 誤差は前回と同じくpath CombinedのRGB合計を分母とするRGB絶対差の合計。`hybrid` は拡散＋発光を真上（真上から見えない壁は面法線方向）の参照から取り、候補の鏡面を足した合計の誤差。
- 分解：Cyclesの鏡面は `(GlossDir+GlossInd)×GlossCol`。threeの結果をアルベド（単散乱＋多重散乱）と実効的な入射光（鏡面÷アルベド）に分け、それぞれのRGB合計の比を `GlossCol`・`GlossDir+GlossInd` と比べる。
- 点12（石の壁、側面全反射）は水面より上（glTF y=0.844m、`WATER_BOX` 外）で、製品は水中グリッドを使わないため集計から除外（36件）。

## 結果

pathの鏡面の2seed差は中央値3.4%・90百分位16.7%・最大30.6%（同じ分母）。

| 候補 | 鏡面の誤差 中央値／90百分位／最大 | 拡散参照＋鏡面の合計誤差 | 鏡面の比 | アルベド比 | 入射光比 |
| --- | --- | --- | --- | --- | --- |
| omit | 39.9% / 85.5% / 93.9% | 40.2% / 83.5% / 92.9% | 0 | — | — |
| probe_camera（現行） | 27.1% / 101.0% / 492.4% | 28.1% / 100.7% / 493.1% | 0.19 / 2.26 / 8.23 | 0.78 / 5.52 / 7.58 | 0.48 / 1.32 / 3.15 |
| probe_path | 29.1% / 113.9% / 353.5% | 29.3% / 112.9% / 359.6% | 0.78 / 4.09 / 6.15 | 0.95 / 0.99 / 0.99 | 1.03 / 4.15 / 6.49 |
| hann_path | 23.2% / 161.5% / 303.9% | 28.1% / 164.3% / 306.5% | 1.16 / 4.11 / 4.96 | 0.95 / 0.99 / 0.99 | 1.20 / 4.35 / 5.09 |
| irradiance_path | 24.0% / 156.8% / 299.8% | 28.9% / 159.6% / 302.4% | 1.15 / 3.97 / 4.90 | 0.95 / 0.99 / 0.99 | 1.20 / 4.20 / 5.04 |

比は中央値／90百分位／最大。昼夕・材質別の値は [specular.json](specular.json) の `by_scene`・`by_material`、点ごとの項（プローブの放射輝度・照度・DFG・N·V）は `rows`。

- **BRDFは合う**：最後の光線方向で評価すると、threeのアルベドは `GlossCol` の0.95倍（タイル0.92・青銅0.97、90百分位0.99）。石だけ0.64〜0.87倍で、N·Vが0.06〜0.16の壁で低い。threeは `KHR_materials_specular` でF90も0.56倍にするが、元のSpecular IOR LevelはF0だけを変えると考えられる（未検証）。元カメラ方向ではFresnelの角度がずれ、アルベド比は0.19〜7.58倍に広がる。
- **入射光が合わない**：誤差の大半はプローブ側。昼の `probe_path` の入射光比は中央値0.03：水中グリッドの昼の係数は強い方向成分を持ち、L2のリンギングで反対側（glTFの−X・−Z）が負になり0にクランプされる。水中の到達点の反射方向はちょうどその範囲に入る。水中グリッドの反射は照度と同一の係数（[既知](../water-probes/)）。
- Hann窓・照度/πは0クランプを避け昼の中央値を1.5倍前後にするが、90百分位は4倍を超える。ローブが広すぎ、方向ごとの差を表せない。
- 材質別では青銅（水底の基壇、18件）がどの候補でも中央値60〜78%と最悪で、プローブ由来の候補は入射光を1.7〜2.1倍に見積もる。タイルはプローブ由来の候補で中央値13〜14%（omit 20%）、石は7〜9%（omit 10%）で、いずれも2seed差（中央値3.4%）を大きく超える。
- 夕は `probe_path` の中央値21%（omit 56%）と改善するが、90百分位は100%前後。
- **結論**：どの候補も雑音の水準に届かず、鏡面の近似方式としては採用しない。最後の光線方向で視線を与えることはBRDFには有効だが、L2の水中プローブは到達点の入射光の方向分布を表せない。現行製品（`probe_camera`）の水中の鏡面は昼ほぼ0で、Cyclesより鏡面分（Combinedの中央値33%）だけ暗い可能性がある。

## 次の候補

入射光を方向ごとに得る必要がある。候補は、到達点から支配方向へ1本レイを追った先（水面の裏側の全反射・水越しの空・向かいの壁）の放射輝度を参照すること。Cyclesで到達点の反射方向の到達先を分類し、その先が既存の拡散＋発光の参照（真上／面座標）や空色で表せる割合を測る。青銅の基壇は面積と画面寄与を確認してから扱う。

## 再実行

```sh
python3 scripts/diagnose_water_specular.py docs/3d-qa/water-radiance/radiance.json --out docs/3d-qa/water-specular
python3 -m unittest discover -s scripts -p 'test_*.py'
```

`node_modules/three` のDFG LUT、`public/models` の反射・照度プローブ（ヘッダーのハッシュを検査）とGLBを読む。入力・GLB・プローブ・スクリプトのハッシュを `specular.json` に記録する。
