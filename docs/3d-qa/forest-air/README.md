# 林と遠景の空気遠近（2026-10-20）

## 変更

- `aerialPerspective.ts`：照度プローブを使う標準材質（`SUI_IRRADIANCE` かつ `STANDARD`）の出力を、トーンマッピングの前にカメラからの距離に応じて空気の色へ混ぜる。割合は `1 − exp(−max(0, d − 20) / 250)`（44m 約0.09、54m 約0.13、72m 約0.19）。20m以内（室内・水風呂・デッキ・周りの草地）は変えない。
- 空気の色は山並みの霞色（`gardenDetails.ts`、時間帯・曇天で補間）と同じで、毎フレーム `suiAirColor` へ写す。
- `farForest.ts`：遠い森の帯の固定の基礎霞（0.025〜0.08）を同じ距離の式に置き換えた。裾の霧の項は維持。
- 材質・プログラム・テクスチャ・描画パスは増やさない（既存のプログラムのソースだけが変わる）。体積散乱・太陽方向の散乱・光の減衰はない。

## 調整の経緯

| 設定 | 結果 |
| --- | --- |
| 開始8m・230m | 林の緑が灰青に抜け、夕夜は手前の丘が淡い帯になった |
| 開始8m・300m | 林はまだ灰色寄り |
| 開始20m・250m（採用） | 昼は林と奥の森の重なりが分かれ、夕夜の丘は暗いまま |

樹冠の色味を青→緑寄りにし、内側の陰を浅く（0.6→0.7）する案も試した。しかし変更前ビルドとの差は最大8階調（画素の0.1%）で、目で分かる差がなかったため採らなかった。

## 検証

- `e2e/forest-air.visual.ts`：同じビルドで、ブラウザ内の `// SUI_AIR_CONTROL`・`// SUI_FAR_AIR_CONTROL` だけを変更前の式へ戻した対照と、ABBAの順に撮影した（3ステージ×3方位×昼夕夜＋秋・冬・雨、1回30枚、計120 PNG）。標準画質・DPR1・1280×800。
- 同じ条件の再撮影の差は全30枚で0画素。前後で8階調を超えて変わった画素は0〜9.7%（外気浴の正面の昼で最大）。差分の一覧は `diff.txt`（ローカル）。
- `FOREST_REVIEW=visual FOREST_BASELINE_DIST=<HEADのdist>` で `66cf613` の製品ビルドも撮り、対照（空気なし）と一致することを確かめた（8階調超0〜0.01%）。
- 目視：外気浴の昼夕夜、水風呂の昼、サウナの窓越し、雨・冬（`totonou-*.jpg`・`grid.jpg`、ローカル）。
