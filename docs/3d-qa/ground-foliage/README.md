# 手前のシダ・草と地面のなじみ

2026-10-19。改善候補1への承認範囲。遠景の森・TAA・水・室内照明は対象外。

## 変更

- `fernShape.ts` が庭GLBの `V3 | fern 0〜2` だけを読み込み時に加工する。独立した2三角形の各葉で共有する対角線の端点（付け根と先端）を維持し、横幅を95%に、左右の縁をその幅の0.45〜0.75倍だけ下へ反らせる。頂点数・インデックス・材質数は変えず、法線と境界を再計算。未対応の共有形状は全体を変更せず、一度だけ加工する。
- シダの既存ノイズ色のRGBを0.85倍にして明るさを抑える。新しいシェーダー処理・画像・材質・描画パスはない。元のGLBと照度／反射プローブは維持するため、焼き込みの遮蔽は元形状の近似。加工した形状は影・深度・薄雪にも共通。
- `meadowGrass.ts` の草は数m周期の密度のまとまり（従来密度×0.44〜1）を付け、草丈と色の振れ幅を抑える。枯れ色の割合を18%→7%、先端の明るさを弱め、地面から白い線が飛び出す印象を減らす。既存の石・デッキを避ける配置、固定乱数、季節色、解放処理は維持。
- カメラ・音・蒸気・2D・配信GLBは変更しない。

## 形状の確認

`geometry.json` は配信庭GLBをMeshopt展開して加工した結果。3材質の全105,984頂点・52,992三角形に適用し、三角形数は同じ。最大頂点移動は約6.7cm、非有限値／非単位法線は0。法線は元の8bitからfloatへ変わるので、シダの法線バッファは増える（GPU全体の実確保量は測っていない）。

草は21,138→15,009枚（各3三角形）。外気浴昼の主描画は786,545→768,158三角形、描画102回・テクスチャ36・ジオメトリ156は同じ。これは形状数・資源数の診断であり、速度改善・GPU時間・実機FPSの結果ではない。

## 比較と検証

`ground-foliage.visual.ts` は変更前ビルド→変更後→変更後→変更前で撮影し、HTML・動的JSも各ビルドから配信する。読み込んだJSのハッシュを照合する。Chrome 155.0.8059.80・標準DPR1・固定解像度・動作抑制・晴れで、3ステージ×昼夕夜×初期／見下ろしの18視点、外気浴の春秋冬と390×844／844×390の5視点（1回23枚）。

`comparison.json`：4撮影テスト成功、計92 PNG。各方式の再撮影差は1 RGB階調超で0〜1画素（1画素の最大差15階調）。変更前後は83〜67,963画素で、画質向上率ではない。外気浴の昼・見下ろし・夜・冬・縦長の原寸と3ステージの比較一覧を目視し、草の明るい線が減り、シダの縁に陰影が付くことを確認。見た範囲に大きな欠けや発光なし。全92原寸・全周・連続動作の合格とはしない。比較画像は `comparison.jpg`（上：前、下：後）、各ステージの `*-comparison.jpg`（左：前、右：後）。画像はローカルのみ。

変更前は `b8bed7283cb2467fc63d04998825effe9685a245` の製品ビルド。2D入口JS 230.92kB（gzip73.80kB）、遅延3Dチャンク907.32kB（gzip250.78kB）。既存850kB警告は継続。

最初の上向きの浅い折りと葉幅86%の候補は薄く見えたため不採用（`preliminary/` の画像のみローカル保存）。採用候補は下向きの反りと95%の葉幅。

連続見回しのちらつき・残像、実時間の動画、実機・実Safari・高画質・全季節天気の組み合わせ、純GPU時間は未確認。

## 再実行

変更前のコードで `bun run build` し、distを別フォルダへ保存してから変更後をビルドする。変更前distの場所を明示し、同じテストでABBA比較する。

```sh
bun run build
FOLIAGE_BASELINE_DIST=/path/to/before-dist \
  bunx playwright test --config playwright.visual.config.ts ground-foliage --reporter=json > /tmp/ground-foliage.json
bunx playwright test garden-details season scene-lifecycle scene-no-hdr --reporter=json > /tmp/ground-foliage-regression.json
```

`FOLIAGE_QUICK=1` は外気浴・昼の2視点だけを前後撮影する。比較用環境変数なしでは変更後の23枚のみ。画像は `test-results/visual/ground-foliage.visual.ts-ground-foliage-*/` に出るので、次のvisual実行前に退避する。
