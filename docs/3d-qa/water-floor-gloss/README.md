# 水中の反射プローブからV9を除く（2026-09-27）

[水風呂の床の照度](../water-floor-irradiance/README.md)の残件「昼の見下ろしは全体でまだCyclesより+3.4 L*明るい（照度以外か格子の粗さ、未切り分け）」を切り分けた。主因は**水中の反射プローブに入り込んだV9の円盤**で、焼き込みを直した。

## 切り分け

測定値は [measurements.json](measurements.json)。元blend（SHA-256 `f1ee4ddd…`）、Blender 4.5.11 LTS、昼の水風呂の見下ろし（見出し1）640×400・512サンプル。ブラウザは作業用コピーのビルドで、トーンマッピングを x/(1+x) に置き換えた線形の撮影と、成分を切り替えるフラグ（水面の反射なし・水の底面の部分反射なし・水面なしでアルベド／拡散／光沢／発光だけ・光沢なし）を使った。

1. **場所**：CyclesのL*で区切ると、差はタイルの面全体（L* 30〜50の76%の画素で+2.8〜2.9）と目地（L* 20未満の6%で+11.3）。
2. **水面の反射か透過か**：Cyclesの水面のGlossy/Transmissionパスで分けると、反射はCycles 0.0499・ブラウザ0.0511で一致。差はすべて透過（水越しのタイル）にあり、Cycles 0.0994・ブラウザ0.161。
3. **水の底面の部分反射**：ブラウザの透過の差のうち+0.040は底面で映るV9の円盤（画面の1.1%）で、線形の平均を大きく動かすが、白飛びの範囲なのでL*にはほとんど効かない。円盤以外の底面の寄与は前後で一致（Cyclesは底面をタイルの下へ下げた描画との差）。
4. **タイルの成分**：Cyclesの水面の法線で視線を屈折させてタイル面まで延ばし、水をカメラから隠した描画の同じ位置と画素ごとに対応させた。照度はCycles 1.263・ブラウザ1.260で一致、アルベドはブラウザが+6%、タイルの光沢は直接見た場合でCycles 0.0187・ブラウザ0.0283。水越しの透過率は、発光（疑似コースティクス）だけで比べるとCycles 0.877・ブラウザ0.869で一致。
5. **水越しのタイルの光沢**：タイルの下地を黒にした描画で光沢あり／なしの差をとると、水越しの光沢はCycles 0.0114・ブラウザ0.0243（2.1倍）。光沢を除くとブラウザ／Cyclesは1.061倍で、アルベドの差だけが残る。

### 光沢が明るすぎた原因

ブラウザの水中の光沢は、水中グリッドの反射プローブ（L2）×three.jsの分割和の項そのもの（8点でCPUの再現とブラウザが一致）。そのプローブの反射方向の放射輝度が0.3〜1.4で、タイルの点に置いた光沢の受光球（タイルと同じGGX・粗さ0.3・Specular 0.5、下地は黒）から逆算した値の3〜4倍だった。

同じ点で焼き込みと同じ正距円筒パノラマを描き、V9の透過可視性を切り替えると、L2の反射方向の値はV9ありで0.29〜1.41、なしで0.07〜0.15。反射の焼き込みはブラウザがハイライトを描くV9と夕暮れの暖色灯5灯をカメラから隠していたが、水中のパノラマはカメラレイが水面で屈折した後の**透過レイの可視性**で光源を見る（カメラの可視性の切り替えは効かない）ため、V9が入っていた。950Wの円盤はL2で全方向ににじみ、V9から遠い方向の光沢まで明るくしていた。

## 方式

`bake_irradiance_probes.py --reflection` の水中グリッドだけ、パノラマを描く間、反射から除く光源（`in_panorama` が偽）のうち透過に可視なものを透過レイからも隠す。昼はV9、夕暮れは `V10 lounge dusk fill`・`V10 path grazing light 1/4/7`・`V10 specimen uplight`。隠した光源は `reflection-report.json` の `hidden_from_transmission` に記録する。`--grids water` で水中グリッドだけ焼き直した（昼夕で約1分）。製品のシェーダー・照度プローブ・水上の反射グリッドは変更なし。

水中グリッドの上向きの値（RGBの平均）は昼 (1.88, 1.70, 1.29)→(0.27, 0.30, 0.26)、夕 (0.087, 0.102, 0.120)→(0.070, 0.090, 0.113)。

ブラウザは水中に光源を直接当てない（`DRY_ONLY`）ので、これでV9の光沢は水中のタイルに乗らない。Cyclesでは水越しの光沢0.0114のうちV9の光源グループが約0.0025（Specular IOR Level 0との差、拡散側の補償を含む）で、V9の当たるタイルの局所的なハイライトになる。

## 残る差

- 平均は合ったが明暗の幅が縮んだ：見下ろしでCyclesのL* 40以上のタイル（V9の当たる明るい所）は変更前+2.9→後−1.6、目地（L* 20未満）は+11.3→+7.8。V9のタイルの光沢（Cyclesで約0.0025）がなくなった分と、目地のアルベド（ブラウザ0.083・Cycles 0.032、テクスチャの縮小で目地がタイルと混ざる分を含む）。
- タイルのアルベドがCyclesより6%高い。水越しの光沢の不足（0.0031対0.0114）を相殺しているため、アルベドだけを直すと暗くなる。
- Cyclesでは、カメラが水面越しにタイルを見るとV9の寄与が発光だけの透過率（0.877）よりさらに約1割減る（V9の光源グループで0.783、クランプを外しても0.792）。カメラ光線が先に屈折を通るかどうか（パスの状態）で変わり、カメラの前に屈折板（IOR 1.0・粗さ0.018、カメラにだけ可視）を置いた受光球ではV9の当たる点の光沢が約半分になった。照度プローブの拡散球はカメラから直接見ているので、V9の照度を約1割多く持つ可能性がある。未対応。
