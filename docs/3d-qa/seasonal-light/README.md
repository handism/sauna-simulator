# 季節ごとの間接光・ぼけた反射（2026-10-17）

## 変更

基準は `aafaa19`（奥の森の19樹冠を含む）。元の夏の照度／反射プローブは保持し、`seasonalLight.ts` と `seasonal-light.json` が季節・4グリッド・昼夕夜・照度／反射の種類ごとのRGBエネルギー比をuniformで渡す。シーンごとに補正してから時間帯を混ぜる。夏は全成分1。方向ごとのSH係数と遮蔽は夏のままで、季節ごとの方向性・遮蔽を全面的に再ベイクしたものではない。

飛び石の夕夜の局所照度と、その場の粗いプローブから差し引く照度にも同じ比を掛ける。水底の反射プローブから取り除く光沢専用灯のSH成分も対応する昼夕夜の比を掛ける。解析的な直接光は従来のまま。水面の平面鏡像は既存の季節の材質・可視性を映す。

新たなテクスチャ・sampler・描画パス・モデル取得はない。追加のRGB uniformは24個。季節変更と温め中の各draw直前に既存のuniformへ値を反映し、モデルとセッションは再生成しない。

## Blenderでの測定

`bake_irradiance_probes.py -- --seasonal --out <dir>` から `bake_seasonal_probes.py` を呼ぶ。元blendは保存せず、実行前後のSHA-256を照合。既存プローブと同じ入力 `d7969b95...`、Blender 4.5.11、室内4点・中庭6点・外周8点・水中2点、四季×昼夕夜×照度／反射。パノラマ64×32・64サンプル、seed7319。水中照度は既存の球受光器（6面・256サンプル）を使う。最終実行290.8秒で成功。

春・秋はブラウザの葉のパレットに合わせ、秋は地表を枯れ色にする。冬は広葉樹を落葉させ、林の約35%を常緑として残し、上向きの対象面へ平均的な雪の色を重ねる。元シーンを使う近似で、ブラウザの細かな吹きだまり・葉カード分割・後から足す草花とは一致しない。

各グリッドの最後の1点を補正の当てはめから除き、残りの点のL0 RGB平均比を0.6〜1.8に制限する。除外点でのRGB絶対差平均（線形SH L0）は以下。画像の画質向上率ではない。単一seed・少数位置の局所的なエネルギー校正で、全面的な照明の正しさを保証しない。

| 季節 | 照度：前→後 | 反射：前→後 |
| --- | ---: | ---: |
| 春 | 0.00531→0.00336 | 0.00349→0.00170 |
| 秋 | 0.00479→0.00316 | 0.00467→0.00172 |
| 冬 | 0.21108→0.12523 | 0.26950→0.14265 |

春・秋の照度は12条件中10条件、反射は各12条件中12条件で除外点の誤差が下がった。冬は照度／反射とも12条件中12条件。すべての位置で改善したという意味ではない。冬の外周などは比の上限に達しており、補正しきれない差が残る。詳細は `bake.json`。

## ブラウザ検証

季節補正のみの独立ビルド（波の像の揺らぎ追加前）と基準を、標準DPR1・固定解像度・動作抑制・ミュートで前→後→後→前に撮る。3ステージ×四季×昼夕夜の各36 PNG。撮影成功と目視の確認範囲は別に記録する。

Chrome 155.0.8059.80で4件成功、計144 PNG。ページ／コンソールerrorなし。同一canvasを保持。各版36枚すべて再撮影差0画素。夏の前後差は全体平均0.000003 RGB階調、春0.172・秋0.191・冬6.008（0〜255のRGB絶対差平均）。これは変化量で、画質向上率ではない。

変更後36条件の一覧と、冬・昼の外気浴／冬・夕の水風呂／秋・昼のサウナの原寸ペアを確認。冬の雪からデッキや周囲へ返る光が増える。確認範囲に大きな白飛び・黒抜けなし。春秋の全体の変化は控えめ。[冬の前後](comparison-0.jpg)（左：前、右：後）。全角度・全画質・実機の確認ではない。

`validation.json` に条件・入力／画像ハッシュ・再撮影差を保存。`variants.json` に3つの独立ビルドの全runtimeソース／配信モデル／バンドルのハッシュを記録。基準→季節補正のみは6ファイル、季節補正→揺らぎ追加は5ファイルの差で、配信モデル・プローブ群は完全一致。

## 再実行

基準・季節補正のみ・両方を含む最終版を独立ディレクトリで `bun run build`。基準と季節補正のみで次をABBA実行し、各回のJSONと出力画像を保存してから集計する。Chromeの検証専用設定はプレビューポート4293と音声出力無効化のみを上書きする。

```sh
bunx playwright test --config review.config.ts e2e/season-light.visual.ts --reporter=json
python3 scripts/summarize_season_water.py seasonal <前1.json> <後1.json> <後2.json> <前2.json> docs/3d-qa/seasonal-light
```

通常ブラウザ回帰全件・四季の全周・季節ごとの方向性や遮蔽の再ベイク・実Safari・実機は未確認。結合した製品版の回帰と負荷は [像の揺らぎ](../refraction-sway/README.md) に記録する。
