## 方法

- Chrome・macOS headless、1280×800・標準画質・動作抑制なし・`frameRate=full`。サウナから入室し、庭の準備完了後に水風呂／外気浴へ移る。
- 水風呂の昼→夕暮れ（12〜15分）、外気浴の夕暮れ→夜（27〜30分）を各195秒観察。開始前の保持時間だけをDate.nowのオフセットで省き、その後はrAF・時計・水の動きを実時間で進める。
- 50〜70秒、110〜130秒にマウスで左右約±0.5radの見回し。約1秒ごとの全標本で自動照明・庭ready・分割完了・本体／庭の未描画グループ0を検査する。
- 照明値の単調増加、目標との差0.025未満、時計差250ms未満、標本間隔5秒未満、終点到達、同一canvas維持、2D復帰、ページ／コンソールエラーなしを検査。
- 集計で条件不足・重複・失敗・skip・flaky・入力変更・方式混入・準備未完了を拒否。WebMと変換後MP4を全デコードし、各12枚を抽出する。

## 再実行

```sh
MOTION_WARMUP=split bun run test:browser:motion --reporter=json > /tmp/sauna-split-auto-motion.json
python3 scripts/summarize_auto_motion.py /tmp/sauna-split-auto-motion.json docs/3d-qa/warmup-auto-motion --warmup split
```

## 判定の範囲

録画の符号化負荷を含むため、動画のfpsをアプリのfpsや性能合格とみなさない。通常／分割の動画の画素比較ではない。抽出画像の確認は、連続再生で感じるちらつきや短時間の鏡像更新の段差の合否を保証しない。非HDR、高画質、サウナ視点の連続見回し、WebKit、実Safari・Windows・モバイル・遅い端末、音の実聴は対象外。
