## 表現と検証の範囲

- せせらぎは地形上の帯の色を動かす視覚的な近似。流体計算、水風呂と同じ屈折・鏡像、追加音はない。
- 山並みは色付きの遠景形状。灯籠は夕夜の発光面で、追加光源や間接光の再ベイクはない。
- 動く草・蝶は静的影を投射しない。動作抑制でない間の水風呂の鏡像更新は125ms刻みで、連続動画の知覚的な滑らかさは別検証。
- 実機Safari・モバイル実機・GPU性能・長時間の資源安定性は今回の検証に含めない。通常ブラウザ試験の全件実行は行っていない。
