# 通常／分割準備の全周比較

`?warmup=off` と `?warmup=split` を通常→分割→分割→通常（ABBA）で比較する。製品コード・配信物は変更しない。

```sh
bun run test:browser:visual e2e/warmup-surround.visual.ts --reporter=json > /private/tmp/sauna-warmup-surround.json
python3 scripts/summarize_warmup_surround.py /private/tmp/sauna-warmup-surround.json docs/3d-qa/warmup-surround/summary.json
```

インストール済みGoogle Chrome、1200×800・DPR1・標準画質・固定解像度・全速描画・動作抑制。サウナから入室し、庭の準備完了を待つ。3ステージ×昼夕夜×8方向×3俯仰の216視点を各4回、計864枚撮影する。カメラ操作後に70 rAF待ち、DOM演出・フォーカス枠を除いて撮影する。画質変更で初期準備方式を再設定しないよう、初期値と同じ標準画質を選択する。

集計はABBA順・成功4件（skip／retry／flakyなし）・視点順・ブラウザ／製品／検証入力・PNGハッシュ・寸法・別撮影パス・設定・庭の準備完了を照合する。分割方式は分割完了・未描画グループ0も要求する。方式間の2組と、通常／分割それぞれの再撮影差を分けて記録する。PNGと比較一覧はローカルのみ。

これは準備完了後の静止全周比較。初回フレーム、連続見回し、自動時間帯、3画質・3入口の全組合せ、非HDR、WebKit／Safari／Windows／モバイル、GPU費用・読み込み性能、実聴は対象外。標準・夜の既知の差を調べたCfT・DPR1.5とはブラウザと画素比が異なる。
