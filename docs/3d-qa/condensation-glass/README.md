# 結露の粒を透明な水として描く（2026-10-12）

## 症状と原因

- 水風呂の既定視点（昼）で、画面右上の空に2px前後の暗い点が十数個見えた（`../deck-stone/water-day.png`・`../woodland-haze/water-day.png` の x≈1050〜1280、y≈90〜260）。
- 点の画素への光線はサウナの窓ガラスに当たった後、物体に当たらず空へ抜けた。シーン木の深さ1〜4の424個の物体を1つずつ隠して同じ範囲を撮ると、`Glass condensation bead`（材質 `V2 | condensed clear droplets`、95粒を1メッシュに結合）を隠したときだけ暗い点の画素が67→0になった。
- 元blendの材質は Principled の透過1.0・IOR 1.333・粗さ0.035・色(0.94, 0.98, 1)。書き出しで不透明の拡散面（粗さ0.3）になり、暗く照らされた粒が明るい空の前で点として見えていた。Cyclesの同視点（`blender/renders/stage-water/day-0-level.png`）では、この窓の部分に暗い点はなく、粒の屈折で奥の木がぼやける。
- `export_web_glb.py` は名前に `droplet` を含む物体を除外するが、この粒は名前が違うため配信GLBに残っている。

## 変更

- `glass.ts` の `GLASS` に `V2 | condensed clear droplets`（IOR 1.333・色は元の値）を加え、窓ガラスと同じ「透過率の乗算＋反射プローブの加算」で描く。各粒の表の面を1枚の板として扱う。屈折によるぼけは省略する。
- 元GLB・ベイク済みプローブは変更しない。粒は影マスク・深度プリパスの対象から外れる（`ShaderMaterial`）。影は窓ガラスと同じく投射する。

## 確認

- 水風呂の既定視点・昼（1280×800・標準画質・TAAなし・動作抑制）：右上の範囲の暗い点の画素（7×7のメディアンより12以上暗い画素）が67→0。`before-water-day-clip.png` が変更前（変更後の画像は以後のテスト実行で消えたため残っていない）。
- 結露の近接（`e2e/body-normals.visual.ts`、標準画質・DPR 1.5、昼夕夜）：`before-condensation-*.png`／`after-condensation-*.png`。変更前の白く濁った多面体が、縁にかすかな映り込みのある透明な粒になった。
- 型検査、55ファイル356単体テスト、Lint、整形、本番ビルド成功。Chromeで `garden-details`・`scene-no-hdr`・`scene-shader` の22件成功。
