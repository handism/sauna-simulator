# 水面に映る寝椅子灯の像のぼかし（2026-10-20）

## 課題

- 夕暮れ・夜の水風呂に、寝椅子灯（`V10 lounge dusk fill`、直径2mの円盤、ブルーアワー42W）の像が、輪郭のくっきりしたクリーム色の形で載っていた。切り絵がタイルの上に置かれたように見えた。
- 正体は水面の鏡像（`planarReflection.ts`）に写る光沢専用の面光源（`glossyLights.ts`）。Cyclesでも輪郭は鋭い。
  - 水底の部分反射（`waterBottom.ts`）の経路で寝椅子灯を0にした撮影でも像は残った。その経路の縁をぼかす試みは画像がほぼ変わらず、取り消した。
  - 直線の切れ目は、鏡像の中で縁石が灯りを隠している輪郭。

## 変更（元blendにない補正）

- `SOFT_GLOSSY`：円盤を半径の1.8倍まで描く。0.6倍の内側は一定、その外は0.25倍ごとに1/eで落とす（端で1%未満）。
- 電力が元と同じになるよう、明るさを1.29倍にする（`softScale`）。
- 平面座標（`local`）とぼかしの値（`softness`）を頂点属性で渡し、断片段で計算する。他の11灯は従来のまま。
- 水底の部分反射から見る同じ灯り、縁石などの遮蔽物の輪郭は鋭いまま。

## 確認

  - 同方式の再撮影差は全条件で0画素。
  - 8階調超で変わった画素：水風呂の昼1.3〜2.5%（昼の弱い同じ灯りの淡い像）、夕暮れ2.0〜3.8%、夜1.9〜3.7%。外気浴0%。
