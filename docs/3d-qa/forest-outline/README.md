# 奥の森の輪郭（2026-10-21、採用）

奥の森（48〜54m）の上端に、細い柱の先に小さな塊が乗った「煙突」のような突起が並んでいた。手前の立体の葉群は滑らかな楕円の輪郭で、綿の玉や植え込みのように見えた。

## 原因

- 手前の73樹冠の立体は、頂部を元の樹冠より1.1m低くしていた（`forest-volume/`）。その上に奥54mの帯の樹冠の先が覗き、帯の輪郭のほつれ（`FRAY`）が細い先を柱と塊に切っていた。広葉樹・常緑樹の両方で起きる。
- 立体には帯の上端用のほつれを掛けていない（閉じた輪郭を持つため）ので、葉群の縁は低分割の楕円のままだった。
- 水風呂のガラス越しの視点で森の中に見える明るい1〜2画素の点は、サウナの窓の結露の粒（`glass.ts`）で、森の不具合ではない（ガラス越しでない視点にはない）。

## 変更

- `farForest.ts` の `FRONT_DROP`（0.2m）：手前の立体を元の樹冠の0.2m下まで上げる。手前（48〜51m）にあるので、同じ高さの奥の帯の先は立体に隠れる。中間・奥の補完の立体（0.25m・0.1m下）はそのまま。
- 常緑樹の立体の幹（leader）の上半分を円錐にする（`lobeTaper`）。立体を上げると、帯が見せていた尖った先が丸い頭に替わり、広葉樹のように見えたため。
- `VOLUME_FRAY`（0.8）：立体に頂点属性 `gardenNormal`（8bitの法線、帯は0）を足し、断片段で視線から面がそれる所（輪郭）を、約0.4m・0.17mの葉の塊のノイズで最大0.8だけ削る（`discard`）。後ろの葉群・樹冠が覗く。葉の塊が画素より細かくなる距離では削らない。描画パス・材質・三角形は増えない。属性は約240KB増える（森のメッシュ全体で約5.58MB）。

候補（比較画像はローカルの `variants-day.png`・`variants-evening.png`、上から変更前・常緑樹を丸頭のまま・採用）：

- 常緑樹だけ上げる：広葉樹の位置の帯の先が小さな塊のまま残った。
- 立体のほつれ0.45：輪郭の約1割しか削らず、丸い葉群のままだった。
- 常緑樹の頂部を丸いまま上げる：冬・秋の常緑樹が丸い頭になった（`winter-rounded-spire.png`、上が変更前）。

## 確認

変更前は `farForest.ts` だけを `7878920` に戻したビルド。Chrome 155.0.8059.85。値は [values.json](values.json)。

- 静止画（`forest-leaf-masses.visual.ts`、1280×800・標準DPR1・固定解像度・動作抑制、3ステージ×昼夕夜×水平3方位＋外気浴の春秋冬の昼、30枚×前→後→後→前）：全4件成功、ページ／console errorなし。変更後の再撮影差は0。変更前の再撮影は15枚で1〜2画素の孤立した差（既知の読み込み間の差）。変化は奥の森だけで、ΔE>2の画素は0.04〜1.1%。
- 制御した見回し（`resolution-shimmer.visual.ts`、1200×800・DPR1.5・段1.5固定・`&camera=review`、3ステージ×昼夕、既定の向きと右60キー）：回転補償残差の比は既定の向きで0.995〜1.002、右60キーで1.000〜1.006。同じ版の再撮影は1.000。知覚的なちらつきの合否ではない。
- 描画間隔（`forest-back-crowns.gpu.ts`、標準DPR1・右20キー・描画3回反復、ABBA 2組）：0.999〜1.001倍。
- 単体テスト：帯の法線が0・立体の法線が単位長、手前の立体の頂部が元の樹冠の0.2m以内、シェーダーに輪郭のほつれが入ること、立体が閉じていること。

## 範囲

高画質・雨雪・実機は未確認。葉群が楕円の集まりであること（近くで見るとブロッコリーのような丸い塊の重なり）、54mの帯の陰影が固定方向であることは残る。輪郭のほつれは視線と低分割の補間法線による近似で、葉の形ではない。
