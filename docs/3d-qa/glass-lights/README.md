# ガラスに映る光沢専用の灯り（2026-10-26、採用）

改善候補の3番目「水の反射像の形と部分遮蔽」を見直す中で、水風呂の窓ガラスの映り込みに大きな差を見つけた。夜・夕暮れのCycles（`blender/renders/stage-water/`）では、水風呂から見たサウナの窓に寝椅子灯（`V10 lounge dusk fill`、直径2m）が明るい半月形に映るが、製品の窓は素通しだった。

## 原因

`glass.ts` の反射は反射プローブ（と室内から見たときの室内の照り返し）だけで、プローブはブラウザが描く灯り（V9と夕暮れの暖色灯5灯）を焼き込みから外している（`scripts/bake_irradiance_probes.py`）。ブラウザはそれらのハイライトを通常の材質には描くが、ガラスには描かないので、どこにも映らなかった。

## 変更

- `waterBottom.ts` の光線と面光源の交差（形・柔らかい縁・天蓋の梁とルーバーの遮蔽）を `sourcesGlsl(sources)` として公開し、水の底面の部分反射と共用する（水底の生成コードは同じ）。
- `glass.ts` の反射の材質で、室外側から見るときだけ、反射した視線をこの6灯（`GLASS_LIGHTS`）と交差させて足す。室内から見た反射は室内に向かうので足さない。天蓋以外の遮蔽物は扱わない。
- 水面の鏡像のパスでは足さない（`onBeforeRender` で鏡像のカメラの `MIRROR_LAYER` を見る、空の太陽円盤と同じ方法）。水面→ガラス→灯りは光沢の2回目の反射で、Cyclesでは間接光のクランプでごく淡い。最初の試作では、昼の見下ろしの水面にガラスの中のV9がクリーム色の円盤で映り、Cyclesの淡い輪と合わなかった。

## 確認

Chrome 155.0.8059.85、標準・DPR1・1280×800・動作抑制。

- `stage-compare.visual.ts`（水風呂4方向×昼夕夜、PNG）：窓の範囲（1280×800の x 160〜460・y 100〜380）のCyclesとのΔE76の平均は、夜19.40→14.79、夕暮れ21.97→19.68、昼21.98→21.76。夜の像は位置・形（右側が切れた半月形）がCyclesとほぼ一致する。製品の像は縁が少し硬く、Cyclesはわずかににじむ。
- 全周撮影（`scene-survey.visual.ts`、216視点、変更前は `c6b353e` のworktree）：画面の縁40pxを除いて局所的に変わったのは水風呂・外気浴の14視点（窓の寝椅子灯：水風呂と外気浴の夕夜の水平、昼の見上げのV9）。昼の見上げ（見出し0・1・2）でガラスに映るV9の円盤は、同じ視点を `blender_stage_reference.py` の複製で描いたCycles（128サンプル）でも同じ位置・大きさに映る。昼の見下ろしは鏡像で足さない修正の後、変化は縁の数画素だけ。
- 描画費用（`frame-cost.gpu.ts`、3ステージ×昼夕夜、描画3回反復、変更前→後→後→前）：フレーム間隔の比0.999〜1.002。描画数・三角形数は不変。
- 単体テスト（`glass.test.ts`）：6灯が光沢専用の面光源の表にあること、反射の材質だけに関数が入ること、鏡像のカメラで0・主カメラで1になること。型検査・489単体テスト・Lint・整形・ビルド、`scene-lifecycle`・`scene-no-hdr`・`scene-shader`・`temporal-aa` の28件が成功。

## 調べて変えなかったもの

- 水底の寝椅子灯の像（クリーム色の斑）：タイル自身の光沢（`suiWetSpecular`）を外した一時ビルドは縁がくっきりして見えたが、像の周りのCyclesとのΔE76は12.4〜13.0→15.7〜15.8と悪化した。形の差は2026-09-30の調査（`water-gloss-grazing/`）でも原因が特定できておらず、変えていない。
- 夜の見下ろしの足元の丸い光：水風呂の真上の `V7 water reflection soft strip` の鏡像で、2026-10-22に意図してぼかしたもの（`water-strip-glow/`）。Cyclesでは縁の硬い多角形。

## 範囲

静止画とCyclesの比較で、四季・雨雪・高画質・見回し中・実機は見ていない。灯りとガラスの間の天蓋以外の遮蔽物（屋根・柱・木）は扱わないため、それらに隠れる角度では像が出すぎる可能性がある（全周撮影の216視点では見当たらなかった）。
