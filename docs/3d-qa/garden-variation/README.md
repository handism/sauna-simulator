# 低木・花・石組みの個体差（2026-10-12）

## 課題

`gardenDetails.ts` の低木は同じ大きさの葉54枚を同じ黄金角の螺旋に並べたドーム（大きさ3段階）、花は各株の頂上の同じ4か所、せせらぎの縁石は滑らかな楕円体（3段階）を0.23m間隔で両岸に並べていたため、同じ形の繰り返しに見えた。

## 変更

- 決定的な乱数（mulberry32、固定の種）で、毎回同じ庭を生成する。
- 低木：株ごとに大きさ（0.24〜0.48）・横幅・奥行き・高さ・葉の数（38〜69）・向き・緑の明るさと黄み、葉ごとに大きさ（0.7〜1.3倍）・傾き・張り出し・明るさをばらつかせ、株の位置もずらす。
- 花：株ごとに2〜6輪を樹冠の上部へ散らし、大きさと明るさを変える。季節の色は従来どおり材質色で、頂点色はその明るさの差だけ。
- 石：`rockGeometry()` が球を位置の正弦波でゆがめ、底を平らにした不規則な岩を作る（三角形数は従来の球と同じ）。縁石・株脇の石は大きさ・向き・間隔・色を変え、縁石の約2割に小石を添える。
- 個体の色は頂点色（石・低木・花の材質で `vertexColors`）。テクスチャを使わない材質のため結合前にUVを外す。元GLB・ベイク済みプローブは変更しない。

## 確認

- `garden-details.e2e.ts`（標準画質・1280×800・動作抑制）の撮影を `../meadow-ground/` と比較（`compare-summer.png`・`compare-runnel-zoom.png`、上が変更前）。夏・春・秋・冬・夕・夜・雨を目視し、冬は花が消え雪が載る。
- 型検査、55ファイル359単体テスト（決定性・個体の色・岩の形と法線を追加）、Lint、整形、本番ビルド成功。Chromeで `garden-details`・`season`・`scene-no-hdr`・`scene-shader`・`scene-warmup` の36件成功。
