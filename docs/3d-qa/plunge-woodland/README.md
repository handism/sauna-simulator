# 水風呂の水深・タイルと中景の樹冠（2026-10-20）

## 課題

- 水風呂がプールのように見えた。
  - 元の水はほぼ透明で、1mで赤が約5%減るだけ（`refraction.ts` の `WATER_ABSORPTION`）。深さが見えなかった。
  - 床は全タイル同じ単色の明るい青緑（0.12, 0.32, 0.28）。
  - 疑似コースティクスの明るい網目が床一面に出ていた。
- 外気浴の10〜20m先の林の樹冠が、空を透かした暗い葉の点のレースに見えた。葉カードの葉が1画素前後になると、閾値0.5のアルファ被覆で葉が1枚ずつ点になるため。

## 変更（いずれも元blendにない補正）

- **水越しの色**（`refraction.ts` の `VIEW_DEPTH`）：視線の屈折経路長に応じて、元の吸収にRGB 1.1・0.45・0.5 /m を足す。さらに水の散乱として、1mあたり0.2の割合で「見えている色の輝度×暗い青緑（0.26, 0.62, 0.56）」を足す。
  - 深い所・斜めに遠い所ほど暗い緑になり、目地のコントラストが下がる。
  - 灯りの経路（`waterBottom.ts`）は元の吸収のまま。
- **タイル**（新規 `poolTiles.ts`）：書き出したタイルの角から読んだ13×16枚の格子で、次を付ける。テクスチャは使わない（床の材質はユニット16を使い切っている）。
  - 1枚ごとの明るさ（0.68〜1.02倍）・色相・粗さ（±0.06）
  - 縁2cmの釉だまり（最大0.7倍）
  - まだら（±12%）
  - 浴槽の壁から35cm以内の暗さ（壁際で0.62倍）
- **コースティクス**（`caustics.ts`）：描く色だけ `CAUSTIC_VIEW_SCALE` 0.6倍。強さの関数はBlender照合のまま。
- **林のカード**（`leafCluster.ts`）：1画素が1.5→4テクセルを覆うにつれ、被覆の閾値を0.5から最大0.14下げる（`LEAF_FAR_FILL`）。
  - 深度プリパス・影マスクの複製も同じ関数を使う。影マップは0.5のまま。
- **樹冠の陰**（`crownNormals.ts` の `crownShade`）：内側を0.6→0.7、下面を×0.82→×0.86に明るくした。被覆の変更と同時に入れたもので、片方だけの比較はしていない。

## 調整の経過

- 最初の吸収（0.42・0.14・0.19、散乱0.3）とタイルのむら（±13%）は、撮影で差がほとんど分からなかった。手前の床の平均で赤が約14%減っただけだった。
- そこで2段階で強め、明るさの平均を下げ、壁際の陰とコースティクスの減光を足した。

## 確認

- `e2e/plunge-woodland.visual.ts`（Chrome 155.0.8059.85、標準DPR1・1280×800・動作抑制・固定解像度）で、変更前のdist（`bdb2e0a`）と変更後をABBA撮影した（各20枚、計80 PNG）。結果は [comparison.json](comparison.json)。
  - 同方式の再撮影差は全条件で0画素。
  - 8階調超で変わった画素の割合：水風呂34〜73%、外気浴の林4〜10%（冬は常緑樹だけで3%）。
- 比較画像（ローカルのみ、左が変更前）：
  - `plunge.jpg`：水風呂の昼の見下ろし・夕暮れの横・夜の見下ろし
  - `woodland.jpg`：外気浴の林の昼・夕暮れ・秋・冬
- `frame-cost.gpu.ts`（晴れ、`FRAME_COST_REPEAT=3`、標準・1200×800・DPR1・固定解像度）を変更前→後→後→前で測った。結果は [cost.json](cost.json)。
  - フレーム間隔÷3の後/前（2組の中央値）は、サウナ0.981〜0.993、水風呂0.981〜1.006、外気浴0.966〜0.970。
  - 外気浴が軽くなった理由は切り分けていない。被覆の増えた樹冠が深度プリパスで奥を隠す分が考えられる。

- 型検査・456単体テスト・Lint・整形・本番ビルド、`caustics`（Blender照合）・`garden-details`・`season`・`scene-no-hdr` の28回帰が成功。
