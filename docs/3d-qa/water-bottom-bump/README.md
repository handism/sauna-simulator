# 水底反射の斑の縁をバンプでほつれさせる（2026-09-29）

水風呂の夕暮れ・夜に水面へ出る寝椅子灯（`V10 lounge dusk fill`）の斑は、水の底面での部分反射の像（[water-bottom](../water-bottom/README.md)）。ブラウザでは縁が滑らかで一様な面になり、Cyclesでは縁が細かくほつれていた（同READMEの「残る差：円盤の縁が硬い」）。

## 原因の切り分け（Cycles）

`scripts/diagnose_water_bump.py`（元blend、ブルーアワー、読み取りのみ）で、斑の部分を3条件で描いた。

| 条件 | 縁 |
| --- | --- |
| 参照設定（128サンプル・デノイズ） | ほつれる |
| 2048サンプル・デノイズなし | ほつれる（デノイズは原因ではない） |
| 同上で水の Bump ノードを外す | **滑らか**（ブラウザの従来の像に近い） |

- 原因は元の水材質のバンプ（Object座標のノイズFac、Scale 55・Detail 2、Distance 0.0006・Strength 0.08）だった。
- 元の水面の形状（上面14,520面、約2.4cm格子）は当てはめた波 `WAVES` とよく一致し（傾きの残差の中央値0.0005）、形状の細かな凹凸は原因ではない。
- バンプの傾きは、真上から見た法線パスのバンプ有無の差で実効値0.0013・中央値0.0011・95%点0.0022（[値](#値)）。小さいが、数m先の灯りへ向かう視線を振るので縁がほつれる。
- 元の水形状は**底面も同じバンプ材質**で、底面での反射は傾きの2倍だけ視線を曲げる。最初に水面の入射・出射だけにバンプを入れたときは縁の粗さが足りず（下の「結果」の途中の試作）、底面の反射に入れて揃った。

## 方式（`waterBottom.ts`）

- 底面の部分反射の経路で、水面への入射・底面での反射・水面からの出射の3か所で、波の法線にバンプを重ねる。バンプは `waterEffects.ts` の `WATER_BUMP_GLSL` で、BlenderのBumpノードと同じ式（`normalize(mix(N, normalize(N − 0.0006·∇h), 0.08))`）。高さの勾配は水平面上の0.4mmの前進差分、ノイズは既存の `sui_fbm`（画素より細かいオクターブは弱める）。NumPy版（`scripts/water_bump.py`）の傾きは同じ範囲で実効値0.0013で、Cyclesの法線パスと一致した。
- 全画素でバンプを評価すると水風呂のGPU時間が+11〜23%になった。まずバンプなしで追い、底面の法線を4方向へ0.006傾けた安い追跡のどれかで見える灯りが変わる画素（灯りの縁・縁石・側面で経路が変わる境目の近く）だけ、灯りの項をバンプ付きで追い直す。プローブの項はバンプなしのまま。
  - 最初は「灯りの大きさの±10%／±20%の帯」で判定したが、縁石で隠れる境目と、側面で反射する経路の境目の縁が滑らかなまま残った。法線を傾ける判定なら、これらもまとめて拾える。
- 全面版との差は8bitで40以下が大半（注水口の近くの見出し4で約20画素が最大119〜138）。
- 水越しの床の像と、鏡映像（側面の像）の入射はバンプなしのまま。水面そのものの鏡像（見出し0の斑は水面の反射で、別経路）にはバンプを入れていない。
- ほつれの位相はCyclesと画素単位では一致しない。ブラウザは水面の高さを平面で近似し、波も動くため。

## 結果

`e2e/stage-compare.visual.ts`（標準画質・1280×800）の撮影で、変更前はHEADのworktree。縁の粗さは `water_bump.edge_roughness`（明るい部分のマスクとそのぼかしの差を縁の画素数で割る相対値。滑らかな円で約0.3）。

| 視点 | 変更前 | 変更後 | Cycles |
| --- | ---: | ---: | ---: |
| 夕暮れ・見下ろし | 0.367 | 0.668 | 0.658 |
| 夕暮れ・見出し2 | 0.375 | 0.652 | 0.735 |
| 夜・見下ろし | 0.307 | 0.638 | 0.661 |
| 夜・見出し2 | 0.326 | 0.683 | 0.717 |

途中の試作（水面の入射・出射だけにバンプ、全画素で評価）は、夕暮れの見下ろし・見出し2で約0.50・0.52だった（同じ考え方の指標をPILのグレースケールで測った値で、上の表とは輝度の重みが少し違う）。全12視点のΔE76は [summary.json](summary.json)。

- 12視点のCyclesとの平均ΔE76（全画面）は変更前後で差が0.003以下。変わった画素（ΔE>2を6px広げた帯）に限ると0.01〜0.20悪化する（昼の見下ろし10.46→10.65、夜の見出し4 16.31→16.46）。ほつれはCyclesと画素単位では一致しないので、ほつれた縁はずれた位置で差を生む。ΔE76は改善の指標にならず、他の部分が動いていないことの確認に使う。昼（V9の淡い斑）も縁がほつれ、変わった画素は656〜2,073。見出し0（水面そのものの鏡像）は変化0。
- 比較画像（ローカル）：`review.png`（夕・夜の見下ろしと見出し2、左から変更前・変更後・Cycles）。

残る差：

- Cyclesの斑は内側にタイルの目地が透け、中央ほど白い。ブラウザの内側は一様な面のまま。
- ブラウザのほつれは1画素1標本で、Cyclesのようにぼけない（縁のギザギザが硬い）。
- 波が動くので、ほつれは時間とともに縁の上を動く。Cyclesは静止画なので、動きの比較はない。動画での見え方は未確認。
- 見出し4（注水口の近く）の像の形の差は変わらない。

## 値

- [summary.json](summary.json)：バンプの傾き（Cyclesの法線パスと製品の式）、縁の粗さ、12視点のΔE76、入力ハッシュ。
- [bump.json](bump.json)：`diagnose_water_bump.py` の出力（元blendのハッシュ、条件、法線パスの傾き）。EXR・npyは `blender/diagnostics/water-bump/`（Git管理外）。

```sh

bun run test:browser:visual e2e/stage-compare.visual.ts   # 変更前はHEADのworktreeでも同じく撮る
python3 scripts/summarize_water_bump.py <変更前の撮影> <変更後の撮影> blender/diagnostics/water-bump --out docs/3d-qa/water-bottom-bump
```
