# 水風呂の床にV9のハイライトを描く（2026-09-27）

[水中の照度の受光球](../water-receiver-shell/README.md)の残件「昼の水越しのタイルが暗い（見下ろし全体 −1.6 L*）。残りは水越しのタイルの光沢（V9のハイライト）とアルベド（+6%）」を扱った。アルベドの差は測り方によるもので実在せず、不足は **V9のハイライト** だった。元blendではこのハイライトが間接光クランプとロシアンルーレットで大きく削られることを測り、その分を含めて床に描いた。

## アルベドの+6%は実在しない

タイルの材質は単色（基本色 0.12/0.32/0.28、粗さ0.3、輝度0.2746）で、ブラウザの測定値0.2732と一致する。Cyclesの Diffuse Color パスは「基本色 ×（1 − 鏡面層のアルベド）」で、同じ材質の板で真上0.960倍・40°で0.953倍・60°で0.913倍（Specular IOR Level 0 なら1.0倍）。前回のCycles 0.2579はこの係数込みの値だった。threeも間接光の拡散に同じ係数（1 − 単散乱 − 多重散乱）を掛けており、前回の「光沢を除くとブラウザ／Cyclesは1.061倍」は、ブラウザ側の光沢を外す切り分けがこの係数ごと外していたためと考えられる。アルベドは変更していない。

## 前回の8点の見直し

[前回の測定](../water-floor-gloss/measurements.json)で、V9の当たらない6点ではブラウザの光沢（V9を除いた反射プローブ×分割和）とCyclesの水越しの光沢はほぼ一致していた（合計 0.025対0.028）。不足はV9の当たる2点（Cycles 0.013・0.028、ブラウザ約0.003）に集中していた。

## 元blendでの水越しのV9ハイライト

測定値は [measurements.json](measurements.json)。`scripts/diagnose_water_floor_highlight.py`（Blender 4.5.11、約5分）で、V9の鏡面方向から浴槽を見る斜めの正投影カメラ（320×320・512サンプル）、タイルの下地を黒にし、ライトグループのCombinedを Specular IOR Level 0.5 と0で引いた値を浴槽の範囲で合計した。水越しでは水面自身のV9の鏡像が差を埋もれさせるため、V9を光沢レイからだけ隠した（床の経路は水から透過レイとして出るので残る）。

| 条件 | 水越し ÷ 水なし（直接光） |
| --- | ---: |
| 元の設定（間接光クランプ10） | **0.141** |
| クランプ30 | 0.396 |
| クランプ100 | 1.072 |
| クランプなし | 1.097 |
| ロシアンルーレットなし（`min_light_bounces` 64） | 1.083 |

- 視線の透過率（メッシュの発光の比）は0.909。クランプもロシアンルーレットも外せば水なしとほぼ同じ（床の外に届く分・側面の全反射による像も含む）。
- クランプ値にほぼ比例して増えるので、V9に届く標本のほぼすべてがクランプ（RGBの和10）に掛かっている。床はカメラから3バウンス目で、暗いタイルの光沢の後で生き残った経路がロシアンルーレットで増幅される（前回見つけた「ロシアンルーレット×クランプ」と同じ機構。拡散より強く効く）。
- 夕暮れの `V10 lounge dusk fill`（放射輝度はV9の約1/70）はクランプ値で変わらない（2.35〜2.81倍、雑音の範囲）。水越しの方が大きいのは、低い灯りの直線の影は縁石で床の大半を覆うが、屈折した経路は水中で急になり影が浅くなるため。ハイライトの量は床全体で合計0.4と小さい。

## 方式

`waterBottom.ts` の `suiWetSpecular`：床（`SUI_WATER_BOTTOM`、底面より下）のV9・寝椅子灯の鏡面だけを足す。拡散は水中プローブにあり、水中の反射プローブはこの2灯を除いている。

- 床は水の底面の下の空気層にあるので、平らな水面なら光は空気中の向きのまま届き、視線は底面で屈折して出る（平行な2面）。視線は `suiWetView`（波で屈折済み）を底面で屈折させて求める。光の経路に (1−R)²・透過色2回・吸収（屈折した経路長）を掛ける。
- 円盤の大きさ：点光源のままではハイライトの中心が14%（最大21%）強すぎる。GGXの α'² = α² + 0.25 (r/d)² で広げると、円盤上の積分との誤差は最大4.7%（`waterBottom.test.ts` は3点で±10%以内を確認）。
- クランプ：標本値をRGBの和で `WET_SAMPLE_WEIGHT` × 光源の放射輝度の和と見積もり、10を超える分を縮める。V9で0.17倍（0.141 ÷ 視線0.909 ÷ 光の経路 約0.89 から当てはめ）、寝椅子灯は1倍。
- 影は真の位置からの直線のまま（屈折による影の縁のずれ、V9で約8cmは省略）。
- 最初の試作は7灯に展開されるスポット光のループの中で鏡面を計算したが、同じ材質が使われるサウナの視点でもGPU時間が増えた（交互7組で+1〜10%）。ループでは光源の判定と色・向きの保存だけにし、ループの後で2灯分だけ計算する形にした。

## 残る差

- 見下ろし全体はまだCyclesより0.8 L*暗い。クランプなしのCyclesが水なしの1.09倍になる分（側面の全反射で映るV9、床の外から届く分）は入れていない。
- 屈折による影のずれ：夕暮れの寝椅子灯は直線の影で床の大半が影になり、水越しの床のハイライトを取りこぼす（量は小さい）。
- ハイライトの位置は平らな水面の光の向きで、光の経路の波による揺らぎ（コースティクス状の模様）はない。視線側は波で屈折済み。
- 側面の内壁・青銅の基壇には足していない（床だけ）。
