# デッキ・石の質感（2026-10-12）

## 変更

- 屋外デッキの地面付近へ、板の長手方向の細い木目・繊維と既存の物体乱数に基づく板ごとの濃淡を加えた。
- 鉱物系の庭石・舗石へ大小の色むら、細かな凹凸、粗さのむらを加えた。画像テクスチャと法線マップを残して合成する。
- ワールド座標で模様を固定し、画面上で細かくなったノイズは平均へ薄める。新しいテクスチャ・sampler・形状は追加しない。シェーダー計算は増えるため性能不変とは主張しない。
- 対象材質を明示名で絞り、室内木材・タイル・ガラス・水中専用石材を除外。積雪の色は後から重ね、微小凹凸と粗さのむらは残る。

- 型検査、55ファイル355単体テスト、Lint、整形、本番ビルド成功。
- Chromeの庭・季節試験9件成功（1.5分）。四季、3画質、遅延した庭への設定反映、同一canvas保持を確認。
