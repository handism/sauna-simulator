# 奥の森の樹冠のインポスタ（2026-10-27、採用）

利用者の「進めて」（未完了事項の画質「奥の森の近似」：葉群が楕円の塊の重なりであること）。[葉の塊の模様](../forest-leaf-masses/README.md)・[輪郭のほつれ](../forest-outline/README.md)の後も、帯の手前の樹冠は低分割の楕円体（手前73・中間19・奥18樹冠、各3つの芯と4〜10個の葉群、計91,404三角形）で、綿の玉の重なりに見えた。近似の調整では形が変わらないため、密な葉の樹冠をBlenderで焼いた板（インポスタ）に置き換えた。

## 変更

- `scripts/bake_forest_impostors.py`（新規）：元blendは使わない。林の木（`Forest trunk`・枝・葉のカード）は疎なカードで、焼くと空の透けたレースになるため、空のシーンに密な葉の樹冠を作る。広葉樹5種は葉の塊（ローブ）26〜32個（3つに1つは芯）を地面近くから頂部までの卵形に重ね、常緑樹3種は垂れた枝の段の円錐。葉は菱形の小さな面で、法線を樹冠と葉の塊の外向きへ寄せる（葉自身の向きは0.3）。正投影で、RG＝法線の横・上、B＝天頂ほど明るい曇天（放射輝度∝cos^1.5）の下での葉の明るさ（開けた上向きの葉に対する比）の平方根、A＝被覆を焼き、4×2タイル（各160×320、6.4×12.8m）の `public/models/forest-impostors.webp`（可逆、291,362 bytes）にする。出力は実行ごとに同じ。
- `farForest.ts`：帯の手前の樹冠を、原点を向く板1枚ずつにした（距離・頂部の下げ幅は従来の3段のまま）。断片段で焼いた法線に固定の日光（夕夜・曇天は平均）と上向きの明るさを当て、Bで0.2＋1.9×Bを掛ける。季節色・時間帯・霞・距離の暗さ・足元の暗がりは帯と共用。輪郭はalpha-to-coverage。冬の広葉樹は被覆0.72で切り、約0.3mの枝の隙間を抜く。広葉樹の板は焼いた幅の1.3倍。楕円体の葉群・立体の法線（`gardenNormal`）・日光の比（`gardenSunRatio`）・立体の輪郭のほつれは廃止した。
- 帯：樹冠に覆われた下草の輪郭を「なし（1e4）」から上の樹冠の輪郭の高さにし、下草の根元（y=BASE）の頂点を樹冠に属さない平均の色にした（下記）。
- 画像は庭の読み込みの最初に取得し（`SaunaScene.tsx`、`data-forest-impostors`）、1×1の透明な仮テクスチャと差し替える。届くまで・失敗時は帯だけになる。

## 試して変えたもの

- 一様な白い空で焼いた明るさ：表面の葉で約0.5と値は正しいが、縮小しても葉1枚ずつの粒しか残らず、葉の塊の上が明るく下が暗い構造にならなかった（一時ビルドでBだけを表示して確認）。天頂ほど明るい空にした。値は中央値約0.11に偏るため平方根で保存する。
- 葉の頂点の並び：最初の版は時計回りで、面の向きがカスタム法線と逆になり、Cyclesで全面が黒くなった（正面向きの板1枚で切り分け）。
- 葉面積密度：最初の2,600枚/m³（約27m²/m³、実際の樹冠の10倍以上）では外側の葉まで影になった。広葉樹は700枚/m³（葉の塊の表面寄り）。
- タイルからはみ出した樹冠：広葉樹（半幅2.1〜2.6m＋葉の塊）と常緑樹の裾（2.0〜2.5m）がタイルの端で切れ、縦の直線の輪郭（秋の茶色・冬の暗い四角）になった。半幅1.55〜1.9m・常緑の枝の長さ1.6〜1.95mにし、タイルの外の葉は捨てる。
- 冬の暗い四角：板にした後も、常緑樹の間に縦の切れ目の暗い塊が残った。部位を色分けした一時ビルドで、帯の、樹冠に覆われた下草（輪郭なしで平らな上端）と、樹冠ごとの色・霞の透けが根元まで続く区間と分かった（以前は楕円体の葉群が隠していた）。下草の輪郭を樹冠の高さにし、根元の頂点を平均の色にして根元側の境目は消えたが、樹冠の付け根の高さ（4.5m）付近の境目は弱く残る。
- 冬だけ覆われた下草の上端を4.5mでほつれさせる案は、問題の区間が常緑樹の下で効かなかった。

## 確認

Chrome 155.0.8059.85、1280×800・標準DPR1・固定解像度・全速描画・夏晴れ（季節は外気浴の右60キー）。

- 静止画（`forest-leaf-masses.visual.ts`、30枚、変更前は同じ作業の開始時のHEAD）：変化した画素（輝度差8超）は各画像の0.04〜1.34%（奥の森の範囲）。水風呂の右60キーの昼で、綿の玉の重なりが、上の明るい葉の塊の重なりの広葉樹と尖った常緑樹の並びになった。秋の黄土色の樹冠は風船の集まりから葉の茂る樹冠に、夜は常緑樹の尖りのある影絵になった。冬の広葉樹は以前より透けて目立たない。
- 単体テスト：樹冠ごとに1枚・頂部と段の下げ幅・タイルの種類（常緑／広葉）・向き・三角形数（2.5万未満）、仮テクスチャの差し替えと解放、alpha-to-coverage、下草の輪郭と根元の色。

- 描画費用（`forest-back-crowns.gpu.ts`、標準DPR1・右20キー・描画3回反復、変更前は作業開始時のHEAD `58681c6` のworktreeのdist、前→後→後→前）：フレーム間隔の比は3ステージ×昼夜で0.992〜0.997倍、三角形数は1フレームあたり約8.6万減（サウナ昼1,044,305→958,673）。描画数は同じ。
- ブラウザ回帰（`bun run test:browser`）：79/80件が成功。`frame-rate.e2e.ts` の1件（静止中の間引きの割合）が失敗し、単独で3回繰り返すと6件とも成功した（前回の記録と同じ、タイミングに左右されるテスト）。
- 焼き込みは同じ出力を2回確認（CPUで約20秒）。
