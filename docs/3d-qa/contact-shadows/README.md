# テラスの小物の接地（2026-10-22）

外気浴のデッキで、サンダル・寝椅子・小卓が床から浮いて見えていた。元GLBを調べると、実際にサンダルの底（y 0.10）はデッキ面（0.07）から3cm、寝椅子の青銅の脚8本（0.10）は舗石（約0.083）・デッキから1.7〜3cm浮いていた。遮蔽の焼き込みもなく、足元が明るいままだった。

## 変更

`gardenDetails.ts` の `settleTerraceProps()`（本体の読み込み時、材質準備の前）：

- 支える面はデッキ板（`outdoor ash`／`locally damp ash`）と舗石（`pale mineral paving`）。高さ0.3mから下向きのレイで求め、各部品の中心と四隅のうち最も高い面を使う（脚1本は板の継ぎ目の真上にあり、中心のレイだけでは隙間を抜けた）。
- サンダルの底（`cork sandal sole` の接続成分）を隙間の分だけ下げる。寝椅子の脚（`Blackened bronze` の幅12cm未満・高さ0.6m未満の部品）は下端4mmの頂点を面まで延ばす。対象は隙間3mm〜6cm。実モデルで10部品（`data-settled-props`）。
- 既存の接地の陰メッシュ（`Garden contact shade`）に以下を追加する：サンダル（外形の内側の角丸矩形、余白0.1m・濃さ0.7）、脚（円、0.08m・0.5）、小卓の足（円、0.18m・0.5）と天板が空を隠す分（円、0.5m・0.25）、寝椅子の胴体（左右のレールの脚4本から求めた向きの矩形、0.3m・0.35）。陰はデッキ面に沿わせ、継ぎ目に落ちる頂点はその部品の高さに置く。寝椅子2台は左右のレールの外形が重ならないものもあるため、平行で0.3〜1.2m離れて並ぶレールの脚の組を1台とする。
- 陰の矩形に回転（`turn`）を持たせた。描画数・材質・テクスチャは増えない（陰メッシュの三角形が増えるだけ）。

サウナ室のストーブ・桶は既存の `SUI_ROOM_FLOOR` の陰、庭石・岩・低木・灯籠は既存の陰があるため変更していない。水風呂の浴槽の箱と舗石の接する線は対象外。

- 変更前の再撮影差（3段階超の画素）：最大0.0004%。
- 変化はすべて外気浴：見下ろし2.3〜2.5%、正面0.4〜0.5%、左右0.3〜0.6%。サウナ・水風呂は3段階超の差なし（最大2段階）。
- エラー0件、`data-settled-props` 10。

値は `values.json`、比較画像 `compare.png`（ローカルのみ）は左が変更前・右が変更後（サンダル昼・夜、小卓、寝椅子の右側）。
