# 光沢にだけ見える面光源を水面の鏡像に描く（2026-09-26）

[側面の部分反射](../water-side-partial/README.md)の後、水風呂の既定視点で残る最大の差は、Cyclesだけに写る白い四角形・円盤だった（前回まで「Cyclesだけの灯りのハイライト（既知の差）」としていたもの）。

## 原因の特定

元blend（修正後）で水風呂の視点のカメラ光線を追った（シーンの `ray_cast`、水面で反射・屈折に分岐）。

- 昼の見下ろしの四角形：水面で反射した光線が `V7 water reflection soft strip`（2.2×1.6mの長方形、65W、色 `(0.78,0.88,1.0)`）に当たる。**カメラに不可視・光沢に可視**で、水面に映るためだけの光源。
- 昼の見下ろしの左下の円盤：水面で反射して `V9 lounge patch of sunlight`（直径1.25m、950W）に当たる。
- 夕暮れの見出し0の左下の円盤：水面で反射して `V10 lounge dusk fill`（直径2m、42W）に当たる。

光沢に可視の面光源は両シーンで13灯（位置・向きは共通、出力だけ違う。すべてspread 180°）。ブラウザでは、

- 水面（`waterEffects.ts`）は `ShaderMaterial` でブラウザの光源を受けず、平面反射（`planarReflection.ts`）は形状しか描かない。
- 反射プローブ（`reflection.ts`）にはV7・V8などが入るが、L2なのでぼけた明るさだけ。V9・夕暮れの暖色灯5灯は「ブラウザがハイライトを描く」ため焼き込みから外している。しかも鏡像があるときの水面はプローブを使わない。

そのため、これらの光源の形は水面にまったく写っていなかった。

## 方式

- `glossyLights.ts`：13灯を元の形（長方形、または円盤。円盤は32角形で面積を保つ）・位置・向きの発光面にし、1メッシュにまとめる。放射輝度はランバート面光源の `P·color/(π·A)`（`interiorLights.ts`・スポット光の `P/π` cdと同じ単位）。表は光が出る側（元のローカル−Z）。
- 昼・ブルーアワーの出力を頂点属性に持ち、照明の補間量（`suiIrradianceEvening` と同じ値）で混ぜる。V9は昼950W・夕暮れ0、V10の暖色灯は昼0.64〜3.36W・夕暮れ8〜42W、V8は28→55W、V7の2灯は両方同じ。
- メッシュはレイヤー3（`MIRROR_LAYER`）に置き、鏡像のカメラだけがこのレイヤーを描く。主カメラ・影のパス（主カメラのレイヤーで判定）には写らない。
- 鏡像は照明の補間量が変わると描き直すため、描画のたびの追加処理はuniformの更新だけ。鏡像パスの描画数が1増える。

## 残る差

- **夕暮れの見出し1の上部・見出し2・4の大きな円盤**（Cyclesで Combined 1.0〜1.2、周囲0.03〜0.1）は、`V10 lounge dusk fill` を消すとすべて消える（パス分解では透過の間接成分。暖色灯の残り4灯・V7/V8/デッキ端を消しても変わらない）。光線の経路は「水面を透過→（側面の全反射）→水中のタイルの光沢反射→水面から出て灯り」で、ブラウザは水中にブラウザの光源を直接当てない（`lighting.ts` の `DRY_ONLY`）ため、このハイライトがない。次の候補。
- 鏡像の光源は、水面の波による像のずれを他の鏡像と同じく0.6m先の点で近似しているため、5〜7m先の光源ではCyclesより輪郭の歪みが小さい。
- 鏡像がない場合（軽量画質・HDR出力なしの端末）は従来どおり反射プローブで、V9・夕暮れの暖色灯は水面に写らない。
- ガラス・石など水面以外の光沢面の映り込みは従来どおり（プローブと点光源のハイライト）。

## 再実行

```sh
bun run build
bunx playwright test --config playwright.visual.config.ts e2e/stage-compare.visual.ts e2e/cycles-compare.visual.ts --reporter=json > <出力>.json
# 変更前は HEAD の worktree（node_modules をリンク）で同じ撮影を行い、cycles-*.jpg・stage-water-*.jpg を別のディレクトリへ集める
python3 scripts/summarize_water_side_images.py <変更前> <変更後> --out docs/3d-qa/glossy-lights \
  --stage blender/renders/stage-water --stage-before <変更前> --stage-after <変更後>
bunx playwright test --config playwright.gpu.config.ts --reporter=json   # 前後を交互に複数回
```

光源の特定に使った光線追跡・パス分解・光源を消した描画は、元blendを読むだけの一時スクリプト（Blender 4.5.11、64サンプル・50%解像度・デノイズなし）で、リポジトリには追加していない。Cyclesの基準画像（`blender/renders/stage-water/`）は前回のもの。
