# 水から出た鏡面の予測がCyclesの光沢パスを超える2点の原因（2026-09-26）

[全周参照の色の誤差](../water-capture-radiance/README.md)から残っていた「19点のうち2点（11・8）で、光学モデルが予測する水から出た成分がCyclesの鏡面パス全体（`GlossCol×(GlossDir+GlossInd)`）の4.5〜8倍になる」原因を切り分けた。**製品・配信データ・元blendは変更していない。暗い帯の修正は未完了。**

## 結論

**原因は元の水メッシュの補間法線**。`V4 rippled spring water volume` の側面（484面）と底（1面）は、上端から下端まで1枚の帯で、スムーズシェード・シャープ辺なし。角の法線が上下に45°傾いており（側面・底の角の法線の幾何法線からの傾き：中央値45.0°、最大54.8°。追跡で当たった点の補間法線では中央値28°・90百分位41°）、Cyclesはこの補間法線で屈折・全反射を計算する。これまでの追跡（`water_reflection_trace.py`）は面の幾何法線を使っていた。

- 水の面をフラットシェードにするだけで、2点のCyclesの鏡面は予測どおりになる（下表）。バウンス上限・Filter Glossy・間接光のクランプ・水のバンプ・吸収は、この2点の差をほとんど変えない。
- 逆に、モデル側で補間法線を使って追跡し直すと、19点すべてで「水から出た成分 ≤ Cyclesの鏡面全体」になる。

## 測定条件

- **Cycles側**（`diagnose_water_gloss_mismatch.py`、Blender、Metal、約2.5分）：19点の到達点の1mm手前から最後の区間の向きで10µmの正投影カメラ（5×5画素の平均、1024サンプル/画素、seed 17/83）を描き、元シーンの設定を1つずつ変えた。元の設定は昼夕とも最大10・拡散4・**光沢4**・透過8・透明8・ボリューム2、Filter Glossy 1.0、間接光のクランプ10、直接光のクランプなし。
  - `base`（元のまま）、`bounces`（上限を全て64）、`blur0`（Filter Glossy 0）、`clamp0`（間接光のクランプなし）、`nobump`（水のPrincipled BSDFからバンプを外す）、`noabsorb`（水のボリューム吸収を外す）、`flat`（水の全面をフラットシェード）、`model`（以上全部）。
  - 変更は変種ごとに元へ戻し、元blendは保存しない（実行前後のハッシュ一致）。
- **モデル側**（`diagnose_water_shading_normals.py`、Blender、描画なし、約4秒）：前回までと同じGLBの粗さ・F0・乱数種の鏡面ローブ（64本と1024本）を、水の面を①幾何法線、②三角形内で角の法線を重心座標で補間した法線（Cyclesと同じ。バンプは含めない）で追跡した。①の64本は前回の `lobe_total` を全点で再現した。
- **水から出た成分の見積もり**（`summarize_water_gloss_mismatch.py`、通常のpython3、1秒未満）：水から出た終端を前回の参照（浴槽中央・水面10cm上、縁石の高さの2段の箱、幅2048、2seed平均）で引いた。幾何法線の64本では、前回Cyclesで描いた真値との差が中央値4.1%／2.7%（昼／夕、最大23〜25%）。

- 補間法線で追跡すると、水から出る重みは点11で0.100→0.010、点8で0.061→0.018に減り、見積もった成分はCyclesの鏡面の33〜34%（昼）／27〜32%（夕）に収まる。19点全体でも最大0.81倍で、1倍を超える点はない。
- 他の側面全反射の点（9・10）も補間法線では水から出る成分が1/5〜1/7になる（前回の比0.74〜0.97は、たまたま1未満だった）。底の点（0〜5）は幾何法線の0.5〜1.5倍、側面透過の点（13〜18）はもともと小さい。

## 判断

- 2点の過大予測は近似（単散乱GGX・スカラーF0）やレンダー設定ではなく、**元の水の側面・底の法線の違い**による。前回までの水の追跡の診断（経路分類・到達先・水から出た鏡面・箱の中の1経路・遮蔽）はすべて幾何法線で、**フラットシェードの水を仮定した値**であり、元のCyclesの見た目とは側面全反射の点で大きく異なる。
- 元blendの水の側面・底は、1枚の帯にスムーズシェードを掛けたもので、実際の水槽の平らな面としては不自然（意図したものかは未確認）。今後の基準をどちらにするか決める必要がある：
  1. **元blendを直す**（水の側面・底をフラットにする）。前回までの幾何法線の診断がそのまま使えるが、Cyclesの基準画像（03など）と、それに合わせた過去の比較をやり直す必要がある。
  2. **元blendのまま合わせる**。製品側の水の近似も補間法線の見え方（側面で全反射の範囲がずれる）を再現する必要があり、箱の中の1経路の設計（平らな側面）を見直す。
- 次は、この判断のあと、67点全体で補間法線と幾何法線の水から出る重み・Cyclesの鏡面を比べ、箱の中の1経路の誤差への影響を測る。

## 限界

- 19点（層化標本）・カメラ03の静止した元形状だけ。見積もりは参照を引いた値で、補間法線の終端の真値は描いていない。
- 補間法線の追跡は、Cyclesのように屈折後の向きが幾何面の反対側に回り込む場合の扱い（内外の判定）を再現していない。バンプは含めない。
- 光源・V9・夕暮れの暖色灯5灯の扱いは前回と同じ（Cycles側の鏡面には含まれ、参照・真値からは外している）。
