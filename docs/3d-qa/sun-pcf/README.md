# 夕暮れの日光：4参照PCFの候補評価

## 方法

製品は変更せず、`e2e/sun-shadow.gpu.ts` の検証ブラウザ内で方向光の影の参照だけを差し替える。通常PCSS（16+24）、硬い影（1参照）、PCF（4参照）の比較。PCFはシャドウマップの隣接4テクセルについて深度比較を行い、その結果を双線形補間する。受け側平面の傾きを各参照の深度に反映する。微分は既存どおり光源の分岐の前に計算し、スポット光・光源強度・影マップは維持する。

高画質、1200×800、DPR1、動作抑制、庭の準備完了後。夕暮れのみ。順番は通常→硬い影→PCF→通常再撮影→PCF→硬い影→通常。最初の4条件では3ステージ既定視点、既存Cycles6視点、各ステージ8方向×3俯仰角（既定角から±0.45rad、入力の上限±0.85rad）、1px（0.004rad）ずつ8回の見回しを撮影する。通常の全周撮影と異なり、45°刻み・既定角基準で、DOM演出は除外する。

GPU時間は既定3視点を各4秒＋回収待ち1秒。後ろの3条件は既定視点だけを撮影・計測する。GPU計測とほかの検証は並行しない。

`summary.json` の `motion` は「候補−通常」のLab誤差のフレーム間差であり、画面座標上での追加の揺れを示す診断値。光学フローで物体を追跡した値でも知覚的なちらつきの合否でもない。通常の再撮影で再現性を確認する。Cyclesは既存画像を600×400へ揃えた参考比較で、光や材質の完全一致を主張しない。ΔE76>0.5は弱い夕暮れの日光の変更領域を抽出するための閾値で、画質の合格線ではない。

## 再実行

```sh
SUN_SHADOW_REVIEW=1 bun run test:browser:gpu e2e/sun-shadow.gpu.ts --reporter=json > /tmp/sauna-sun-pcf.json
python3 scripts/summarize_sun_pcf.py /tmp/sauna-sun-pcf.json docs/3d-qa/sun-pcf
```

環境変数を付けない既存診断（通常／硬い影／影なし／通常再撮影）は維持する。PNGは `test-results/gpu/`（Git管理外）に保存される。

## 結果と判断（2026-09-28）

**固定幅の4参照PCFは採用しない。** 硬い影より縁の階段状の変化は和らぐが、遮蔽物との距離に応じた半影は戻らない。外気浴の見出し5の壁で、通常の淡い面状の陰影に対し候補は斜めの帯が残る。全画面の差は弱い日光のため小さいが、この画質の変化と性能の利益を釣り合わせて、今回は製品変更へ進めない。硬い影も採用しない。昼夕補間の実装・評価は行っていない。

- Chrome 154.0.8037.57、macOS headless、607.5秒、7件成功、skip・再試行・ページ／コンソールエラー0。
- 各108視点（既定3＋Cycles6＋全周72＋見回し27）×4条件、後半の性能追試3視点×3条件。通常再撮影の最大平均ΔE76は0.0000192、ΔE>0.5は最大0.00198%（最大19画素）。候補差の大きさとは十分離れているが、画像の完全一致ではない。
- 最大の差は外気浴・見出し5・既定俯仰：硬い影 平均ΔE76 0.309／ΔE>0.5が37.52%、PCF 0.276／33.64%。この閾値は画質の合否ではない。
- 見回しの追加の誤差の揺れ（Lab、平均）：サウナ 硬い影0.0637→PCF0.0530、水風呂0.0201→0.0155、外気浴0.0577→0.0450（約17〜23%減）。静止波・動作抑制下の小さなドラッグだけで、通常動作中の知覚的なちらつきの合格とはしない。
- Cycles6視点でPCFの変更領域の誤差は3視点で減少・3視点で増加、平均ΔE76の差−0.0185〜+0.0227。方向は一貫せず、Cyclesへの改善を根拠にはできない。新しいCyclesレンダーは行っていない。
