# 足元灯の光だまりと林の影の帯・水風呂の明るさの確認（2026-10-13）

## 足元灯の光路（変更）

Cyclesのブルーアワー（07）では、`V10 path grazing light 1/4/7`（各8W・直径0.28m、飛び石の脇の地面すれすれから+x方向へ照らす）が飛び石に光だまりを作る。足元灯を加えたとき（`../dusk-light/`）はWebにも小さく出ていたが、今回の撮影では消えていた。

- 原因：`gardenDetails.ts` の低木群（中心 (-0.5, 5.7)、株は中心から約1.2m・葉はさらに約0.8m広がる）が灯7を囲み、灯4の前にもかかっていた。灯の光は葉に当たり、飛び石の代わりに低木が黄緑に光っていた。さらに灯籠 (-0.9, 4.7) が灯7から手前（カメラ側）の飛び石への光を遮っていた。灯の位置で地形・飛び石の高さを測ると、灯は地面に埋まってはいない（飛び石の天面の方が低い）。
- 変更：低木群を (-3.4, 3.6)、灯籠を (-1.9, 4.3)（灯7の背後）へ移した。`lighting.ts` の `FOOTLIGHTS`・`FOOTLIGHT_DIRECTION` に灯の位置・向きを出し、`gardenDetails.test.ts` が灯から±60°・上向き3段の光線が2m以内で影を落とす追加物に当たらないことを検査する（旧配置では灯籠の石に当たって失敗することを確かめた）。
- `compare-07-evening.jpg`：上からCycles（ブルーアワー参照）／変更前／変更後。モミジの幹の脇の飛び石2つに光だまりが出た。Cyclesの手前左の飛び石の光だまりは出ていない（原因未確認）。`intermediate-shrubs-only.jpg` は低木群だけ移した途中の版（光だまり1つ）。
- `composition.jpg`：外気浴の昼・夕暮れ、サウナの昼（左が変更前）。外気浴ではモミジの右の低木と大岩脇の灯籠がなくなり、飛び石の小径が見通せる。

## 手前左の飛び石の光だまり（調べたが変えていない）

07の画面に光源を投影すると、Cyclesの手前左の光だまり（900×600で約(185,460)）は足元灯（436〜606）ではなく、デッキの外縁の `V10 concealed deck edge 4.4`（12W・直径0.65m、(4.4, −0.04, 3.86) から+z・やや下向き）の位置（195,474）に当たる。右の光だまりには `deck edge 0`（612,416）も重なる。この3灯はブラウザで描かない光源で、元blendではカメラに不可視・拡散と光沢には可視。拡散の直接光は1m格子の照度プローブに焼き込まれてぼけるため、鋭い光だまりにならない（光沢は水面の鏡像だけ、`glossyLights.ts`）。

- 試作（`rejected-deck-edge-lights.jpg`、上からCycles／現行／試作）：3灯を影なしのスポット光（`P/π` cd・90°円錐・余弦配光）として足すと、手前左の飛び石は照らされず、灯の前の庭の追加物（低木群 (3.8, 6.3) の株・揺れる草）が光った。
- 採らなかった理由：(1) この3灯の直接光は照度・反射プローブに入っているので、ブラウザでも描くと二重になる。正しくはこの3灯を「ブラウザで描く光源」としてプローブを焼き直す必要がある（昼夕夜、Blenderで1時間以上）。(2) 影を落とす灯は影マスクの上限7灯に達しているため影なしになり、庭の追加物を通り抜けない。(3) 3灯ぶんの照明計算が全画素のシェーダーに加わる。

## 林の影の帯（調べたが変えていない）

晴れの昼、外気浴から見た草地の稜線に、林の影が灰色の帯として横切る（帯 (50,57,47)、日なた (71,83,60)、夕暮れは差なし）。Cyclesの元の昼（07）にはない。晴れの昼の補正（`CLEAR_DAY_SUN` 2.2倍、`../clear-day/`）で日光だけが強くなり、空と照り返しを焼き込んだプローブは元のままのため、影の部分だけが相対的に暗く青灰色になる。

- 不採用：晴れの昼だけ屋外のプローブを1.3倍にする案（`rejected-clear-day-bounce.jpg`、左が変更前）。帯と日なたの比はGで0.69→0.72と小さく、日なたも明るくなって晴れの陰影が弱まるだけだった。プローブは空と照り返しを分けて持たないため、照り返しだけを強めることはできない。
- 強い日差しの下の林の影としては自然な見え方なので、そのままにした。

## 水風呂まわりの明るさ（確認のみ）

最初の提案で「水風呂まわりが暗い」としたのは、照度プローブ導入前の記録（bh-03でCyclesより−4.8 L*）に基づいていた。今回のCycles同視点（`tone-stats.txt`）では、水風呂の夕暮れbh-03がCycles 26.7／Web 26.5、夜n-03が25.1／24.1、昼03が46.6／52.0（昼は晴れの補正で全体に明るい）で、暗さは解消している。07の夕暮れが+14 L*と大きく出るのは、ブルーアワーの参照画像の空が空のノード（`build_sky_world.py`）を入れる前の一様な紺で、Webの夕焼けの空と違うため（地面・木の明るさの差ではない）。
