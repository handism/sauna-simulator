# 林の樹冠の密度と外気浴の視点（2026-10-12）

## 課題

- 林の木（`V6 woodland leaf N card`、5材質・約3.8万枚のカード）は、枝先に小さな房が点々と付くだけで、夏の昼でも枯れ木のように見えた。前回（`../woodland-haze/`）カードを1.35〜1.65倍に広げたが、まだ枝の間が抜けていた。
- 外気浴の既定視点では、パーゴラの柱（`Facade_mullion`、カメラから約2.8m）が画面の中央付近を縦に横切り、主景のモミジの幹（約7m先）とほぼ重なっていた。

## 変更

- `woodlandCrowns.ts`：元のカードの拡大を1.15〜1.35倍に抑え、各カードの脇（カードの大きさの0.3〜0.5倍ずらす）に、面内で50〜130°回して±20°傾けた複製を1枚足す（`CROWN_FILL_COPIES`）。複製は元のカードのUV・法線をそのまま持つので、同じ明るさで照らされる。ずらしは位置から決める。描画数は変わらず、林のカードの三角形は7.7万→15.4万になる。影・深度プリパス・影マスクは同じ形状を共有し、冬は元のカードと一緒に隠れる。
- 試した候補（外気浴の昼。比較は `compare-totonou-summer.png` など。上が変更前、下が変更後）：
  - カードを3倍に拡大：樹冠は埋まるが、葉が粗く、半透明のもやに見えるため不採用。
  - 複製1枚・傾き±35°：傾いた複製が灰色の半透明に見えたため、傾きを±20°にした。
  - 複製2枚・傾き±20°：最も密だが、屋外のフレーム費用が+17〜26%（下表とは別の2組）になるため不採用。
  - 複製1枚＋拡大1.35〜1.65倍：+11〜18%。
  - **複製1枚＋拡大1.15〜1.35倍（採用）**：見た目は前の候補とほぼ同じで、費用は小さい。
- `scripts/web_scene.py`：外気浴の視点を Blender座標で (4.3, 2.0, 1.48)→(2.8, −6, 2.3) から (4.86, 1.79, 1.48)→(4.2, −6.2, 2.3) に変更した（寝椅子の中央寄りへ0.56m、左へ約6°振る）。左右の柱が画面の両端に来て庭を囲み、モミジの幹・小川・灯籠が柱に隠れない。向きだけ変える案（左14°・右30°）は柱がモミジに重なるか、水風呂の縁が画面を占めた。`public/models/sauna.scene.json` と `docs/3d-export/export-report.json` のハッシュを再生成した。GLB・プローブ・Cyclesのカメラは変更しない。

## 確認

- `garden-details.e2e.ts`（標準画質・1280×800・動作抑制）で3ステージの昼と、外気浴の四季・夕・夜・雨を撮り、`../clear-day/` と目視で比べた。冬は複製も含めて落葉し、水風呂からの林も密になった。
- 単体テスト（`woodlandCrowns.test.ts`：複製の数・位置・UV・法線・インデックス・2回目の処理の無効化）、型検査、Lint、整形。通常のブラウザ回帰の結果は進捗記録に書く。
