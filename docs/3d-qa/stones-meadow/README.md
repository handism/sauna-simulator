# 庭石の質感と中景の草地（2026-10-21）

## 動機

外気浴の入室視点で、庭石・飛び石・せせらぎの石・縁石がどれも同じ明るい灰色の滑らかな面に見え、CGらしさの主因になっていた（`stone` の色の振れ幅は±7〜9%だけ）。草地は、草の葉（`meadowGrass.ts`）が終わる原点から16m先から林まで、斑だけの一様な緑で、刈り込んだ芝のように見えていた。

## 変更

- `surfaceDetails.ts` の `stone`：石より広い約1m周期の暖色寄り／寒色寄りの色味、数cm〜数十cmのまだら（±20%）、約3cmの黒い鉱物の粒（`suiSurfaceMask`、画素より細ければ被覆率0.1へ）、下向きの面ほど暗く（最大0.65倍）。
- 名前が `charcoal stone` で終わる材質だけ（`SUI_STONE_MOSS`）：肩・側面ほど多く、平らな上面は0.15倍の苔と、小さな淡い地衣類の点を付ける。室内・デッキ・水風呂とその縁・高さ1.2m以上（`MOSS_FREE`）には付けない。白い舗石（`pale mineral paving`）は苔なし。
- `ground`：数十cm〜1mの株のむら（±27%）と、視線が浅い所ほど葉の側面・先端の明るい黄緑を足す。
- `meadowGrass.ts` の `meadowTufts()`：原点から11〜15mで現れ33〜40mで消える丈20〜48cmの野草の株（14,113枚・約4.2万三角形）を、数m周期のまとまりに置く。遠い葉は幅を距離×0.0016以上にする。別メッシュ `Garden meadow tufts` にして冬は隠す。

## 試して採らなかったもの

- 苔の初版（上面の0.35倍・広い被覆・明るい緑）：庭石の頂部が緑の帽子のようになり、デッキ上の石のテーブルとせせらぎの石がほぼ緑になった。被覆を絞り、平らな上面を0.15倍にし、色を暗くして、デッキを除外した。
- 地衣類の点の初版（約9cm・0.55）：庭石に白い斑が浮いて鳥のフンのように見えたため、約4cm・0.4にした。
- 野草の株の冬の表示：雪原に暗い株の点が並び、うるさく見えたため冬は隠した。
- 株の初版（まとまりの間4割・密度1.6）：まばらな細い筋が散って毛のように見えたため、間を4%・密度2.6にしてまとまりに集めた。

## 見回し中のちらつき

`resolution-shimmer.visual.ts`（`playwright.forest.config.ts` の `FOREST_REVIEW=visual`、`SHIMMER_FIXED=1 SHIMMER_CONTROLLED=1 SHIMMER_RATIOS=1.5 SHIMMER_QUERY='&camera=review'`、1200×800・DPR1.5・標準、3ステージ×昼夕）を、変更前→後→後→前の順に撮った。before系は `FOREST_BASELINE_DIST` に変更前のdistを渡す（`forest-build.ts` が照合する `farForest.before.ts` は変更のない `farForest.ts` の複製）。切り分けとして、株だけを隠した一時ビルドも1回撮った（コードは戻し、最終ビルドのハッシュが一致することを確認）。

- 同じ版の2回の値は全視点で一致した。
- 面の残差（変更前比）：外気浴の昼1.033倍・夕1.019倍、サウナ1.008〜1.011倍、水風呂1.000〜1.012倍。増えた所は画面下半分の草地（林の下の帯）。株なしの一時ビルドは外気浴の昼1.014倍・夕1.016倍で、外気浴の昼の増分の約半分が株、残りは地面・石の質感。
- 同じ画像を往復で写し直した対照（`trip`、補間誤差）も同じだけ増えた（外気浴の昼1.035倍）。画素の残差÷対照は変更前1.817・変更後1.812・株なし1.813（外気浴の昼。他の視点も±0.005以内）で、増分は細部が増えた分の補間誤差に見合い、葉の出入り（点滅）の増加は見られなかった。
- 制御撮影の比較で、実時間の知覚的なちらつきの合否ではない。

数値は `values.json`。画像（`before/`・`after/`・`compare-front.png`）はローカルのみ。
