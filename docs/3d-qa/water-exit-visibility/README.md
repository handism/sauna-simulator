# 水中の遮蔽を焼き込んで水から出た鏡面を補正できるか（2026-09-26）

前回の[少数の方向で引く場合の本数と誤差](../water-exit-sampling/README.md)の次の課題「ローブが水面まで遮られずに届く割合（水中の遮蔽率）を場所ごとに焼き込んだ場合、青銅・側面近くの誤差がどこまで下がるか」を測った。**製品・配信データは変更していない。暗い帯の修正は未完了。**

## 測定条件

- 真値・参照・推定は前回と同じ（`water-capture-radiance` の真値、浴槽中央・水面10cm上の参照を幅128、箱の中の1経路、Hammersley 4096本＝収束、N=8/16は32試行）。候補ごとに、各ローブ標本の重みに係数を掛ける。
- **焼き込み**（`diagnose_water_exit_visibility.py`、Blender、約2分）：到達点67点と周囲の格子点で、全球2048方向（Fibonacci）を元の水形状・シーンに両分岐で通し、水から出た重み T（水上の物体・空に届いた終端の重みの和）を記録した。到達点で焼いた T を真値の64本のローブで最近傍方向に積分すると、真値の出る量と一致した（抜き出した25点で差0.008以内）。
- **候補1：方向ビンの比**。八面体マップ1×1（スカラー）〜8×8のビンごとに T と箱の経路の出る量 B（同じ2048方向、本スクリプトで計算）を合計し、三線形の重みで ΣwT／ΣwB を係数にする。到達点そのものの値と、3D格子（水の箱をxyに2cm広げ、基壇0.2mを含む0.185mから水面まで、セル中心、間隔5/10/20cm）の値。格子は到達点の補間に使う角だけ焼いた（267/233/141点。全体なら42,900/5,544/714点）。裏面に当たる方向が25%を超える点（形状内、16/22/15点）は補間から除く。
- **候補2：床の地平線マップ**。床の到達点61点（法線が上向きから45°以内、青銅13・タイル48）で、床の1mm上から方位16方向×仰角1°刻みのレイを飛ばし、水の箱の内側（2mm内側）の物体に当たる最高仰角を地平線とした。浴槽の壁は箱の側面の経路が扱うため遮蔽に数えない。到達点そのものの値と、xyの床格子（水面から下向きのレイで床を拾う、間隔2.5/5/10cm、全体14,170/3,575/924テクセル）の双線形。方位8は16の1つおき。地平線より下の標本を捨てる。
- **候補3：青銅の一律係数**。青銅は水上からの光を0にする、または他の青銅点の T／B の合計比（leave-one-out、全点では0.32〜0.33）を掛ける。
- 材質群：タイル49点、石5点、青銅11点（青銅13点のうち2点は水から出る光がなく誤差の母数から除く）。Combined比は19点のうち水から出る光のある17点（タイル6・石4・青銅7）。

- **3D格子はどの間隔・ビン数でも青銅を直さない**。モデルと追跡の出る量の比（青銅、中央値／90百分位）は補正なしで2.9／25倍、格子5〜20cmでも3.0〜3.2／25〜33倍のまま。タイルでは方向ビンを増やすほど悪化する（10cm・8×8で90百分位59%）。
- **到達点そのもので焼いても、8×8のビン（1ビン約25°）では細い青銅のローブ（粗さ0.3、α=0.09）に対して粗すぎる**。出る量の比は1.66／5.4倍に下がるが、真値には届かない。全球の1×1スカラーは壁の石で11倍の過大になる。壁と水の側面の間の空気の隙間から出る方向（箱では出ない）まで平均するためと考えられる（未検証）。
- **原因は目地の面取り**。青銅は、タイル（`Individual submerged tile`）の目地の隙間から見える基壇（`V8 recessed pool plinth`、0.200m。タイル上面は0.202〜0.203m）だった。青銅13点のうち9点はタイルから0.3〜5.1mm、残り4点は奥の壁ぎわ（y≈4.10m、タイルから31〜35mm）。到達点58では仰角25〜45°の方向が0.2〜0.3mm先のタイルの面取り（法線が15°傾いた縁）に当たる。追跡の T では方位45〜135°が仰角約48°まで遮られるが、1mm上から測った地平線は31°にとどまり、面取りを取りこぼす。
- 地平線マップは2.5cm格子で青銅の中央値を35〜42%に下げるが、90百分位は29〜48倍で、5cm・10cm格子では目地を捉えられず効果がない。タイルの誤差は変わらない（N=8でも中央値12%／90百分位38〜46%のまま）。
- 青銅は水上からの光を0にすると、Combined比の中央値が40%→18%（昼）、56%→28%（夕）に下がり、17点全体の90百分位は98%→31%、127%→44%になる。残る90百分位（129〜170%）は1点（到達点38＝前回の19点のうち8番）で、真値自体がCombinedの2.5〜3.6倍になる既知の過大予測による。一律係数（0.32前後）は0より良くならない。
- 静止波の法線でも傾向は同じ（タイル補正なし6%/25% ／ 7%/32%、青銅0でCombined比18% ／ 28%）。

## 判断

- **水中の遮蔽の焼き込み（3D格子・床の地平線マップ・方向ビンの比）は採用しない**。タイル・石は補正なしで既に正確な追跡並み（Combined比1〜2%以内）で、補正すると補間・ビンの誤差で悪化する。青銅の遮蔽はmm規模の目地にあり、2.5cm以上の格子や1mm上からの地平線では表せない。
- 製品で水から出た鏡面を入れる場合は、**タイル・石は前回の「箱の中の1経路・8〜16本」のまま、青銅（`Blackened bronze` の水中の基壇）は水上からの光を足さない**のが最も単純で誤差も小さい。材質で切り替えればよく、追加のテクスチャは要らない。
- 次は、製品に入れる前に、前回から残る「2点（19点の11・8）で予測が鏡面パスの3〜8倍」をCyclesの光沢パスと突き合わせて原因を切り分ける（今回の青銅0の残差もこの点）。その後、シェーダーの試作でGPU費用と1画素の雑音を測る。

## 限界

- 到達点67点・カメラ03の静止した元形状だけ。焼き込みは到達点の補間に使う格子点だけで、全体の格子の容量・継ぎ目・GPUでのフィルタは評価していない。
- 方向は2048方向（約4.5°間隔）の固定集合で、ビン・地平線は1通りの作り方（八面体の点サンプル、方位の線形補間、仰角1°刻み、床の1mm上、形状内の判定は裏面25%）だけ。
- 製品のGLBの目地の形状（Decimate後）が元形状と同じかは確認していない。
- 真値・ローブの重みの近似（単散乱GGX・スカラーF0・幾何法線・滑らかな水）と、既知の2点の過大予測は前回と同じ。
