# 水風呂の床の照度を元シーンのクランプどおりに焼く（2026-09-27）

[水の底面での部分反射](../water-bottom/README.md)の残件「昼は水中のタイルがCyclesより明るい（昼の見下ろし全体で約+7 L*）」の原因を特定し、水中の照度プローブの焼き方を変えた。

## 原因の特定

測定値は [measurements.json](measurements.json)。元blend（SHA-256 `f1ee4ddd…`）、Blender 4.5.11 LTS、水風呂の見下ろし（見出し1）640×400。

1. **光源グループ別に分解**：Cyclesのライトグループ（空・日光・V7・V9・夕暮れの寝椅子灯・その他の灯・水中の疑似コースティクスの発光・その他の発光）で描くと、昼の水面の画素（Combinedの平均輝度0.150）の**76%がV9**（寝椅子上の950Wの円盤光、水面越しにタイルを照らす）だった。ブラウザの線形の値（トーンマッピング前を x/(1+x) で書き出して戻した値）は0.237で1.58倍。コースティクスの発光はCycles 0.0085・ブラウザ0.0082で一致。画面を区切ると、ブラウザとCyclesの比はV9の割合が大きい所ほど大きく（割合0.7で約1.5倍、0で約1.0倍）、過大はV9の分だけにあった。
2. **タイルの照度そのもの**：水をカメラからだけ隠して描いたタイルの `π·(DiffDir+DiffInd)` は平均1.23。配信中の水中グリッド（パノラマで焼いたL2）をCPUで同じ点に補間すると1.70（1.38倍）。
3. **測り方の差**：焼き込みと同じパノラマで、タイル直上の空気層（底面の下）と水中0.33mで測ると1.5〜1.9で、高さによらずグリッドと同程度。つまりタイルの位置のパノラマでもタイル自身の照度より明るい。元blendの間接光クランプ10を外すとタイルの照度は中央値1.69になり、パノラマの値と揃う。Filter Glossy 1.0を外すと0.74まで下がる。V9は水面の屈折を経てしか届かず、タイルの拡散反射の後の経路はクランプ（アルベド×放射輝度の和が10まで）と光沢フィルタを受けるが、パノラマのカメラレイが水面越しにV9を見る経路はどちらも受けない。

## 方式

`bake_irradiance_probes.py` の水中グリッドだけ、照度をパノラマの代わりに**拡散球**で測る。

- 各プローブ位置にタイルと同じアルベド（見下ろしのタイルのDiffColの平均 (0.109, 0.290, 0.254)、クランプはアルベドを掛けた値に効く）の半径4mmの拡散球を置き、カメラレイにだけ見せる（ほかの光線には不可視なので互いに干渉しない）。水はカメラからだけ隠す。球の5mm手前から6方向の正投影（32×32画素、256サンプル）で描き、DiffDir+DiffIndの画素と法線からL2で照度を当てはめて、放射輝度の係数として保存する。Positionパスで球以外が写った場合は無効にして近傍から埋める（今回0件）。
- 球を描画ごとに動かすとCyclesがシーンを同期し直す（1枚約12秒）ため、全プローブに球を置いたままカメラだけ動かす。1枚は約4秒で、昼夕168点の焼き込みは約2.3時間。
- 64サンプル・固定の乱数種では1点の雑音が約±10%で、しかも全プローブで同じ雑音が繰り返されてグリッド全体が約1.16倍に偏った。描画ごとに乱数種を変え（永続データでは出力パスも変える）、256サンプルにした。
- 下の層をタイル（0.202m）と水の底面（0.215m）の間の空気層 y=0.2085m に移した（上の層は0.66mのまま）。床は底面を通った後の光を受けるため。水中0.33mの拡散球はタイル直上より約14%明るい（底面での反射と、底面での屈折が光沢フィルタ・クランプの結果を変える分）。
- ブラウザは水中グリッドを**法線方向にずらさずに**読む（`irradiance.ts` の `suiGridSH` の `offset`、ほかのグリッドは従来どおり半間隔）。水中のプローブはすべて有効で、床は自分の高さの層を読む。`probe_sampling.py` も同じ規則にした。
- 反射プローブの水中グリッドは配置を合わせてパノラマのまま焼き直した（照度と反射は同じ配置が必須）。水の底面での部分反射（`waterBottom.ts`）が見る反射プローブは水上のグリッドなので変わらない。

## 結果

## 残る差

- 昼の見下ろしは全体でまだCyclesより+3.4 L*明るい。タイル上の照度は1.06倍まで合ったので、残りは照度以外（水面の反射・床の光沢・吸収など）か、0.5m格子でV9の当たる範囲の形が表せない分（点ごとの比は10〜90百分位で広く散る）。未切り分け。
- 拡散球のアルベドはタイルの平均。クランプはアルベドに比例して効くため、水中の石の内壁・青銅の基壇ではタイルと同じ値を使う近似になる。
- 空気層の拡散球はタイルの実測より約5%明るい（3点とも1.05倍前後、1024サンプルでも同じ）。球の高さ（6.5mm上）か残る雑音かは未確認。
- 反射プローブ（パノラマで焼く）にも同じクランプの差があり得るが、今回は扱っていない。

## 検証

型検査、35ファイル188単体テスト、Python 103テスト（今回1件追加）、Lint、整形、本番ビルド。ブラウザ回帰は13件中12件成功、`scene-viewport.e2e.ts` の1件は矢印キー後の描画の変化を5秒以内に検出できず失敗（全体3分）。**HEADのworktreeでも同じく失敗する**ため今回の変更による回帰ではないが、前回セッションでは成功しており、この機械の現在の状態での既存の失敗として残す。ステージ視点・Cycles同視点の撮影成功（変更前はHEADのworktree）。Blender 4.5.11 LTS正常終了（焼き込み2本、元blendのハッシュ一致）。5分継続検証は、この機械では変更前でも失敗することが分かっているため実行していない。
