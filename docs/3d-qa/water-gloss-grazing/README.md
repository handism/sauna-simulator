# 側面の像のタイル光沢：浅い角度の円盤の広がりと遮蔽（2026-09-30、不採用）

[前回](../water-gloss-capture/README.md)の残件「真っすぐの部分の光沢が斑の外で1.5倍強い（像の経路の遮蔽・着色の差を入れていない）」を切り分けた。量の差は像の経路の遮蔽漏れでほぼ説明でき、形の差は製品の円盤の広げ方が浅い角度で破綻していることが分かった。広げ方を直した試作は撮影でCyclesから離れたため**製品は変更しない**。

## 方法

- `scripts/diagnose_water_gloss_grazing.py`（Blender不要、約1分15秒）：前回と同じ2切り出し（夕暮れの見下ろし・見出し2）の真っすぐの部分の5×5ブロック（1,013・938個）で、平らな水の箱で追った床の点・空気層の視線から、寝椅子灯の円盤を側面で折り返した屈折経路で厳密に積分する（`exact`、側面のFresnel・両面の透過・出口と縁石の判定、着色・遮蔽なし）。製品の式（`round`：像から中心への屈折経路の向き、点光源、GGX α'² = α² + 0.25(r/d)²）と試作（`aniso`、下記）を並べ、Cyclesのタイル光沢（[元シーンの切り分け](../water-gloss-scene/README.md)の `source`、浴槽外を隠した `rim`、縁石も隠した `bare`）と比べる。床の20×24格子で直接の経路も比べる（[床のハイライトの近似](../water-floor-disk/README.md)と同じ積分）。値は [grazing.json](grazing.json)。
- `scripts/diagnose_water_gloss_image_occluders.py`（Blender、描画なし）：真っすぐの部分の60点（`rim` が0.01超から無作為）を x最小の側面で鏡映し、像から円盤216点への厳密な屈折経路のうち側面の先・水の中で水面を出るものを、出口から灯りへ飛ばして最初に当たる物体を数える。円盤の中心だけ（製品の影マップが見るもの）も調べる。値は [image-occluders.json](image-occluders.json)。
- ブラウザ撮影は `e2e/water-gloss-capture.visual.ts`（前回と同じ）で、HEAD・試作2種を `summarize_water_gloss_capture.py` で集計した（[capture.json](capture.json)）。

## 分かったこと

### 量：像の経路の遮蔽は影マップに入らない

真っすぐの部分の光沢の平均（線形の輝度）：

| | 見下ろし | 見出し2 |
| --- | ---: | ---: |
| ブラウザ（HEAD） | 0.0298 | 0.0362 |
| Cycles `source` | 0.0188 | 0.0240 |
| Cycles `rim`（浴槽外なし・着色なし・平らな水） | 0.0298 | 0.0353 |
| Cycles `bare` | 0.0316 | 0.0378 |
| 厳密積分（遮蔽・着色なし） | 0.0422 | 0.0509 |

- ブラウザは浴槽外の物体がないCyclesとほぼ同じ。`source`/`rim` は0.63／0.68で、どの層でも0.55〜0.72（[層別](grazing.json) `byExact`）。
- 像の経路の遮蔽物（円盤216点×60点、12,960本）：天蓋の梁 9.5%、細いルーバー（.005〜.013）計9.7%、縁石 3.5%、青銅の柱 0.2%。円盤の見える割合は平均77%。**円盤の中心は60点すべてで見える。** 製品の影は中心1点の影マップ＋PCSSなので、細い梁が円盤の一部だけを隠すこの遮蔽は入らない（前回「出口で影を引いても値がほぼ1」だった理由）。
- 点ごとの幾何の見える割合と `source`/`rim` の相関は −0.64。光沢のローブが向く円盤の部分が隠れるかで決まり、幾何の割合を掛けるだけでは合わない。

### 形：浅い角度では円盤が半ベクトルで楕円になる

像の経路は灯りを約72°の浅い角度で見る。灯りの向きを変えたときの半ベクトルの動きは、灯りと視線の面の中では半分、その面を横切る方向では 1/(2 l·h) 倍（l·h ≈ 0.3で約1.6倍）。製品の式は前者だけを仮定しているため、ピークが厳密値の1.6〜1.8倍に尖る。

| 真っすぐの部分 | 平均 | 最大 | 厳密値との比 | 厳密値との相関 | Cycles `rim` との相関 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 厳密積分 | 0.0422 | 0.135 | 1 | 1 | 0.68 |
| 製品の式 `round` | 0.0358 | 0.224 | 0.85 | 0.905 | 0.61 |
| 試作 `aniso` | 0.0341 | 0.114 | 0.81 | 0.976 | 0.60 |
| ブラウザ（HEAD） | 0.0298 | 0.202 | 0.71 | 0.885 | 0.57 |

（見下ろし。見出し2も同じ傾向。）試作 `aniso` は、その横切る方向だけ広がりを (l·h)² で割った異方性GGX（可視項はタイルの粗さのまま）。床格子の直接の経路では、寝椅子灯の相関が0.917→0.949（屈折経路の向きと併用で0.914→0.978）、V9は0.998のまま。

ただし**厳密積分とCyclesの相関は0.63〜0.68しかない**（平らな水・浴槽外なしの `rim` でも）。厳密値の上位10%のブロックでCyclesは厳密値の0.3〜0.4倍（`source`）・0.4〜0.5倍（`rim`）で、その1つ下の層より暗い。Cyclesの山は解析よりなだらかで位置がずれる。平らな箱の対応づけのずれ（前回の中央値1.7〜2.3cm）だけでは説明できず、原因は未特定。

### 撮影：形は近づくが斑が暗くなる

`suiWetSpecular` の広げ方を異方性に替えた試作（`aniso`）と、直接の経路も中心への屈折経路の向きにした試作（`aniso-refracted`）を撮った。見下ろし（見出し2も同傾向）：

| | 斑のタイル光沢 | 真っすぐの部分 | 側面の像の部分 | 自分の斑の全体 | 5×5相関 | 光沢の重心y |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| HEAD | 0.0893 | 0.0299 | 0.0407 | 0.4491 | 0.670 | 76.8 |
| `aniso` | 0.0641 | 0.0283 | 0.0361 | 0.4164 | 0.653 | 69.1 |
| `aniso-refracted` | 0.0670 | 0.0283 | 0.0384 | 0.4190 | 0.666 | 65.6 |
| Cycles | 0.0850 | 0.0186 | 0.0393 | 0.4534 | | 61.4 |

光沢の重心はCyclesに近づき、真っすぐの部分のピークは0.20→0.10になったが、斑の光沢が25%（屈折の向きと併用で21%）落ち、斑の全体が0.03暗くなる。斑の外の余分（遮蔽漏れ）はほぼ残る。HEADの斑がCyclesに合っているのは、尖りすぎ（×1.6）・直線の向きによる不足（×0.66）・遮蔽漏れ（×1/0.7）の打ち消し合いで、どれか1つだけ正しくすると離れる。[床のハイライトの近似](../water-floor-disk/README.md)（不採用）と同じ構図。

## 判断と残件

製品は変更しない。試作の差分（`waterBottom.ts` の `suiDiskGGX`・`diskGgx`、直接の経路のNewton法、テスト）はGit管理外の `blender/diagnostics/water-gloss-grazing/grazing-refracted.diff` に残した。

斑の形と明るさを同時にCyclesへ寄せるには、次の3つを揃える必要がある：(1) 円盤の一部を隠す細い遮蔽（中心1点の影マップでは出ない。像・直接の経路とも）、(2) 厳密積分とCyclesの分布の差（平らな水・浴槽外なしでも相関0.68）の原因、(3) 前回の `bare` で出た、Cyclesが解析より斑で強い分。(2) が分からないうちは、(1) を焼き込み等で入れても合う保証がない。撮影の斑の平均（8bit）は現在、夕暮れでCyclesと0.4以内、夜で+1.5〜1.6で、ここから先は費用に見合う改善かを先に判断する。
