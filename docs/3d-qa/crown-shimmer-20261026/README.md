# 林の樹冠の見回し中のちらつきの切り分け（2026-10-26、製品の変更なし）

改善候補の2番目。`6f36425` のビルドで、残りのちらつきがどこから来るかを切り分けた。Chrome 155、`resolution-shimmer.visual.ts`（1200×800・DPR1.5・標準・段1.5固定・`SHIMMER_CONTROLLED=1`・`&camera=review`、3ステージ×昼夕）。比は同じ方式で撮った製品に対する面の残差（8 CSS px）の中央値（範囲）。各条件1回撮影。

## 残差の場所

原寸の残差図（外気浴の昼、右の樹冠）では、明滅は樹冠と空の境目ではなく、樹冠の内側に1画素ずつ散らばっていた。前後のフレームを6倍に拡大して並べても見た目の違いは分からず、L*で数段階の粒だった。画素の残差は往復の補間誤差（対照）の1.3〜1.9倍で、ゆっくりした見回しでは補間誤差に近い。

## 一時ビルドの切り分け

| 条件 | 面の残差の比 | 備考 |
|---|---|---|
| マスクが合わない画素（硬い影の1回参照）を影なし | 1.06（1.01〜1.20） | 増えた。硬い影への切り替えは原因ではない |
| 影マスクを読む材質の影をすべて外す | 0.96（0.83〜1.04） | 影の寄与は小さい |

| TAAの制限幅 1.25→3.0 | 0.91（0.86〜0.94） | 同上 |
| 制限幅3.0＋履歴の重み0.9→0.95 | 0.84（0.79〜0.90） | 往復誤差が約1割下がる（見回し中の像がやわらかい） |

1フレームに6 CSS pxの速い見回しでは、TAAなし（`&temporal=off`）に対して製品は面の残差を約0.43〜0.50倍にしていた。

## 判断

- 残りのちらつきは影・空との縁ではなく、葉の重なりの細かな明暗が画素の格子をまたぐことによるもので、TAAの設定で減らせるのは制限幅で数％、それ以上は重みを上げて見回し中の像をやわらかくする引き換えになる。
- 制限幅2.0は静止画を変えず（現在の画素を必ず箱に含める）、往復誤差も変わらないが、動くもの（雨・草・水）の残像は確かめられていない。動作抑制なし・雨・時刻を進めた撮影を試したが、水の時刻の起点が読み込みごとに違い、波の模様そのものが変わって比較にならなかった。雨筋はTAAありの両方で薄くなり、目で見た差はなかった。
- このため製品は変えていない。採るなら、動くものの時刻をそろえた残像の確認と、実機での目視が先に要る。
