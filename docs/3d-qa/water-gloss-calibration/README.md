# 寝椅子灯とタイルだけで光沢の式を較正（2026-09-30）

[前回](../water-floor-disk/README.md)の残件「解析とCyclesに約2倍の説明できない差がある」について、光源の値の換算と材質の式を切り分けた。**光源の換算は一致。Schlick近似による差はあるが、この条件では約15%であり、約2倍の差を説明しない。製品は変更しない。**

## 条件

`scripts/diagnose_water_gloss_calibration.py` が元blendを読み、新しい診断シーンに寝椅子灯のコピーと高さ0.202mの平面だけを置く。元blendは保存せず、実行前後のSHA-256一致を検査する。

- Blender 4.5.11 LTS / Metal。96×96、2048 samples、seed 17 / 53、デノイズ・適応サンプリング・直接／間接クランプなし。黒いWorld。水・縁石・他の形状なし。
- 光源：元の42W・色(1, 0.7, 0.39)・直径2mの正規化された円盤、spread π。コピーのカメラ／光沢／拡散可視性を有効にする。放射輝度の換算は `power × color / (π × 面積)`。
- 元のタイル材質の下地を黒にする（粗さ0.3、IOR 1.5、Specular IOR Level 0.5、MULTI_GGX）。白いLambertの別材質で光源の換算を検査し、タイルのGGX単散乱版でも比較する。
- 平面の中心(1.18, 2.5, 0.202)、光源の中心を鏡映した方向から正投影（幅2m）。視線の上向き成分0.3906。7×7の49画素についてPositionパスの位置で円盤を立体角積分する。
- 積分は401×401方向。201×201との合計差は0.01%未満。全49点・両seedのRGB線形値、条件・ハッシュは [calibration.json](calibration.json)。画像はローカルの `blender/diagnostics/water-gloss-calibration/`。
- **測定は `Combined_lamp` の光源別パス。** 元のタイルには発光する模様がある。初回のCombined全体による約20%の差は発光の混入だったため破棄した。最終画像でも模様が除かれたことを確認した。

## 結果

値は49点のRGB合計の Cycles ÷ 解析。L1は2 seedの平均と解析との差の絶対値合計 ÷ 解析合計。

| 比較 | seed 17 | seed 53 | 相対L1 |
| --- | ---: | ---: | ---: |
| 白いLambert（光源換算） | 1.000038 | 1.000021 | 0.0113% |
| 元タイル / Three相当のSchlick Fresnel GGX | 1.147808 | 1.147841 | 14.7824% |
| 元タイル / 厳密な誘電体Fresnel GGX | 1.003300 | 1.003329 | 0.3318% |
| 単散乱タイル / 厳密な誘電体Fresnel GGX | 0.999923 | 0.999952 | 0.0680% |

この水を通さない単一視線の条件では、光源の換算は一致し、Fresnelの近似の差を取り除くと元の材質との差は0.33%になる。単散乱にするとさらに一致するため、残りの0.33%は多重散乱の影響と整合する。約15%を製品全体へ掛ける補正はしない。角度依存の差であり、水を通った斑の位置・分布の一致を検証した結果でもない。

## 判断と次の作業

前回の水越しの解析は既にCyclesより1.5〜1.6倍強かった。厳密Fresnelで光沢を強くするとその差を広げる方向になる。したがって明るさの換算ミスを仮定した製品の補正は見送る。

次は同じ光源・タイルの診断に平らな水の層を加え、カメラから水を隠した条件（光源側の屈折だけ）と通常の水越しを比べる。透過率・視線と床の対応・クランプを一つずつ加えて、どこで差が生じるかを測る。今回の結果だけでは、波・側面反射・縁石の遮蔽・クランプの寄与は判定できない。
