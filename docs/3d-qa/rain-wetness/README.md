# 雨の地面の濡れ（2026-10-12）

## 課題

雨の天気でも、デッキ・飛び石・庭石・苔地が晴れと同じ乾いた見え方だった（`src/components/3d/CLAUDE.md` に「地面の濡れはない」と記録されていた）。

## 変更

`rainWetness.ts` の `applyRainWetness()` を、`SaunaScene` の材質準備（本体・庭）で `surfaceDetails.ts` と同じ対象材質に掛ける。雨の重み（`lighting.rain`）を毎フレーム uniform `suiRainWet` に渡す。再コンパイルは発生しない。

| 対象 | 色 | 水膜の粗さ |
| --- | --- | --- |
| デッキ（`outdoor ash`／`locally damp ash`） | ×0.5 | 0.4まで下げる |
| 石・舗石・追加庭石 | ×0.62 | 0.3まで下げる |
| 苔地（`layered living moss`／`moss and woodland earth`） | ×0.6 | 変えない |

- 細かな凹凸（法線マップ・表面の質感・雪のバンプ）を、濡れの量に応じて半分までならす。
- 上向きの面に最大で掛ける。鉛直面は半分、下向きの面は少しだけにする。
- サウナ室の屋根の下（`INTERIOR_BOX`＋軒0.3m、降る雨と同じ範囲）と水面下（`WATER_BOX`）は濡らさない。
- 挿入位置は `emissivemap_fragment` の直前。画像ランプ・表面の質感（粗さの下限0.32）・雪より後で、照明より前になる。

## 不採用

- **最初の案（粗さ：デッキ0.2・石0.14・苔地0.45、石の上面に水たまり）**：反射プローブはL2で、ぼけた空しか持たない。このため、草地とデッキが一様な灰色の艶に覆われ、霜や雪のように見えた（`rejected-first-try.jpg`、左が変更前）。
- **水たまり**：粗さを0.08にしても撮影では見分けられず、仮に見えても同じ灰色の斑にしかならないため外した。

## 確認

- `e2e/weather.visual.ts`（標準・1280×800・DPR1）を、変更前（`0bd58f1` のworktree）と変更後で撮影した。3ステージ×昼夕夜×晴れ・雨・雪の各27枚。
- `compare-rain.jpg`：左が変更前、右が変更後。上から外気浴の昼、外気浴の夜、サウナの夕暮れ。
  - 昼：デッキが暗く、曇天の艶を帯びる。苔地も暗くなる。
  - 夜：デッキが暗くなり、右手の暖色灯の光沢が出る。
  - サウナの室内の床は変わらない。
  - 水風呂の水中のタイルは変わらない。縁石の上面にわずかな艶が出る。
- 型検査、368単体テスト、Lint、整形、本番ビルド、通常のブラウザ回帰79件（22.6分）がすべて成功した。

## 範囲

濡れた面は鏡像を持たない（L2プローブのぼけた空と、ブラウザが描くスポット光の光沢だけ）。灯籠は光源ではないため、濡れた面に映らない。水しぶき、雨上がりに乾くまでの遅れ、雪と雨の同時の表現（雨の天気では積雪の季節でも雪面が暗くなる）はない。見回し中のちらつき・全周撮影・実機は確認していない。
