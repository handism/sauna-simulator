# 日光PCSSの昼夕切り替え確認（2026-09-28）

製品化した日光の4＋6標本（`softShadows.ts`）について、昼夕補間の途中を変更前（日光も常時16＋24）と比較した。製品の描画・配信物は変更していない。

## 条件と再現性

- Chrome 154、macOS headless、1280×800、DPR1。標準・高画質×製品／変更前／製品再撮影の6条件、3ステージ各14枚、計252枚。6件成功（337.9秒）、skip・再試行・ページ／コンソールエラー0件。
- 動作抑制なし。検証ブラウザ内でrAFの時刻を100msずつ進め、製品の `lighting.update` を実行する。撮影待ち中のフレームはdelta=0で照明・水の時刻を固定。日光の実uniform値も記録し、3条件の全撮影で時刻・日光RGBが一致することを集計時に検査した。
- 昼の終点に揃えてから夕暮れへ切り替え、5.3〜6.2秒を撮影。その状態から昼へ戻す0〜0.3秒も撮影。夕暮れへの5.6秒では日光最大成分0.10216、5.7秒では0.09824となり、製品の閾値0.1をまたぐ。逆向きは0〜0.1秒でまたぐ。
- 製品再撮影との差は**全画像0**。閾値をまたぐ前と、昼へ戻り閾値を越えた後は、製品と変更前も同一。

## 差

各画質の全42視点での最大値（元解像度のCIELAB）：

| 画質 | 平均ΔE76の最大 | ΔE>2の画素割合の最大 | 製品再撮影の平均ΔE |
| --- | ---: | ---: | ---: |
| 標準 | 0.03616 | 0.001465% | 0 |
| 高画質 | 0.03582 | 0.001074% | 0 |

差が最大になるのは切り替え直後の5.7秒。3ステージの同時点の比較画像を目視し、照明が大きく飛ぶ変化は認めなかった。最大差は日光の影の細かな粒で、夕暮れの終点より日光が強い分、終点の比較より差が増える。製品−変更前のLab誤差のフレーム間変化は平均の最大が標準0.04604／高画質0.04347（外気浴5.8秒）。これは画面座標での変化であり、知覚的なちらつきの判定値ではない。

**この制御撮影では閾値を下げたり補間方式を変更する必要は認めない。** 通常速度の動画・全周を見回しながらの昼夕補間・モバイル実機・実FPSは未検証。100ms刻みなので、通常の全フレームを撮影した証拠ではない。
