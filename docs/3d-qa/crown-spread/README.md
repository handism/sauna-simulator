# 林の葉の房の間隔と傾き（2026-10-13）

## 変更

林の房が横に薄く、枝の間に空が抜けていた。`woodlandCrowns.ts` の既存の複製1枚を、元のカードの大きさの0.3〜0.5倍から0.55〜0.75倍離し、傾きを±20°から正負どちらかへ35〜60°にした。元のカードの位置・拡大率、複製の枚数・大きさ、UV・樹冠の法線は維持する。幹・近景のモミジ・GLB・プローブは変更しない。

平行に近い房の重なりを減らし、同じ枚数で枝の間に葉を広げる調整。葉を大型化したり枚数を増やしたりはしていないが、画面上の被覆面積は変わる。

## 画像

`garden-details.e2e.ts`、Chrome、標準画質、1280×800、DPR1、動作抑制。変更前・変更後とも成功。3ステージの昼、外気浴の四季・夕夜・雨を撮影。夏・秋・冬・夕暮れ・水風呂の比較は同名のJPG（上が変更前、下が変更後、ローカルのみ）。

夏・秋の枝の間の房が広がり、横に薄かった林に厚みが出た。冬の落葉と常緑樹の維持、水風呂から見た林も確認。撮影時刻に依存する呼吸文字・滞在時間は画像差の対象外。
