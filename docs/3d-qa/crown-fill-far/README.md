# 遠い林の樹冠の埋め（2026-10-21、採用）

[見回し中のちらつきの確認](../motion-jitter/README.md)で、残りのちらつきが林の樹冠（画面中段）に集中していた。拡大すると20〜40m先の樹冠は、暗い葉が1枚ずつ空に浮いたレースで、その縁が見回し中に点滅していた。

## 変更

`leafCluster.ts` の `suiLeafCoverage`：1画素がカードのテクスチャを覆う量（footprint）に応じて閾値を下げる処理を、1.5→4テクセルで最大0.14から、**1→3テクセルで最大0.32**（`LEAF_FAR_FILL`）にした。遠いカードほど多くのサンプルを覆い、樹冠が葉の塊として読める。影マップは従来どおり0.5で切る。

- 遠景では遷移の幅（`fwidth` と `LEAF_FAR_RAMP` の大きい方）が閾値より大きく、下端が負になる。カードの空いた部分にも薄い被覆が乗り、葉どうしをつなぐ。下端を0で止める版も撮ったが、ちらつきの減りが0.89〜0.98倍に縮んだため採らなかった。
- 葉の面積（`LEAF_AREA` 0.9→1.3）を増やす案は遠景も埋まるが、近い木（サウナから見る軒先の木）の葉が大きな塊に融けたため採らなかった。

## 確認

撮影は `resolution-shimmer.visual.ts`（Chrome 155、1200×800・DPR1.5・標準・段1.5固定・`SHIMMER_CONTROLLED=1`・`&camera=review`、3ステージ×昼夕）。候補は一時ビルドのURLで切り替え、基準は同じビルドの既定値。最終ビルドの画像は候補B3と全PNGで一致した。値は [values.json](values.json)。

| 案 | 面の残差（変更前比） |
|---|---|
| 埋め0.25・1→3 | 0.85〜0.96 |
| 面積1.3 | 0.77〜0.91（近景の葉が融ける） |
| 面積1.3＋埋め0.25 | 0.70〜0.89（同上） |
| **埋め0.32・1→3（採用）** | **0.79〜0.93** |
| 採用案の下端を0で止める | 0.89〜0.98 |

- 外気浴の夕暮れが最も減り（0.79）、サウナの昼が最も小さい（0.93）。
- 見た目は撮影の0枚目を等倍・2倍で比較した（比較画像はローカルのみ）。外気浴・水風呂の林は空の透けたレースから葉の塊に、サウナの軒先の木は葉の形を保ったまま少し密になる。8階調超で変わった画素はサウナ昼2.7%、外気浴昼4.7%。

## 費用

`frame-cost.gpu.ts`（標準DPR1・`FRAME_COST_REPEAT=3`）を変更前（`5f92be5` のworktree）→変更後→変更後→変更前で測った。描画したrAF間隔の平均÷3の比は **0.90〜0.95倍**（同じ版の2回は±0.1ms、サウナ昼の変更前だけ10.06／11.11ms）。葉が全サンプルを覆う画素が増え、深度プリパスが奥を隠す分が増えたためと考えられるが、切り分けていない。純GPU時間・実機ではない。

静止画と制御した見回しの比較で、知覚的な合否・実機ではない。夏・晴れ・昼夕だけを撮り、秋冬の林、夜、高画質は撮っていない（季節の色・影は変えていない）。`season.e2e.ts`・`garden-details.e2e.ts`・`temporal-aa.e2e.ts` の11件が成功。
