# 元シーンの水越しタイル光沢を切り分ける（2026-09-30）

[平らな水の層](../water-gloss-slab/README.md)では「解析が水越しのCyclesの1.5〜1.6倍」（[床のハイライトの近似](../water-floor-disk/README.md)）が再現しなかった。元シーンの切り出しで、各画素が実際に見る床の位置・方向を取り、元の水から要素を1つずつ外して差の出どころを探す。製品コード・配信物は変更しない。

## 条件と測定

`scripts/diagnose_water_gloss_scene.py` が元blend（`SUI • Blue hour`）を読み、`diagnose_water_bottom_gloss.py` と同じ2つの切り出し（夕暮れの水風呂ステージ、見下ろし・見出し2）を描く。元blendは保存せず、前後のSHA-256一致を検査する。

- Blender 4.5.11 LTS / Metal、1024 samples・seed 17、デノイズ・適応サンプリングなし。寝椅子灯（`V10 lounge dusk fill / dusk`）だけのライトグループの線形RGBを使い、タイルのSpecular IOR Levelをそのまま／0で描いた差をタイル光沢とする。
- 元の水から要素を順に外す（メモリ上のみ）：`source` そのまま → `clear` 水を白・吸収なし → `smooth` 粗さ0・バンプなし → `flat` 上面を平均の高さ0.765mに → `rim` 浴槽（壁・縁石・目地・台座・底）以外を非表示 → `bare` 縁石・目地も非表示にし、壁を水面の高さで切る。
- 対応づけ：タイルの面を発光に置き換え（他の物体・寝椅子灯は非表示、拡散バウンス0、タイルを光源として標本化しない）、視線経路のRGB透過率×被覆・Position・Incoming（空気層の視線方向）を64 samplesで描く。5画素おきの点で、この位置・方向に[平らな層の光源側の積分](../water-gloss-slab/README.md)（両面のFresnel、遮蔽なし、透明な水）×透過率を解析値とし、Cyclesの5×5画素平均と比べる。
- 斑：`source` の寝椅子灯成分の上位20%の画素。
- `summarize_water_gloss_scene.py` は同じ点を平らな水の箱（側面での反射はFresnelで折り返す）でも追い、前回までの対応づけ（記録なし）を再現して比べる。
- 遮蔽：`diagnose_water_gloss_occluders.py`（描画なし）が斑を覆う床の5×5点から、寝椅子灯の円盤216点へ厳密な屈折経路（`water_gloss.exact_exit`）で光線を飛ばし、最初に当たる物体を数える。幾何の割合で、光沢のローブによる重みはない。

## 結果

斑の平均のタイル光沢（輝度、線形）と前の条件との比。Cycles÷解析は斑の中の点の合計比。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| source | 0.0850 | | 0.824 | 0.22 | 0.0793 | | 0.902 | 0.37 |
| clear | 0.0945 | 1.112 | 0.867 | 0.22 | 0.0882 | 1.112 | 0.950 | 0.37 |
| smooth | 0.0947 | 1.003 | 0.870 | 0.22 | 0.0884 | 1.003 | 0.952 | 0.37 |

| bare | 0.1271 | 1.133 | 1.156 | 0.54 | 0.1184 | 1.141 | 1.250 | 0.63 |

- **対応づけは差の原因ではない。** 平らな箱で追った床の位置はCyclesの対応から中央値1.7〜2.3cm（90%点 5.6〜6.8cm）、方向は1°未満ずれるだけで、解析値の比は0.97〜1.05。
- source→bareで斑の光沢は1.50倍（両視点）。内訳は着色・吸収1.11倍、浴槽の外の遮蔽1.20倍、縁石と水面より上の壁1.13〜1.14倍。粗さ・バンプ（1.003）と波（0.983）は明るさをほぼ変えず、波は斑の中の相関を下げる（0.22→0.41、0.37→0.50）。
- 遮蔽の内訳（[値](occluders.json)）：円盤の見える割合は平均70.2%（点ごとに59.7〜77.8%）。縁石と目地が11.3%、天蓋の梁（`V8 canopy timber beam`）が9.4%、細いルーバー（`V8 slender shade louver.005〜.013`）が9.1%。梁・ルーバーを除くと見える割合は1.26倍、さらに縁石を除くと1.13倍で、`rim`・`bare` の比（1.20、1.13〜1.14）とおおむね合う。
- 前回の解析は縁石の遮蔽だけを入れ、着色・吸収と天蓋の梁・ルーバーを入れていなかった。この2つで1.11×1.20≈1.33倍になり、「解析がCyclesの1.5〜1.6倍」の大部分に当たる。光沢の式・光源の換算・屈折の計算の誤りを示す結果はない。
- `bare` ではCyclesが解析より16〜25%強い。平らな層で残った約7%（内部反射・タイルの再訪）より大きく、壁を水面で切ったことで、切る前は見えなかった壁の内側の反射などの経路が加わった可能性がある。今回は切り分けていない。

## 判断と残件

製品は変更しない。ブラウザは不透明な物体をすべて影に入れる（`modelMaterials.ts`）ため、梁・ルーバーの遮蔽はPCSSの影で既に入っている見込み。ただし製品の影は円盤の中心への屈折経路の出口1点で引くので、梁・ルーバーのような細い遮蔽物の割合が円盤全体の70%と合うかは未確認。

次は、ブラウザで同じ切り出しのタイル光沢だけ（`suiWetSpecular` の有無の差）を撮り、この `source` の値（見下ろし0.085、見出し2 0.079）と画素ごとに比べる。以前の撮影でブラウザの斑は「Cyclesの約6割」だったが、Cyclesの光沢は斑の寝椅子灯成分の約2割しかないため、斑全体の不足がタイル光沢によるものかを先に確かめる必要がある。

## 検証

Blender診断12条件×2（光沢のオン／オフ）＋対応づけ36枚、遮蔽の光線判定5,400本。元blendと関連スクリプトのハッシュを照合。前のセッションで起動した同じ診断が同じ出力先へ並行して書いていたが、両方の実行で全12件の値が6×10⁻⁵以内で一致した（見出し2の`source`は解析点が1点違い）。残したのは後の実行の出力。Python 143テスト（`test_water_gloss_scene.py` 11件：解析点の選別・透過率×積分・スコアの比と斑・平らな箱の垂直／斜め／側面の折り返し・カメラの光線）、型検査、37ファイル220単体テスト、Lint、整形、本番ビルド成功。3Dチャンク738.18KBの既存警告は継続。製品変更はないため、ブラウザ回帰・全周・動画・GPU時間・継続利用は再実行していない。制限内のBlender起動は許可環境で実行した。
