# WebKitの分割準備後の自動照明・見回し（2026-10-08）

製品・配信物は変更せず、`?warmup=split` 後の動的検証をWebKitへ広げた。既定2Dと分割準備の試験オプションを維持する。

## 方法と再実行

```sh
MOTION_BROWSER=webkit MOTION_WARMUP=split bun run test:browser:motion --reporter=json > /tmp/sauna-webkit-split-motion.json
python3 scripts/summarize_auto_motion.py /tmp/sauna-webkit-split-motion.json docs/3d-qa/warmup-auto-motion-webkit --warmup split --browser webkit
```

WebKit 26.6・macOS headless、1280×800・標準画質・動作抑制なし・全速描画。開始前の12／27分だけDate.nowのオフセットで省き、以後は実時間で195秒観察する。50〜70秒と110〜130秒に左右約±0.5radを見回す。詳細は[Chrome側の方法](../warmup-auto-motion/README.md)。ブラウザ名も標本添付に記録し、集計の `--browser` でエンジン違い・欠落を拒否する。
