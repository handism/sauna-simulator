# 動的解像度の段の見た目（2026-10-02、確認）

[動的解像度](../dynamic-resolution/README.md)の残件「下げたときの見た目の撮影」。製品コードの変更はない。

## 方法（`e2e/resolution-steps.visual.ts`）

- Chrome headless・M1 Max・1200×800・DPR 1.5・標準画質・動作抑制・庭の準備完了後、`2101889` の本番ビルド。
- 視点：サウナ・外気浴の既定視点、水風呂は `stage-compare.visual.ts` と同じ4方向（見出し0/2/4の水平・1の見下ろし）。各×昼夕夜で18視点。
- 各視点を同じページで 1.5 → 1.25 → 1 → 1.5（再撮影）の順に、画面の画素（1800×1200 PNG、`rendererCaptureStyle`）で撮る。
  1.25・1は画面より小さいcanvasをブラウザが拡大した、利用者に見える像。
- 段の下げは `dynamic-resolution.e2e.ts` と同じrAFの空回し（30ms）、1.5への戻しは画質の変更。撮影中はrAFの時刻を止めて制御の窓を終わらせない
  （最初の実行ではサウナの夜が標準・1.5で自然に予算を超え、画質を5回戻しても1.25へ下がった）。動作抑制で水と照明は止まっているので、
  止めた時刻は画像を変えない。
- 集計：`python3 scripts/summarize_resolution_steps.py <report.json> test-results/visual/<出力先> docs/3d-qa/resolution-steps`。
  各視点の最初の1.5との CIELAB ΔE76（平均・2／5超の割合・中央部の5超）と、細部の保持率（L* の勾配の大きさの平均の、1.5に対する比）。

## 結果（18視点、[値](steps.json)）

| 比較 | 平均ΔE（最小・中央値・最大） | ΔE>5の割合（中央値・最大） | 細部の保持率（最小・中央値・最大） |
|---|---|---|---|
| 1.25 | 0.27・0.84・1.93 | 3.2%・8.6% | 0.70・0.79・0.95 |
| 1 | 0.35・1.08・2.37 | 4.3%・10.5% | 0.60・0.72・0.92 |
| 1.5の再撮影 | 0・0・0 | 0%・0% | 1・1・1 |

- 再撮影は全18視点で画素一致。差はすべて解像度による。
- 段の保持を `resolution-control.ts` へ切り出した後に別のページ読み込みで再実行し、集計の値はすべて一致（72枚中57枚がバイト一致、残りは読み込み間の既知の揺れ）。
- 差の大きい視点は葉の多い像：外気浴（1.25で平均ΔE 1.14〜1.93）、サウナの窓越しの林（1.02〜1.54）、水風呂の見出し0（庭と林、1.09〜1.62）。
  各段・時間帯で最も差の大きい200×150の窓はすべて葉と枝（`crops-*.png`、ローカルのみ）。1.5での葉（近景は小さな三角形、遠景の林は alpha to coverage のカード。どちらも4×MSAA）のギザギザが
  拡大でぼけて柔らかくなり、細い枝が薄く太くなる。色・明るさの変化ではない。
- 水風呂の見下ろし・見出し2/4（水面・タイル・内壁）は小さい（1.25で平均ΔE 0.27〜0.67、保持率0.83〜0.95）。実際に段が下がる場面
  （水風呂の夕暮れ・夜）の主な面は水面・タイルで、目立つ変化は画面上部に入る葉に限られる。
- 葉の多い視点では、夜は暗い分ΔEが小さい（同じ視点で昼の0.59〜0.67倍）。水風呂の見出し2・見下ろしは昼夜でほぼ同じ（0.91〜1.02倍）。

## 範囲

静止画の比較で、見回し中の葉のちらつき（1.5のギザギザは動くと瞬く。下げるとぼけで減る可能性がある）は見ていない。
画質の良し悪しの判定ではなく、どこが変わるかの記録。他の端末（DPR 2〜3）での段（高画質は1.25まで下がる）は撮っていない。
