# 桶の水・ストーブの熱・夕夜のサウナ室の露出（2026-10-27）

利用者の依頼（「グラフィック面で改善すべき事項」で挙げた1〜3の対応）。サウナの既定視点で目立っていた3点。

## 原因と変更

- **桶の水が水に見えない**：同日の修正（[pail-plunge-side](../pail-plunge-side/README.md)）で灰色の円盤ではなくなったが、書き出しの水は不透明度38%の暗い膜（`Loyly | recessed pail water`、基本色ほぼ黒・粗さ0.12）のままで、ベンチから見ると空の桶にかかった灰色のもやに見え、水際も映り込みもなかった。ガラス（`glass.ts`）と同じく、透過率の乗算と映り込みの加算の2回の描画にした。ガラスは板（2面）だが水は1面なので、`GLASS` の項目に `surface: true` を付けて `T=(1−F)·t`・`R=F`（IOR 1.333）にし、反射プローブの粗さは元の0.12（`suiRoughness`）。室内から見るので、ガラスと同じく室内6灯に照らされた杉の壁・天井の映り込み（`suiRoomGlow`）も足す。元にない補正として、透過の色 `t`（0.48・0.46・0.40）で水面下の桶の内側を暗くし、水際の線を見せる（元の水はほぼ透明だが、底まで約10cmの水越しの杉が上の乾いた内壁と同じ明るさでは水が入って見えない）。影は投射も受光もしない（照明を使わない材質なので、前回の「桶の水だけ影を受ける」規則は外した）。
- **ストーブに熱を感じない**：石かごの石は昼夜とも冷たい灰色の山だった。元にない演出として、`surfaceDetails.ts` の `heater` で、上の段より下（`HEATER_EMBER.deep`、高さ0.9→0.5mで最大）・かごの中心寄り（半径0.12〜0.34m）の石に、熾火の赤の発光（`HEATER_EMBER.color`、線形0.16・0.035・0.007）を、ノイズの斑（熱い所）と下向きの面ほど強く付ける。最初の0.42・0.11・0.025では下半分の石がすべて橙に光り、焚き火に見えたため、約0.4倍にして斑を絞った。足元の床の照り返しは付けていない（かごの下部は板で囲まれ、床に光が漏れる形ではない）。
- **夜のベンチ・床が明るすぎる**：室内6灯はどの時間帯も同じ強さだが、露出は元blendのとおり夕暮れ0.55・夜0.9段（昼0.15段）に開くため、サウナ室は昼より夜のほうが明るく、ベンチと床が平らな明るい橙に見えた。カメラが室内の箱（`INTERIOR_BOX`）にいる間だけ、露出に `ROOM_DUSK_EXPOSURE`（昼0・夕暮れ−0.4・夜−0.65段）を時間帯の重みで足す（`lighting.update()` の7番目の引数 `indoor`）。照らされた部屋に目が慣れた見え方で、ガラス越しの庭はその分暗い。ステージの切り替え（暗転中）で即時に変わる。水風呂・外気浴は変わらない。

## 静止画

Chrome、標準・DPR1・1280×800・固定解像度・全速描画・動作抑制、夏・晴れ。`e2e/sauna-warmth.visual.ts`（`WARMTH_RUN` が回のラベル）でサウナの既定視点・ストーブの見下ろし（下へ3キー）・ベンチ側（左5・下2キー）×昼夕夜の9枚を、変更前（`944c6d7` のビルド）・1回目の調整・最終の3回撮った。画像はローカルのみ（Git管理外）。

目視：

- 桶：昼夜とも水面下の内壁が暗くなり、水際の線が見える。柄杓は水面の上に出ている。映り込みは斜めの視線ではFresnelが小さく（約2〜5%）、ほのかな程度。
- ストーブ：石の隙間・下の段の陰になった面に赤い熾火が点々と見える。昼は控えめで、夜はかごの中がほんのり光る。上の段の石灰の付いた石は従来どおり。
- 夜：ベンチ・床が暗い琥珀色になり、灯りの当たる所との差が出た。夕暮れも同様に少し暗い。昼は不変。

## 確認

- 単体テスト：水面の `R=F`・`T=(1−F)t`（`glass.test.ts`）、室内の夕夜の露出と室外・昼で変わらないこと（`lighting.test.ts`）、桶の水が影を受けないこと（`modelMaterials.test.ts`）。
- 型検査・単体テスト512件・Lint・整形・ビルド、ブラウザ回帰（`bun run test:browser`）80/80件が成功。

## 確認していないこと

- 雨雪・高画質・季節・見回し中・ロウリュ中・実機。Cyclesとの比較（夕夜の露出は意図して元から変えた）。
