# 水底の灯りの反射境界を画素内で積分（2026-10-16）

水底のクリーム色の反射像は維持し、細い天蓋の遮蔽や微細なバンプが作る硬い1画素の段差を弱める。`waterBottom.ts` の境界付近だけ、画素の4分割の中心（x/y各±0.25画素）で灯りへの経路を追い、線形の放射輝度を平均する。

## 実装の範囲

既存の4方向の傾斜検査で境界に近いと分かった画素が対象。水中の点・水中の視線・入水前の視線の画面微分は、水中判定・境界の分岐より前で取得する（分岐内の微分はGPUで未定義になる）。各点で従来の入水・底面反射・出水のバンプ、浴槽の縁・天蓋を判定する。光源の強さや反射像の中心をずらす係数は加えない。追加の形状・描画パス・テクスチャ・ターゲットなし。

これは画素内の4点による局所近似で、Cyclesの光沢ローブの再現ではない。既存の境界検出・平らな水による像の位置・側面の像の入水バンプ省略は維持する。境界から離れた反射、プローブ、Fresnel係数、タイル自身の光沢、水面の平面反射、GLB・プローブ、2D既定と回復経路は維持する。像の位置・広いぼけ・タイル光沢の合成差をすべて解決したものではない。

## 静止画

Chrome 155.0.8059.79、標準画質・DPR1・1280×800・動作抑制、水風呂の昼夕夜×4方向。独立した変更前後のビルドを前→後→後→前の順で撮影。4件成功、48枚。各版の12枚すべて再撮影差0画素。[比較画像](comparison.png)・[集計](comparison.json)・[入力ハッシュ](inputs.json)。製品入力の差は `waterBottom.ts` だけ。

夕暮れ・夜の反射右端と細い遮蔽の段差が少しなだらかになった。比較画像の見下ろし・見出し2、および見出し4の全体を確認し、大きな欠落・黒抜けは見当たらない。外形や明るさの大きな変化を狙った修正ではない。

- 夕暮れ・夜でΔE76 > 2の変更領域は357〜1,455画素（画面の約0.035〜0.142%）。この領域のCyclesとの平均色差は夕暮れで15.72〜19.90→10.77〜13.45、夜で15.96〜21.18→10.88〜14.41。約31〜38%低下。画像全体の画質向上率ではない。
- 昼は見出し2・4で6.48→6.28・6.54→6.06、見下ろしで8.73→9.51と混在。既定正面は昼夕夜とも変化0画素。
- Cycles参照は庭・天気追加前。像の位置・広いぼけ・タイル光沢との差は残る。全画面の色差に他の変更も含むため、今回の誤差とは扱わない。

最初の変更前撮影は音声デバイス／WebAudio rendererのconsole errorで2回失敗。エラーを除外せず失敗として扱い、その後の検証用Chromeだけ `--disable-audio-output` で再実行した。製品の音声実装は変更しない。以下の撮影・回帰もこの検証条件であり、音声出力の動作確認を含まない。
