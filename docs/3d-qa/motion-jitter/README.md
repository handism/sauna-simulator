# 見回し中だけのサブピクセルのずらし（2026-10-21、不採用）

[TAA](../temporal-aa/README.md)の試作では、サブピクセルのずらしを加えると見回し中の面の残差が0.35〜0.47倍（ずらしなしは0.54〜0.58倍）だった。不採用の理由は静止画までやわらかくなることだったため、**カメラが回ったフレームだけ**ずらし、静止中はずらさない（静止画は従来どおり1フレームの画像に収束する）案を試した。製品コードの変更はない。

## 試作

- `temporalAA.ts` に、履歴が有効でこのフレームにカメラが回った（位置同じ・0.25rad以内）ときだけ、本描画と影マスクの投影行列にHalton(2,3)の8点のずれ（幅0.5／1描画画素）を足す処理を加えた。水面・デッキの鏡像はずらす前に描く。履歴の再投影はずらさない行列で計算する（ずれた行列では出力自体が揺れる）。
- 比較は同じビルドのURLの切り替え（ずらしなし／0.5／1）。単体テストで、静止・履歴なし・ジャンプ・解像度変更でずらさないこと、再投影がずらさない行列になることを確認した。

## 結果

`resolution-shimmer.visual.ts`（Chrome、1200×800・DPR1.5・標準・段1.5固定・`SHIMMER_CONTROLLED=1`・`&camera=review`、3ステージ×昼夕）。面の残差のずらしなしに対する比（[値](values.json)）。

| 条件 | 1ステップ2フレーム | 1ステップ1フレーム |
|---|---|---|
| ずらしなし（再撮影） | 1.000（全6系列） | — |
| 見回し中だけ・幅1（2回、同値） | 1.06〜1.18 | 1.28〜1.39 |
| 見回し中だけ・幅0.5 | 1.00〜1.05 | — |
| 静止中もずらす・幅1（試作相当の診断） | — | 0.92〜1.14 |

- どの条件もずらしなしより減らなかった。1ステップ1フレームでステップごとに見ると、比は最初の対で約1.0（静止中もずらす診断では0.5）から回るほど増え、ずれの位置が大きく飛ぶ対（Halton列の8点目→1点目など、約0.7画素）で約2倍に跳ねた。ずれた今のフレームが制限の箱を動かし、出力画像そのものがずれに合わせて揺れている。
- 試作時の0.35〜0.47倍は、撮影待ちの間もフレームが進む方式（`SHIMMER_CONTROLLED` 導入前）で、ずれた標本が撮影の合間に余分に平均された値だったと考えられる（同じ指摘は [temporal-variance](../temporal-variance/README.md) の予備結果）。制御撮影では静止中もずらす試作相当でも減らないため、ずらし自体の利点はこの指標では確認できない。
