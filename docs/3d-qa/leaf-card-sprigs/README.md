# 林のカードの葉を房にまとめる（2026-10-27）

水風呂・外気浴の正面に見える中景（約10〜25m）の林の樹冠は、大きな平たい多角形の集まりに見えていた。夜は空を背に、角の欠けた長方形・平行四辺形の影絵がはっきり並んでいた。

## 原因

拡大すると、多角形の正体は葉ではなくカード（約0.51×0.22m、葉20枚分）そのものだった。マスクの葉は正方形のカード全体に格子状に敷かれていた。そのため、1画素が1→3テクセルを覆う距離で閾値を下げる処理（`LEAF_FAR_FILL`）と、2→4テクセルでぼけたミップを読む処理（`LEAF_FAR_BIAS`）が中景の木にも掛かると、カードの長方形の外形がそのまま塗りつぶされた。マスクの葉1枚は約10cm相当で、葉の大きさ自体の問題ではない。

## 変更

`leafCluster.ts` の `leafClusterCoverage`：20枚の葉を、カード中央の房1つと、半径0.25の輪に置いた房4つ（`LEAF_SPRIGS`・`LEAF_SPRIG_RING`、輪の位置は半歩以内でずらす）にまとめた。葉柄は房の中心に置き、葉は房の周りに放射状に並べる。カードの埋まった形が、縁の波打つ丸い葉の房になる。房の葉柄で重なる分の被覆を補うため、葉の面積（`LEAF_AREA`）を0.9→1.2にした（閾値以上の被覆は0.44→0.41）。シェーダー・形状・テクスチャの大きさは変えていない。

試した案（撮影のみ、PNGはローカル）：

| 案 | 結果 |
|---|---|
| 葉を円内に均等に置く | 長方形は消えたが、細長いカードの上で滑らかな楕円になり、巨大な1枚の葉に見えた |
| 格子状の4つの房 | 房がカードの角まで届き、平行四辺形に戻った |
| **中央＋輪の5つの房（採用）** | 縁の波打つ房の塊。夜の影絵が角ばった板から葉の房の集まりになった |

## 確認

- 静止画：`graphic-fixes.visual.ts`（1280×800・DPR1・標準・固定解像度）の37視点を変更前（`HEAD`）と比べた。8階調を超えて変わった画素は0.2〜6.5%で、林が見える秋・昼の外気浴・水風呂が多い。室内（ストーブ）はほぼ変わらない。
- 見回し中のちらつき：`resolution-shimmer.visual.ts` の制御撮影（標準DPR1.5・固定解像度・`camera=review`・3ステージ×昼夕×13枚）を変更前と変更後の2つのビルドで1回ずつ撮った。面の残差（8 CSS px）の変更後÷変更前は次のとおり（[shimmer.json](shimmer.json)）。

| 視点 | 面の残差の比 |
|---|---|
| サウナ昼 | 0.905 |
| サウナ夕 | 0.847 |
| 外気浴昼 | 0.923 |
| 外気浴夕 | 0.873 |
| 水風呂昼 | 0.929 |
| 水風呂夕 | 0.902 |

  別々のビルドでの比較のため、同じビルド内のABBAではない（以前の記録では、同方式の再撮影差は小数3桁でほぼ0）。

- 単体テスト509件とブラウザ回帰80件が成功（`leafCluster.test.ts` は、角が空いていることと、縁の長さが同じ面積の円の約2倍あることを検査する。葉が房でつながるため、連結成分を数える検査は置き換えた）。

## 範囲

夜・高画質・描画費用・実機は測っていない。描画費用については、テクスチャの読み出し回数とシェーダーは変わらない。全画面で見た差は控えめで、遠い林が1画素未満の葉の塊であることは変わらない。中景の樹冠は、カード単位の房の塊として読める程度まで改善した。
