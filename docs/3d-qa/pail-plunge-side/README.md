# 桶の水面・水風呂の外側の側面

2026-10-27。サウナの既定視点で目立っていた2点の修正。

## 原因と変更

- **桶の水が灰色の円盤に見えた**：半透明の材質は影を受けない（`prepareModel` の規則）ため、桶の水面だけが桶・ストーブ・ガラスの枠の影を無視して昼の日光を直に受けていた（夜は日光がないので暗い）。反射プローブの映り込みを0にしても、材質を不透明にしても灰色のままで、影を受けさせると消えた。桶の水（`Loyly | recessed pail water`）だけ影を受ける（影は落とさない）。材質の色・不透明度・映り込みは変えていない。
- **水風呂の外側の側面がのっぺりしていた**：外側の側面は水中の内壁と同じ材質（`V10 | submerged light / V9 | quiet honed stone / V2 | mineral c`）で、元のノードが玄武岩の画像の上に平らな暗色を64%混ぜている（水中の見え方のため）。水の外でもこれが掛かり、サウナからガラス越しに見る長い面が模様のない暗い板になっていた。`exposePlungeSides()` が `WATER_BOX` を水平に10cm広げた箱の外の三角形（124三角形、内壁の面と外側の面の間）を、属性を共有した別メッシュと材質の複製へ移し、混ぜる割合を0.15（`PLUNGE_OUTER_MIX`）にして、乾いた石と同じ表面の質感（`surfaceDetails.ts` の `stone`）を足す。複製に水中の三角形はない。

## 静止画

Chrome、標準・DPR1・1280×800・固定解像度・動作抑制、夏・晴れ。サウナの既定視点・見下ろし（桶）・水風呂側・左（水風呂の側面）×昼夜の8視点を、変更前のビルドと最終ビルドで1回ずつ撮った（一時的な撮影スクリプトで、リポジトリには残していない。同じ視点の多くは `e2e/graphic-fixes.visual.ts` のサウナの3視点で撮れる）。`values.json` は最大チャンネル差が8段階を超える画素の割合（昼0.8〜1.0%、夜0.03〜0.04%）。画像はローカルのみ。

続けて最終ビルドで `e2e/graphic-fixes.visual.ts` の37視点を撮り、変更前（同日の見直しの撮影）と比べた。差が大きいのは外気浴の右（側面を正面から見る、8段階超の画素が昼・秋2.2%、冬1.9%、夜1.4%）とサウナの既定視点（約0.9%）。

目視：昼の桶は暗い水面に底がうっすら見え、柔らかな映り込みが残る。夜は変化なし。側面は玄武岩のまだらと粒が見え、外気浴から見ると以前のほぼ一様な灰色から濃淡のあるまだらになった。室内の灯りによる側面の暖色のにじみ（横長の明るい斑）は残る。
