# 飛び石・庭石の接地の陰、見出しの暗幕、冬の雪面（2026-10-12）

## 課題

1. 外気浴の手前の飛び石が、明るい天端に置いた板のように浮いて見えた。元GLBの石（`V2 | mineral charcoal stone`）は材質ごとに1メッシュへ結合されており、前回の接地の陰（`gardenDetails.ts` が足した岩・低木・灯籠だけ）の対象外だった。調べると、飛び石7枚（1.25×0.62m）は地形ではなく基礎の縁の天端（y −0.01）に3cm埋まって載り、外側へ0.31m張り出していた。その下は砂利の溝（y −0.39）。
2. 晴れの水風呂で、見出しの周りの暗幕（幅720pxの楕円・中心の不透明度0.44・線形に薄れる）が空の灰色の雲に見えた。
3. 冬の地面が一様な白（0.78, 0.83, 0.88）で、無地の面に見えた。手前のシダは雪の上で鮮やかな緑のままだった。

## 変更

1. `gardenDetails.ts` の `restingStones()`：結合メッシュの頂点を1mmで同一視して接続成分に分け、箱が幅0.25〜16mで、支える面に載るか0.5m以内で張り出すもの（基礎・飛び石・庭石など）に、接地の陰と同じメッシュで角丸の矩形の陰を敷く。支える面は、地形または平たい石の箱の天面のうち最も高いもの。平たい石（高さが短辺の0.35倍未満）は外形まで不透明度0.6、外形から余白の0.3倍で0.24、余白（0.3m＋張り出し×0.6）で0にする。丸い石は外形の0.55倍の芯から、外形の0.7倍の余白まで0.55→0。室内・高所の石と砂利の小石は対象外。
2. `index.css`：暗幕を幅 min(560px, 100%)・上下32pxに縮め、中心の不透明度を0.32にして、50%・80%の位置で緩やかに消す（`color-mix`）。可読性は文字の影で補う。
3. `winterSnow.ts`：雪面に数mの吹きだまり（2つのノイズ）、約0.3mのうねり、約13cm間隔の風紋を加える。色（吹きだまりの間は暗く青い (0.64, 0.71, 0.82)）と、法線の凹凸（高さ最大16cm、雪の覆いの割合で元の法線と混ぜる）の両方に反映する。風紋とうねりは、画素より細かくなる距離で平均へ消す。被覆はやや急な面から薄くする（`smoothstep(0.42, 0.88, …)`）。シダ（`V3 | fern N`）を対象に加え、`SUI_SNOW_DUSTING` で被覆を0.1〜0.45の斑にする（全面に載せると白い切り抜きに見えた）。

## 確認

- `garden-details.e2e.ts`（標準画質・1280×800・動作抑制）の撮影を `../scrim-ridge-contact/` と比べた。
  - 飛び石の手前の縁に柔らかい陰が出る（`compare-stepping-stones.png`、上が変更前）。
  - 晴れの水風呂の空に灰色の染みが出ず、見出しは読める（`water-day.png`）。
  - 冬は中景に青みのある吹きだまりの濃淡が出て、シダは粉雪程度になる（`compare-winter.png`）。
- 一時的な撮影（コミットしない）で、冬のサウナ・水風呂・外気浴の昼夕夜を目視した。破綻や黒抜けはなかった。
- 吹きだまりの濃淡は中景では控えめで、遠景の草地はほぼ白いまま。
- 単体テスト：`gardenDetails.test.ts` に、地面と基礎の天面に載る飛び石の陰（高さ・外形まで濃く余白で0）と、高所の石を除くことの検査を追加した。`winterSnow.test.ts` には凹凸の挿入位置とシダを追加した。

## 範囲

陰は円盤・角丸の矩形による近似で、日光の向きや形に応じた遮蔽ではない。雪の吹きだまりは色と法線だけで、形状・積雪量は変えない。照度・反射プローブは夏のまま。見回し中のちらつき（風紋）は確認していない。
