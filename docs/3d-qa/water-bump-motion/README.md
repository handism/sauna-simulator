# 水底反射の斑のほつれが波で動くときの見え方（2026-09-29）

[water-bottom-bump](../water-bottom-bump/README.md) で寝椅子灯（`V10 lounge dusk fill`）の斑の縁をバンプでほつれさせた。残件は「ほつれは1画素単位で硬く、波とともに縁の上を動く。動画での見え方は未確認」だった。1画素のほつれが毎フレーム入れ替わると、縁がちらついて見えるおそれがある。

## 方法

- `e2e/water-bump-motion.visual.ts`（標準画質・1280×800・DPR1）が検証ブラウザ内でrAFの時刻だけを固定し、1/60秒ずつ進めて、水風呂ステージの夕暮れ・夜 × 見下ろし（見出し1）・見出し2で各72フレーム（1.2秒）を無劣化PNGで撮る。水の時刻はrAFの時刻に従う。撮影用の余分なフレームではdelta 0。自動照明の録画（`auto-lighting.motion.ts`）はVP8・25fpsで、1画素のほつれは符号化で潰れるため使わなかった。
- 変更前はバンプを入れる前のコミット（`191f9de^`）のworktreeで、同じテストを同じ時刻列で撮った（`motion.json` の入力ハッシュ）。製品の描画・配信物は変更なし。
- `scripts/analyze_water_bump_motion.py` が斑の範囲（`summarize_water_bump.py` と同じ切り出し）について、次を出す。
  - 縁の粗さ（`water_bump.edge_roughness`、滑らかな円で約0.3）：各フレームの中央値と、6フレーム（100ms、目が積分する時間の目安）の平均画像の中央値。ほつれが時間平均で消えて、ぼけた縁に変わるかを見る。
  - しきい値をまたぐ画素：前フレームとの間で斑の内外が入れ替わる画素数（縁の画素1個あたり）と、そのうち3フレーム以内に戻る割合（ちらつき。一方向に動くだけなら0）。
  - 時間方向の高周波 |y1 − (y0 + y2)/2|（8bit輝度）：縁の近く（全フレームの縁を2画素広げた範囲）と、それ以外（波で動く水面そのもの）。縁の近くの時間スペクトルのうち10Hz以上の割合。

| 夕暮れ・見下ろし | 0.474→0.706 | 0.580→0.767 | 0.925→0.820 | 0.042→0.044 | 3.58→3.50 | 0.065→0.064 |
| 夕暮れ・見出し2 | 0.448→0.709 | 0.507→0.776 | 1.025→0.880 | 0.044→0.041 | 3.59→3.47 | 0.063→0.062 |
| 夜・見下ろし | 0.383→0.673 | 0.498→0.730 | 0.937→0.825 | 0.046→0.046 | 3.99→3.87 | 0.064→0.064 |
| 夜・見出し2 | 0.445→0.709 | 0.499→0.744 | 1.005→0.851 | 0.044→0.043 | 4.01→3.89 | 0.062→0.062 |

縁から離れた水面の高周波は前後とも0.18〜0.31で、差は0.01以下。

- **バンプはちらつきを増やしていない。** 変更前から、斑の輪郭は波で1フレームに約1画素動く（入れ替わる画素が縁1画素あたり約1）。3フレーム以内に戻る画素は前後とも4〜5%で変わらない。縁の近くの高周波と10Hz以上の割合も、前後の差は3.4%以内（どれも後の方が小さい）。ほつれは輪郭と一緒に動き、その場で点滅はしていない。
- **ほつれは100msの平均でも残る。** 平均画像の粗さは0.73〜0.78で、変更前の平均画像（0.50〜0.58）より高い。目で積分しても、ほつれた縁として見えると考えられる。
- 変更前の各フレームの粗さ（0.38〜0.47）は [water-bottom-bump](../water-bottom-bump/README.md) の静止画（0.31〜0.38）より高い。撮影したフレーム（波の位相）と画像形式（今回はPNG、前回はJPEG）が違うため。
- 目視（`<視点>.webp`、左が変更前・右が変更後、2倍、60fps、ローカル）でも、輪郭全体が波で大きく揺れて形を変え、ほつれはその輪郭に付いて動いていた。変更後のほつれは横方向に伸びた筋になる。

**判定の範囲**：数値の上では、ほつれがちらつく兆候はなかった。標準画質・1.2秒・2視点×2時間帯に限った結果。実際に人が通して見て違和感がないか、高画質・DPRの違い・実際の描画速度（rAF時刻の固定で描画の遅れは再現しない）は判定していない。Cyclesは静止画なので、動きをCyclesと比べてはいない。
