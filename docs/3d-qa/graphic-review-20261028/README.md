## 確認

- 静止画：`REVIEW_RUN=<回> bunx playwright test --config playwright.visual.config.ts e2e/graphic-review.visual.ts`（撮る前に `bun run build`）の16視点を、変更前（`before`）と途中・最終で撮って並べて目視した（画像はローカルのみ）。
  - 窓の扇形は柔らかい縦の光のにじみになり、夜は控えめな明るさになった。水底の三角形は暗くなり、周りより明るい飽和した板ではなくなった（形は縁石の鏡像で切れたまま）。
  - 冬の常緑のカードは暗い青緑の針葉の塊になった。本体の `Evergreen foliage` は実形状の広葉の葉のため形は変わらず、暗くなっただけで雪の塊もほとんど見えない。
  - 秋のシダは黄褐〜錆色になり、紅葉・枯れた草地となじんだ。
  - 夕暮れの中景の樹冠は外側の葉が細かくなったが、影絵としての大きな房の輪郭は残る（改善は控えめ）。
