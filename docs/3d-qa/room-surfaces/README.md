# ベンチ座面・左壁・天井の夕夜の照明（2026-10-19）

室内照明の改善候補1への承認に基づき、既存の床・背面壁の補正に続けて、上段／下段ベンチの座面・左杉壁・天井下面の直接光を局所補正した。[前後一覧](comparison.jpg) は左が従来の室内照明、右が補正あり。画像はローカルのみ。

## 方式と範囲

- 既存6灯は部屋全体で平均した遮蔽率を使っていた。新しい4面では元blendの灯りの形・位置・向き・出力を使い、各面光源1024点の面積積分と静的な不透明形状の遮蔽に置き換える。灯りは加算せず、対象部分の6灯の既存直接拡散光を有効度分だけ減らす。太陽や他の光源、反射は変更しない。
- 上段は y=1.035m、x −6.01〜−1.19、z −4.108〜−3.172（40×9点）。下段は y=0.565m、同じx、z −3.028〜−2.512（40×6点）。上面だけを対象とし、側面・裏面・背もたれは今回の追加対象外。
- 左壁は x=−6.0925m、z −4.45〜−0.3、y 0.1〜3.25（35×27点）。天井下面は y=3.285m、x −6.05〜−0.65、z −4.45〜−0.35（44×34点）。約12.5cmの格子で補間し、境界15cm・受光面の法線・昼→夕の重みでフェードする。
- 新しい4面の間接光は既存の方向性を持つSHプローブを維持する。夏の照度へ季節比を掛ける既存の近似も維持。床／背面壁の旧8層は寸法のパディング以外、値を保持したことを配列比較で検査した。
- `roomIrradiance.ts` は同一受光平面にある3頂点の三角形だけを属性共有で分離する。受光面は64→192三角形、材質は2→3。三角形を増やす分割ではなく、既存の三角形の所属変更。GLB・既存プローブ・元blend・2D経路は変更しない。
- 同じsamplerの3Dテクスチャを44×21×8から44×34×12（RGBA16F、59,136→143,616 bytes）へ拡張。配信バイナリは84,480 bytes増える。新しい取得要求や影パスはなく、既存の中止・期限・遅延完了・解放処理を使う。

## 描画負荷

変更前HEAD `5fd2052` の隔離コピーと最終版を、前→後→後→前で比較。最初の前後には別の予備実行を入れ、計6件成功。Chrome 155・標準・DPR1・1280×800・固定解像度・動作抑制・ミュートで、着座正面／ベンチ／左壁／天井の昼夜を各4秒、1コールバックで3回反復描画した。描画を発行したフレーム間隔の平均÷3を使う。[数値と描画数](cost.json)。

- 後÷前の2組は着座正面の昼1.000〜1.004、夜1.000〜1.004。ベンチの昼1.000〜1.004、夜1.000。左壁の昼1.048〜1.048、夜1.000。天井の昼夜は約1.000。
- 左壁の昼は約5.56→5.82ms（反復描画の間隔÷3）で、約4.8%増えた。昼の見た目を変えなくても追加の受光材質・分岐の費用は残る。原因を個別に切り分けた値ではない。他の室内視点の多くは約5.56msの測定下限にあり、小さな差やゼロコストを証明しない。アプリFPS・純GPU時間・実機の性能ではない。
- 全8条件で描画呼び出しは各+1、描画三角形数は同じ。記録したテクスチャ数も同じ。全角度や全パスでの値を保証しない。

## 再実行

元blendは保存しない。ベースv2は従来の間接光＋直接光の結合データで、再生成は [room-light](../room-light/README.md) の手順を使う。すでにv3へ拡張したデータを入力に再拡張しない。

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b blender/scene/SUI_Retreat.blend --python-exit-code 1 --python scripts/bake_room_direct.py -- /tmp/room-combined /tmp/room-surfaces --extend --samples 1024
/Applications/Blender.app/Contents/MacOS/Blender -b blender/scene/SUI_Retreat.blend --python-exit-code 1 --python scripts/blender_room_surfaces_reference.py -- /tmp/room-surfaces-references
```

生成ヘッダーのversion・width・height・scenes・surfaces・input_sha256・bin_sha256だけを配信用JSONへ抜き出し、生成バイナリを配信する。詳細はQA側へ保存する。

```sh
bun run build
bunx playwright test --config playwright.visual.config.ts e2e/room-surfaces.visual.ts --output test-results/room-surfaces/final --reporter=json > /tmp/room-surfaces-final.json
python3 scripts/summarize_room_surfaces.py /tmp/room-surfaces-final.json test-results/room-surfaces/final docs/3d-qa/room-surfaces
python3 scripts/compare_room_surfaces_reference.py test-results/room-surfaces/final /tmp/room-surfaces-references docs/3d-qa/room-surfaces/reference-check.json
```
