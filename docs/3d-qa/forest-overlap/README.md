# 奥の森の樹冠の重なり（2026-10-17）

## 変更

基準は `1b24a8c`。`farForest.ts` の既存の手前73樹冠と奥54mの帯の間へ、19樹冠を間欠的に追加する。既存の固定乱数から6個に1個を選び、中心半径51.2〜51.7m、頂部は対応する帯の樹冠より0.25m低くする。大小3つの葉群を既存より12%細くし、各4段×8分割の閉じた形状へまとめる。下端は地形の下まで延ばし、浮いた底面を見せない。

既存の手前73樹冠・帯の形状と陰影は維持。既存の季節色・固定の近似陰影・時間帯・曇天・霞と同じ材質／メッシュを使い、テクスチャ・光源・影パスは増やさない。冬は灰褐色の葉群近似で、枝のモデルにはならない。

森の三角形27,452→30,188（+2,736、約10%）、頂点属性配列3,953,088→4,347,072 bytes（+393,984 bytes）。半径・最高点の範囲は従来と同じ。これは配列の大きさで、GPU総メモリではない。GLB・プローブ・2D既定・復帰経路は変更しない。

- モデル群のハッシュ一致、前後のソース差が `farForest.ts` のみであること、各版2回のソースハッシュ一致を確認した。最初のサンドボックス内起動は失敗したため、許可された起動で撮り直した。失敗した起動は成功数に含めない。
- 変更後1回目の昼夕夜×3ステージをまとめた一覧と、外気浴91.7°の昼夕夜・水風呂320.9°の昼・サウナ45.8°の昼の原寸前後ペアを確認。新しい大きな欠け・黒抜けは見当たらない。外気浴横向きの一部で葉群の肩の重なりが増えるが、全体の変化は控えめで、奥の帯の平面感は残る。全原寸・全角度の目視合格ではない。[前後比較](comparison-0.jpg)（左：前、右：後。リンク先は変更後2回目）。

## 限界

通常ブラウザ回帰全件・高画質負荷と全周・他季節天気の全周・実時間の連続視聴・実Safari・実機は未確認。冬の灰褐色の葉群近似と夏のプローブ共用は維持。今回の追加は一部の重なりを増やすもので、奥の帯全体の平面感を解消したものではない。

## 再実行

変更前後を独立したディレクトリへ置いて同じ依存関係で `bun run build` する。各版で次を変更前→後→後→前の順に実行し、毎回出力先と画像を分ける。今回のローカル検証コピーは `/private/tmp/forest-overlap-20261017/{before,after}`。`review.config.ts` は既存visual設定にプレビューのポート4293とChromeの `--disable-audio-output` だけを上書きした。音声の実出力は検証しない。

```sh
SHIMMER_HEADING_STEPS=20 SHIMMER_FIXED=1 SHIMMER_RATIOS=1.5 bunx playwright test --config review.config.ts e2e/resolution-shimmer.visual.ts e2e/scene-survey.visual.ts --reporter=json
python3 scripts/summarize_visual_survey.py <report.json> <survey-output>
python3 scripts/summarize_resolution_shimmer.py <report.json> <capture-dir> <shimmer-output>
FRAME_COST_REPEAT=3 FRAME_COST_VARIANTS=product bunx playwright test --config cost.config.ts e2e/forest-cost.gpu.ts --grep 'frame cost' --reporter=json
```

負荷用の `forest-cost.gpu.ts` は既存 `frame-cost.gpu.ts` の各ステージで右20キー分（約91.7°）を向くコピー。各版の初回は `FRAME_COST_VARIANTS=warmup,product`。負荷測定と撮影・画像解析・回帰検査は同時実行しない。画像はローカルのみ、README・JSONをGit管理する。
