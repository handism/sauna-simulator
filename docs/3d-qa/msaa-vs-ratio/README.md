# 4倍MSAA・DPR 1.25と2倍MSAA・DPR 1.5（2026-10-05、確認・不採用）

[メインの描画先のMSAA](../main-msaa/README.md)の残件「4倍・DPR 1.25（動的解像度の1段下）と2倍・DPR 1.5の見た目の比較（同程度の費用で、どちらが良いか）」。動的解像度の最初の段を「画素比を下げる」から「MSAAを2倍にする」へ変える価値があるかを、見た目・GPU時間で比べた。製品コードの変更はない。

## 結論

**変えない。** 2つは同程度の費用ではなかった。4倍・1.25の方が7〜18%（0.9〜2.5ms）安い。2倍・1.5は超標本化の基準に対する平均ΔEが18視点中16で小さいが、葉に2標本の alpha to coverage の市松模様が粗く出る（[切り抜き](crop-sauna-day-default.png)、左から基準・4倍1.5・4倍1.25・2倍1.5。画像はローカルのみ）。4倍・1.25は全体にぼけるが模様は出ない。平均ΔEの差（中央値0.72対0.90）は、ぼけが面全体に広がるのに対し市松模様は画素ごとの誤差が大きい（99百分位で2倍1.5の方が大きい）ことの表れで、見た目の良さの順と一致しない。60fpsに届かない水風呂の夕暮れ・夜では、2倍・1.5（16.1・16.7ms）は予算ぎりぎりで、4倍・1.25（13.7・14.2ms）の方が余裕がある。

## 方法

- 画像：`e2e/resolution-steps.visual.ts`（1200×800・DPR 1.5・標準画質・動作抑制、18視点を1.5→1.25→1→1.5で撮る）を、4倍（`c930ca3`）と2倍（`hdrOutput.ts` の標本数だけ2にしたworktree）で4倍→2倍→2倍→4倍の順に撮った。同じ版の2回は全視点・全段で画素一致。
- 基準：4倍・画素比3（一時的に標準の `pixelRatio` を3、鏡像は画面上の画素数を保つため `mirror` を0.25にしたworktree、DPR 3）で同じ18視点を撮り、3600×2400を線形の光で2×2平均して1800×1200にした。2回撮って画素一致。画素比に比例する鏡像以外の処理（影のマスクなど）も細かくなるため、4倍・1.5でも平均ΔE 0.63の差がある。
- 費用：`frame-cost.gpu.ts`（`FRAME_COST_REPEAT=2`・`?resolution=fixed`・1200×800）で、4倍・DPR 1.25、2倍・DPR 1.5、4倍・DPR 1.5を順を入れ替えながら4組。3ステージ既定視点×昼夕夜のフレーム間隔の平均（÷2）。

- 2倍・1.5が4倍・1.25より平均ΔEで小さいのは16/18視点。逆は外気浴の昼（1.878対1.877）・夕暮れ（1.69対1.68）。水風呂の見出し0（庭と林）は1.52対1.54でほぼ同じ。
- 差が大きいのはどれも葉と枝。2倍・1.5の細部の比が1を超えるのは、市松模様の画素ごとの明暗が基準にない勾配を足すため。水面・タイル（水風呂の見下ろし）はどちらも小さい（0.19対0.31）。
- 2倍・1.25は4倍・1.25とほぼ同じで、画素比を下げた後はMSAAの差はぼけに隠れる。
