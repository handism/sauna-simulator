# 水の底面での部分反射（2026-09-27）

[光沢にだけ見える面光源](../glossy-lights/README.md)の残件「夕暮れの見出し1の上部・見出し2・4の大きな円盤」を扱った。前回は経路を「水中のタイルの光沢反射」と見ていたが、主因は**元の水形状の底面での部分反射**だった。

## 原因の特定

元blend（修正後、SHA-256 `f1ee4ddd…`）をBlender 4.5.11 LTSで読み、水風呂の既定視点（`blender_stage_reference.py` と同じ向き）を640×400・256サンプル・デノイズなしで描いた。数値は [cycles-bottom.json](cycles-bottom.json)。

- `V10 lounge dusk fill` だけを点けた夕暮れの見下ろしでは、円盤の画素の寄与（Combined、RGB平均）0.49/0.38/0.21のうち、タイルのSpecular IOR Levelを0にしても0.39/0.31/0.17が残る。タイルの光沢は2割ほどで、ぼけた光として重なるだけ。
- 円盤の画素からカメラ光線を追うと（シーンの `ray_cast`、Fresnelで両方に分岐）、主な経路は「水面を透過→**水形状の底面（水→空気、R 0.12〜0.25）で反射**→（側面の全反射）→水面から出て灯り」。水形状の底面（y=0.215）はタイルの上面（0.202）より1.3cm上にあり、間は空気なので、底面は滑らかな（粗さ0.018）水と空気の境界になる。
- 水形状の底面の頂点484個を0.19mへ下げて（タイルを水の中に入れて）描き直すと、夕暮れの見出し1・2・4の円盤と見出し4の筋がすべて消える。昼は見出し0・4の`V7 water reflection soft strip`の筋、見出し1のV9の淡い円盤、遠くのタイルの白っぽい映り込みが消える。同時にタイル全体は（1−R）の分だけ明るくなる。

屈折した視線は臨界角より急に下る（|d.y| ≥ 0.66）ので、底面で全反射はしないが、反射率は真下で2%、遠いタイルでは25〜100%に達する。ブラウザの水中は底面の境界を描いておらず、この反射もタイルの減光もなかった。

光源ごとの光線の可視性も確認した：反射した視線は水面から**透過レイ**として出るため、Cyclesでは透過に不可視の `V7 water reflection soft strip` はこの経路で見えない（光沢に可視・透過に可視は `V9`・`V10 lounge dusk fill` ほか）。

## 方式

`waterBottom.ts`（`bottomExit`・`upwardExit`・`clearsRim`・`lightCoverage`・`bottomLightRadiance`・`sourceSH` がTSの参照実装）。

- 水の底面より下のプールの床（`WATER_VOLUME` のxz、裏の内壁の足元5cmを含む）を描く材質に `SUI_WATER_BOTTOM` を定義する（配信モデルでは4材質）。`refraction.ts` が画素の視線を波の法線で屈折させた方向（`suiWetView`、鏡映像では鏡映した方向）を渡す。
- 床の色を `(1 − R)·透過色·床 + R·上へ反射した放射輝度` にする（Rは底面での水→空気のFresnel、透過色は屈折ごとに掛かる水の色）。この後に従来の水越しの色と吸収が掛かる。
- 反射した視線は底面から上へ、側面で反射し（臨界角を超えれば全反射、以下はFresnel反射率、残りは壁へ抜ける）、水面で波の法線について屈折して出る。途中の吸収と、出るときの透過色を掛ける。水面で下へ反射する分は床の色で代用する。
- 出た光線が見るもの：反射プローブ（水面の鏡像がないときと同じ粗さ0.018）＋光沢にだけ見える面光源のうち水面より上で水面を向き、透過レイに見えるもの（`V9 lounge patch of sunlight`・`V10 lounge dusk fill`）。光源は光線と元の形の交差で求める（縁は大きさの3%でぼかす）。プールの縁石（上面1.035m、4辺とも元blendで計測）より低く側面を越える光線は光源に届かない。
- 反射プローブは光沢レイで焼いたので `V7 water reflection soft strip` をぼけた形で含む。プールの中央・水面0.5m上から見たV7のL2係数（`sourceSH`、32×32の分割で積分）を引く。引かないと、真上のV7のぼけた光で夕暮れの見下ろし全体が約+4 L*明るくなった。

## 残る差

- 円盤の縁がCyclesより硬く、周りのぼけた光がない：タイル自身の光沢（粗さ0.3、寄与の約2割）でぼけた同じ像が重なる分を省いた。タイルの光沢は反射プローブ（水中グリッド）だけで、寝椅子灯・V9は含まない。
- 昼は変わった画素がCyclesより明るい（L* +4〜7）。変更前から昼の見下ろし全体がCyclesより約+7 L*明るく、その差は残る。
- 反射した視線の環境はL2の反射プローブなので、縁石・壁の像はぼける。V7の差し引きはプールの中央の1点から見た係数で、端では位置がずれる。
- 見出し4（注水口側）では、Cyclesの細い筋と小さな点に対し、ブラウザは大きめの円盤1つになる。波の強い注水口付近で、像の位置を平らな水面のまま置く近似の差と見ている（未確認）。
- 側面の内壁（6mm裏）も同じく水→空気の境界越しに見えるが、側面の透過色は掛けていない（1−Rは前回の部分反射で扱い済み）。
