## 確認

Chrome 156、1280×800・標準DPR1・固定解像度・動作抑制。

- 静止画：`REVIEW_RUN=<回> bunx playwright test --config playwright.visual.config.ts e2e/graphic-review2-20261029.visual.ts`（撮る前に `bun run build`。`REVIEW_STAGES=sauna,water` のように撮るステージを絞れる）の18視点を、変更前（HEADを別の作業ツリーでビルド）・途中・最終で撮って並べ、目視した（画像はローカルのみ）。
  - 冬：林の常緑樹が細い円錐の針葉樹の並びになり、裸の木と針葉樹の冬の林に見える。円錐の上端に広葉の房のような塊が残る木や、幹の先が円錐の上に出る木がある。秋・春・夏も常緑樹は針葉樹の形で、紅葉の間に暗い針葉樹が混ざる。
  - 手前の樹冠：カードの塊が3つの房に分かれ、空を背にした大きな葉の切り抜きは小さく細かくなった。葉1枚ずつの切り抜きの印象は残る（改善は控えめ）。
  - サウナ：夜はストーブの足元の床に暖色の光だまりができる。昼は籠越しの熾火が赤く見える程度で、見た目はほぼ変わらない。最初に試した強さ（2.4・0.82・0.22、d²+0.12）では夜の床とベンチ全体が平らな橙に明るくなり（以前に夜の露出で直した見え方）、弱めて減衰を急にした。
  - 外気浴：草地に数mの濃淡の斑が出た（控えめ）。
- 描画費用：`GRAPHIC_COST=1` の `frame-cost.gpu.ts`（標準・DPR1、`FRAME_COST_REPEAT=3`、`warmup,product`、`--reporter=json`）を、変更前（`4961fee` のdist、別の作業ツリーでビルド）と後→前→前→後で測った（`cost.json`、`scripts/summarize_frame_cost.py`）。描画間隔の比（中央）はサウナ0.979〜0.998、水風呂の昼0.999・夕夜1.017〜1.02、外気浴の昼1.025（1.013・1.038）・夕1.015・夜1.001。外気浴の昼と水風呂の夕夜の1〜4%増は計測のぶれと同程度かやや上で、切り分けはしていない（候補は円錐で密になった常緑樹のカードの重なりと草地の斑のノイズ1回）。三角形・描画数は不変。
