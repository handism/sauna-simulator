# 秋の草地（2026-10-12）

## 課題

秋にしても、木々（林のカード・モミジ）だけが紅葉し、外気浴から見える起伏の苔地と林床は夏と同じ緑のままだった。`season.ts` が切り替えていたのは葉の材質色だけで、地面は季節で変わっていなかった。

## 変更

`autumnGround.ts` を追加した。`season.ts` が、`surfaceDetails.ts` の `ground` の材質（`V9 | layered living moss`・`V3 | moss and woodland earth`）に適用し、uniform `suiAutumnGround`（秋は1、それ以外は0）で切り替える。再コンパイルは発生しない。

- **枯れ色**：乾いた斑・尾根ほど、色を ×(1.25, 1.0, 0.6) のオリーブ〜わら色に寄せる。量は `0.45 + 0.45·乾き − 0.35·湿り` を0〜1に制限した値で、湿った斑には緑が残る。
- **落ち葉**：9cmのセルごとに、ずらした中心・向き・大きさ（0.75〜1.25倍）・色（赤・橙・黄土・茶、明るさ0.8〜1.2倍）の違う楕円（半径はセルの0.42×0.22）を置く。
  - 置く確率は、被覆率÷楕円の面積とする。被覆率は数m周期の吹きだまりで6〜36%、急斜面では最大8割減らす。
  - セルが約1画素以下になると、被覆率と平均色へフェードする。遠景の点滅を避けるためである。
- **挿入位置**：表面の質感の `ground` の後（その位置・乾き・湿り・斜面を読む）で、粗さの下限・雪の前。雪は後から覆う。
- `data-autumn-ground-materials` に対象材質数を記録する。

## 不採用

最初の案は、枯れ色を ×(1.32, 1.02, 0.52) の強さで `0.55 + 0.45·乾き − 0.25·湿り` だけ掛け、落ち葉の被覆率を12〜62%にしていた。このため、中景が一様なオレンジがかった茶色になり、晩秋の枯れ野に見えた（`rejected-first-try.jpg`、上が変更前、下が最初の案）。

## 確認

- `garden-details.e2e.ts` で撮影した。
  - `compare.jpg`：上から夏、変更前の秋、変更後の秋。
  - `near.jpg`：変更後の秋の近景。手前の草地に落ち葉が見え、中景は温かい枯れ色で、湿った斑には緑が残る。
- 型検査、374単体テスト、Lint、整形、本番ビルド、通常のブラウザ回帰79件（23.0分）がすべて成功した。

## 費用

`frame-cost.gpu.ts`（標準画質・1200×800・DPR1・固定解像度・`FRAME_COST_REPEAT=3`・`FRAME_COST_VARIANTS=product`、夏）を、変更前（`98fc27d` のworktree）と交互に3組測った（[値](cost.json)）。フレーム間隔の比（3組の中央値）は次のとおり。

| 視点 | 昼 | 夕暮れ | 夜 |
| --- | --- | --- | --- |
| サウナ | 1.004 | 1.004 | 0.996 |
| 水風呂 | 0.993 | 0.994 | 0.992 |
| 外気浴 | 1.000 | 0.996 | 1.000 |

いずれも0.992〜1.004倍で、測定のばらつきの範囲内である。描画数は変わらない。秋の視点（分岐を実行する場合）の費用、DPR 1.5・高画質、実機は測っていない。

## 範囲

落ち葉は色と粗さだけの平面の模様で、厚み・影・風での動きはない。木の位置とは無関係な吹きだまりに置く。苔地以外（デッキ・石・砂利・低木の足元）には落ちない。元GLB・プローブは変更しない。夕夜・雨の秋、見回し中のちらつき、全周撮影は確認していない。
