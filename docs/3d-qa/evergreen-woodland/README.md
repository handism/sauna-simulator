# 林の常緑樹（2026-10-12）

## 課題

冬の外気浴・水風呂では、林の木がすべて葉を落とし、棒だけの枯れ木の並びに見えた。林の葉（`V6 woodland leaf 0〜4 card`）は季節の処理で広葉樹として扱われ、冬はメッシュごと非表示になる。葉カードは色ごとの5材質に結合されており、どの木にも5色が混ざっている（3m格子250区画のすべてで1色が8割未満）。そのため、材質単位で残すと全部の木が均一に薄くなるだけで、木ごとに常緑を残せない。

## 変更

`evergreenWoodland.ts` の `splitEvergreenWoodland()` を、庭のGLBの解析後・材質準備の前に呼ぶ。

1. `Tree bark` の接続成分のうち、y<0.6から2m以上伸びるものを幹とし、下端0.3mの頂点の平均を根元とする（157本）。位置の重複の結合は不要だった（あり／なしで同数）。
2. 幹の位置（10cm単位）の整数ハッシュで約35%を常緑にする（59本）。
3. 各カード（4頂点・6インデックス）を、地面上で最も近い幹（5m格子で探索、5m以内）に割り当てる。常緑の木のカードは、材質を複製した別メッシュ（名前末尾 ` evergreen`、色×(0.58, 0.7, 0.6)）へ移す。カードの両側に頂点を共有するメッシュは分けない。
4. 常緑の材質名は `season.ts` の紅葉・落葉の対象に一致しないため、季節によらず緑のまま表示される。`woodlandCrowns.ts` の拡大・複製は同じく受ける。雪は粉雪程度（`winterSnow.ts` の `SUI_SNOW_DUSTING`）。

実データの分割：各色の常緑側が約2,900枚、落葉側が約4,800枚（常緑は全体の約37%）。

## 確認

- `garden-details.e2e.ts` の四季・夕夜・雨・水風呂の撮影を目視した（`seasons.png`：夏・秋・冬・春・水風呂・夜）。
  - 冬は濃い緑の樹冠と枯れ木が混ざる林になる。
  - 秋は紅葉の間に濃い緑が残る。
  - 夏・春は約35%の木がやや濃い緑になり、色の変化が増える。
- 単体テスト（`evergreenWoodland.test.ts`）：木ごとの移動・カード数の保存・材質の複製、秋の色・冬の非表示を受けないこと、幹がないときは変えないことを検査する。

## 費用

`frame-cost.gpu.ts`（標準画質・1200×800・DPR1・固定解像度・`FRAME_COST_REPEAT=3`、夏）を、同じ作業ツリーから分割の呼び出しだけを外した版と交互に3組測った（[値](cost.json)）。フレーム間隔の比（3組の中央値）は次のとおり。

| 視点 | 昼 | 夕暮れ | 夜 |
| --- | --- | --- | --- |
| サウナ | 1.010 | 1.005 | 1.008 |
| 水風呂 | 1.011 | 1.013 | 1.010 |
| 外気浴 | 1.020 | 1.017 | 1.013 |

描画数は主パスで+5、三角形数は不変。読み込み時の分割はbunで約50〜60ms（ブラウザでは未計測）。冬の視点の費用、DPR 1.5・高画質・実機は測っていない。

## 範囲

木の割り当ては、地面上で最も近い幹による近似で、樹冠が重なる所では隣の木のカードが混ざる。常緑樹も元の広葉樹のカードの形のままで、針葉樹の形にはしない。`Fine canopy leaves`・V5の頭上の樹冠・モミジは従来どおり。ベイク済みのプローブは変更しない。
