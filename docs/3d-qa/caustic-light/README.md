# 時間帯・天気による水底の網目の減光（2026-10-20）

## 課題

- 疑似コースティクス（`V10 | submerged light` の発光、`caustics.ts`）は元blendで時間帯によらず一定。
- 夕暮れ・夜は露出が昼より開く（+0.55・+0.9段）ため、日光のない時間帯ほど水底の明るい網目が目立ち、タイルの模様のように見えた。

## 変更（元blendにない補正）

- `causticLight(weights, clouds)`：時間帯の重みで `CAUSTIC_SCENES`（昼1・夕0.22・夜0.06）を混ぜ、曇天の割合で `CAUSTIC_OVERCAST`（0.3）まで弱める。
- 値は共有uniform `suiCausticLight` で全材質（側面の像の複製を含む）へ渡し、`SaunaScene` が毎フレーム `lighting.time`・`lighting.clouds`（平滑化済み）から更新する。再コンパイルなし。
- 強さの関数 `sui_caustic_strength` は変えず、Blender照合（`caustics.e2e.ts`）はそのまま。

## 確認

- `e2e/plunge-woodland.visual.ts`（Chrome 155.0.8059.85、標準DPR1・1280×800・動作抑制・固定解像度）で、変更前のdist（`2031a0f`）と変更後をABBA撮影（各20枚、計80 PNG）。ページ・コンソールのエラー0件。
  - 同方式の再撮影差は全条件で0画素。
  - 8階調超で変わった画素：水風呂の昼0%、夕暮れ7.1〜13.5%、夜10.1〜17.2%。外気浴0〜0.4%。
  - 平均輝度（0〜255）：夕暮れの見下ろし41.2→38.9、夜の見下ろし35.7→31.9。
- 比較画像 `water.jpg`（ローカルのみ、左が変更前）：水風呂の昼・夕暮れ・夜×既定・見下ろし・横。
- 型検査・461単体テスト・Lint・整形・本番ビルド、`caustics`・`scene-no-hdr`・`scene-lifecycle` の24回帰が成功。

## 範囲

- 雨・雪の水風呂は撮影していない（曇天の減光は単体テストのみ）。
- 費用は計測していない（uniformの乗算1つ）。
- 寝椅子灯が水底に映る輪郭のはっきりした像（`waterBottom.ts`、Cyclesにもある）は変更していない。
