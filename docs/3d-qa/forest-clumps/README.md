# 奥の森の葉群（2026-10-21、採用）

これまでの奥の森の調整（[forest-volume](../forest-volume/README.md)・[relief](../forest-relief/README.md)・[shading](../forest-shading/README.md)・[overlap](../forest-overlap/README.md)・[back-crowns](../forest-back-crowns/README.md)）は、どれも「変化は控えめで帯の平面感は残る」で終わっていた。外気浴から右へ約92°向いた視点を拡大すると、手前の樹冠の立体（頂部から地中 y=−4 までの約10m・幅4〜5mの縦長の卵3つ）が、内部の明暗のない霞色の**岩の尖塔・卵の書き割り**に見えていた。

## 変更

`farForest.ts`：

- 各樹冠の手前側に小さな葉群（低分割の楕円体、5段×8分割・64三角形）を、手前73樹冠に10個、中間19に6個、奥18に4個載せる。広葉樹は樹冠の半径0.95倍のドームの手前半分（赤道の少し下から約70°上まで）に半径0.28〜0.40倍、常緑樹は頂部から下へ左右交互に縁へ張り出す段（下ほど広く大きい）。頂部は従来の樹冠の頂部を超えない。
- 広葉樹の芯の卵は樹冠の半径の半分だけ低くし、上の輪郭を葉群の連なりが作る。芯は0.74倍に暗くする（葉群の下の陰）。
- 葉群の頂点色は、側面を芯より少し明るく、上向き・日光（`lighting.ts` の固定方向）側を明るく、下面・樹冠の下の方を暗くし、葉群ごとに0.88〜1.12倍の明るさをばらつかせる。地上から50m先を見上げるため上面はほとんど見えず、上向きの面だけで明るくする版（試作3版目）は暗い塊のままだった。
- メッシュをインデックス付き（Uint32）にし、楕円体の格子の頂点を共有する。森は32,780→91,404三角形、頂点属性とインデックスの合計は4.72→5.32MB（インデックスなしでは13.2MBだった）。材質・描画数・テクスチャ・影パスは不変、季節の色・霞・時間帯・曇天は既存のまま。

試作の初版（6分割・日光の向きだけで陰影）は、背後から日が当たる方向で葉群が多角形の暗い円盤に見えた。

## 確認

- 外気浴・水風呂・サウナの右約92°（`SHIMMER_HEADING_STEPS=20`）を昼夕で撮影し、変更前（`98500dd` のworktree）と並べて目視（画像はローカルのみ）。広葉樹は丸い葉群の集まった樹冠、常緑樹は段のある針葉樹の輪郭になり、夕暮れのシルエットも木の連なりに読める。浮いた葉群・欠けは見当たらなかった。
- 制御した見回し（比較用カメラを右60キー分、段1.5）の面の残差は変更前の0.996〜1.000倍、面の99百分位0.984〜1.000倍（[値](values.json)）。
- `frame-cost.gpu.ts`（標準DPR1・描画3回）を変更前→後→後→前で、既定視点と右20キー分の各9条件。描画間隔の比は0.996〜1.008倍。
- 単体テストは全立体（芯・肩・葉群）が閉じていること・樹冠の頂部以下・三角形と容量の上限を検査。型検査・464単体テスト・Lint・整形・ビルドが成功。

## 範囲

夏・晴れの昼夕だけを撮り、秋冬・夜・雨雪・高画質・全周は見ていない（季節の色は従来の頂点色の塗り替えで葉群にも掛かる）。54mの奥の帯（平面）自体は変えていないので、立体の間から帯が見える所では平面感が残り得る。固定方向の近似陰影で、時間帯ごとの日光・影ではない。実機・GPU総確保量は未確認。
