# 近景の草花・川石と林の房（2026-10-13〜14）

## 変更

変更前は `b44daa8`。`gardenDetails.ts` の草を直線の三角形から4区間の曲線へ変更し、先端を細く、株ごとの高さ・広がり・葉の方向を変え、根元を暗くした。8株×32枚を維持し、草の三角形は256から1792へ増えるがメッシュ数は同じ。固定乱数で生成し、季節・動作抑制・解放は既存の経路を使う。

低木の葉は薄く反らせ、小花を扁平にした。川沿いの石は大小・間隔・埋まり方を変え、同じ大きさの列に見える印象を減らす。石・低木・花の数は維持する。

`woodlandCrowns.ts` は細長い葉カードの短軸を最大1.45倍、長軸をその逆数にし、面積と中心を保ちながら枝先の房を丸みのある形へ寄せる。既存の拡大・複製1枚・照明法線・UVは維持。葉カード数・描画数は増やさない。近景のモミジ・元GLB・ベイク済みプローブは変更しない。
