# 林の樹冠の縁（2026-10-21、採用）

[遠い林の樹冠の埋め](../crown-fill-far/README.md)の後も、20〜40m先の林の樹冠の縁では、暗い葉のカードが1枚ずつ硬い輪郭のまま空に浮き、点の集まりに見えた（見回し中の残差もここに集中する）。

## 変更

- `crownNormals.ts`：各カードの中心の、その木の樹冠の楕円体での半径（中央値0.72、上位10%で1.16以上）から、外殻の段階（1.0→1.45を0〜7）を求め、カードのUVのuに `2×段階` を足す。葉のマスクはRepeatにするので、葉の形は変わらない。本描画・深度プリパス・影マスク・影マップのどれもが同じUVを読むので、新しい属性やvaryingは要らない。
- `leafCluster.ts`：昼（`1 − suiIrradianceEvening`）、葉が1画素未満になる距離（1画素が1→2テクセル）で、外殻のカードの出力を、色相を保ったまま空気の色の輝度の0.6倍へ最大0.3（`LEAF_RIM`）寄せる。空を透かした縁の葉の明るさの近似で、元blendにはない補正。トーンマッピングと距離の空気遠近の前、線形のまま。

不採用：

- 外殻のカードの被覆の遷移を広げて半透明にする案：alpha-to-coverageの部分被覆が、細かい網点（スクリーンドア）として見えた。
- 空気の色そのものへ寄せる案（外殻0.8〜1.2で0.35、1.0〜1.45で0.15）：前者は樹冠全体が白く霞み、後者も縁の葉が灰色の霧の斑に見えた。
- 夕夜も同じに持ち上げる案：空を背にした影絵の締まりが失われ、縁の葉が浮いた。

## 確認

変更前は実旧ビルド（`dbcbcf1` のworktreeのdist）、前→後→後→前。Chrome 155.0.8059.85。値は [values.json](values.json)。

- 静止画（`forest-leaf-masses.visual.ts`、1280×800・標準DPR1・固定解像度・動作抑制、3ステージ×昼夕夜×水平3方位＋外気浴の春秋冬の昼、30枚×4）：全件成功、同じ版の再撮影差は0。ΔE>2の画素は昼で最大5.8%。夕夜は0.3%以下で、効果を切っているのに変わるのは、マスクをRepeatにしたことで小さなミップの縁が反対側の縁と補間され、遠いカードの被覆がわずかに変わるためと考えられる（切り分けていない）。
- 制御した見回し（`resolution-shimmer.visual.ts`、1200×800・DPR1.5・段1.5固定・`&camera=review`、既定視点、3ステージ×昼夕）：回転補償残差の前後比は、昼で画素0.93〜0.97・面0.93〜0.96・面の99百分位0.89〜0.93、夕暮れで1.00〜1.01。同方式の再撮影は1.000。知覚的なちらつきの合否ではない。
- 描画間隔（`forest-back-crowns.gpu.ts`、標準DPR1・右20キー・描画3回反復）の比は0.997〜1.009。
- 単体テスト：段階が中心0・角6になり、UVの小数部（葉の位置）が保たれること、本描画のシェーダーで被覆の後・トーンマッピングの前に持ち上げが入ること。

## 範囲

季節ごとの林（静止画の季節は外気浴の右60キーで、林は壁に隠れる）、雨雪、高画質、近い木（葉が1画素以上なので効果はない）の目視、実機は未確認。外殻は木ごとのカードの中心の広がりで測る近似で、カードの拡大・複製（`woodlandCrowns.ts`）は元のカードの段階を引き継ぐ。
