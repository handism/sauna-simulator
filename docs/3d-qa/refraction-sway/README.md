# 水越しの像の揺らぎ（2026-10-17）

## 変更

`refraction.ts` の平面水面の見かけの深さへ、既存の `WAVE_NORMAL` による接線方向の変位を重ねる。平面の入水点におけるスネルの条件を一次近似し、視線に沿う方向／横方向のヤコビアンで波の傾きによる像の移動を求める。変位は滑らかに最大8mmへ制限し、入水点から水際までの12cmでゼロへ戻す。

像の見かけの高さ・実際の照明位置・水の色と吸収は従来の平面近似を使う。水面の高さ自体を曲面にして厳密に光線追跡したものではない。既存の0.1m格子をタイルにも適用する。従来は0.3mを超える辺があるメッシュだけを分割していたが、0.1mを超える辺に変更する。三角形は増えるが、追加の描画パス・テクスチャはない。細かい波は頂点間で補間される。

真の面・側面／角の鏡映像・鏡映像の深度判定・深度プリパス・影マスクで同じ頂点変形と時刻uniformを使う。動作抑制時は既存の波と同じ時刻0で固定する。水面の反射の波は既存のまま。

## 検証

CPU参照実装を独立した傾斜平面のスネル方程式の数値解と比較。小さな傾きで20µm以内。共有する解析法線が波の高さの数値微分と一致すること、平らな法線／水際／水面下カメラで変位ゼロ、時刻固定と8mm以内の制限を単体テストで確認する。深度プリパスと影マスクの時刻uniformの共有も検査する。

季節補正のみのビルドを基準として、揺らぎ追加後を前→後→後→前で比較する。標準DPR1・固定解像度・TAAあり。昼／夕×正面／見下ろしの4経路、各36位相を1/60秒刻みで進め、各位相で2回のrAFを明示的に実行する。撮影中は実際のアプリのrAFを保留し、撮影待ちで位相や蓄積回数がずれないようにする。別に各経路2枚を動作抑制で撮る。1回152 PNG。実時間動画・アプリFPS・知覚的ちらつきの合否ではない。

初候補では、粗いままのタイルの内部へ、材質識別上は下地に対応する暗い多角形が現れた。タイルと分割済みの下地の補間差による交差と推定する。深度比較・プリパス・TAA・両面化だけの変更では消えず、材質識別用の診断とタイルの格子分割で切り分けた。初候補の画像は合格の記録へ含めない。タイルも同じ格子で分割する回帰テストを追加した。

Chrome 155.0.8059.80で最終候補の前後各2回、4件・608 PNG成功。各版152枚すべて再撮影差0画素。動作抑制の各2枚も全4経路・全4回で差0画素。変更後4経路の6位相ずつの一覧と、昼夕の見下ろし各0／17／35位相の原寸ペアを確認。目地の緩やかな曲がりが増し、確認範囲で初候補の暗い多角形・大きな欠けなし。全152枚の原寸目視合格ではない。

水のROIの平均フレーム差（sRGB重み付き輝度、0〜255）は昼正面0.417→0.639、昼見下ろし0.341→0.889、夕正面0.392→0.615、夕見下ろし0.354→0.903。二階差分も0.437〜0.507→0.636〜1.051へ増えた。像を動かした結果を含み、これをちらつきの改善と解釈しない。実時間の連続視聴・長い波の位相・高画質・夜のこの経路・実機は未確認。

`validation.json` が最終レポート・全PNG・入力ハッシュ、時刻とrAF回数、再撮影差を保持する。`diagnostics.json` は棄却候補と診断、撮影ラッパーの後処理失敗からの回復を記録する。最後の基準撮影はPlaywright自体が成功した最終JSONと152 PNGを照合し、別処理で移動と出力先の修正を行ってから集計した。
