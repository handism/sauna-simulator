# 夕暮れの日光の影を簡略化する候補（2026-09-28）

結論：**日光の影を完全に外す案は不採用。硬い影は次の検証候補として残すが、製品には未採用。** 前回の[影の費用の切り分け](../shadow-facing/README.md)に続き、強度0.045の日光だけを比較した。製品のシェーダー・光源・配信物は変更していない。

## 方法

- `e2e/sun-shadow.gpu.ts` が検証ブラウザの `shaderSource` だけを差し替える。方向光の `getShadow` 呼び出しを通常PCSS／1回の深度比較／常に1（影なし）にする。スポット光、影マップ、光源強度、受け側の微分、面の向きの分岐は同一。
- Chrome 154.0.8037.57、macOS headless、1200×800、DPR1、高画質、動作抑制、庭の準備完了後。通常→硬い影→影なし→通常の再撮影の順で各1回。3ステージの既定視点とCyclesカメラ01〜05・07の合計9視点をPNGで撮影した。
- GPU時間は既定視点のみ、共通の `gpu-timer.ts` で描画を含むコールバックを4秒間計測し、1秒後に回収。CPU負荷を伴うテストは同時に実行していない。撮影・時間計測の成功を画質の合格とは扱わない。
- `scripts/summarize_sun_shadow.py` は元解像度で通常とのΔE76を、600×400（BOX縮小）で既存Cycles夕暮れ画像とのΔE76を集計。変更領域はΔE>0.5（今回の弱い光の影ではΔE>2がほとんどなく差を見落とすため）とし、従来のΔE>2も併記。0.5は領域抽出用の値で、知覚や採用の合格線ではない。
- [集計・入力ハッシュ](summary.json)、[全標本・描画メトリクス](runs.json)。開始時HEADは `a7ed3fb`。Cycles画像は既存の参照を使用し、Blenderは再実行していない。

## 画像

通常の再撮影は9視点すべて差0。硬い影の通常との差は、平均ΔE76 **0.012〜0.102**、ΔE>0.5の画素 **1.3〜12.6%**。影なしは平均 **0.025〜0.313**、同 **2.8〜35.5%**。

| Cyclesカメラ | 硬い影：変更領域の誤差（通常→候補） | 影なし：変更領域の誤差（通常→候補） |
| --- | ---: | ---: |
| 01 | 6.088 → 6.089 | 6.811 → 7.029 |
| 02 | 7.389 → 7.397 | 6.962 → 7.001 |
| 03 | 5.511 → 5.534 | 9.085 → 9.008 |
| 04 | 6.032 → 6.038 | 8.212 → 8.239 |
| 05 | 5.810 → 5.799 | 7.198 → 7.307 |
| 07 | 3.648 → 3.644 | 4.108 → 4.147 |

各候補で変更領域が異なるため、列を直接比較しない。既存の形状・照明・蒸気の差も含むCycles誤差は、日光の影だけの物理的正確さを保証しない。

- 硬い影：全画面のCycles誤差はほぼ同じだが、白い壁の葉の影、庭やデッキの影の輪郭がはっきりする。静止画の低コントラストの差は小さい。まだ見回し時のちらつき・全周・標準画質・昼夕の補間を検証していないため採用判断は保留。
- 影なし：室内の床など、屋根・壁で遮られるはずの面が明るくなる。Cyclesの変更領域の誤差は6視点中5視点で増加。速度のために遮光を失う案は採用しない。
- 次は夕暮れの日光に限る低費用のぼかし（少数のPCFなど）と硬い影を比較し、見回しの連続画像・全周・昼夕の補間で判断する。昼の日光PCSSの標本配置の分散低減も別の残件。

## GPU時間（ms、各条件の中央値）

| 既定視点 | 通常（開始／終了） | 硬い影 | 影なし |
| --- | ---: | ---: | ---: |
| サウナ | 95.66 / 102.15 | 83.20 | 81.27 |
| 水風呂 | 109.51 / 107.27 | 88.37 | 85.73 |
| 外気浴 | 69.86 / 63.05 | 58.16 | 49.93 |

硬い影は両端の通常より短く、両端の平均に対して約13〜18%減。描画数・三角形数は同一。**候補は1回ずつで逆順の追試なし**。通常だけでも変動があり、前回と画面幅・実行時の性能も異なるため、確定した高速化率や前回からの退行とは扱わない。採用前に逆順・複数組で再測定する。GPUクエリ時間は画面の表示FPSやCPU・コンポジタ費用ではない。

## 再実行

```sh
bun run test:browser:gpu e2e/sun-shadow.gpu.ts --reporter=json > /tmp/sauna-sun-shadow.json
python3 scripts/summarize_sun_shadow.py /tmp/sauna-sun-shadow.json docs/3d-qa/sun-shadow
```

集計には撮影直後の `test-results/gpu` と `blender/renders/{06.png,web-bluehour/}` が必要。後続のGPU試験で撮影が消える前に集計する。GPU拡張がない場合も撮影は行い、時間は空として記録する（今回すべて取得成功）。
