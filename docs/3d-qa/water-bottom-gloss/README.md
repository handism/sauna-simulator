# 水底反射の斑の内側：タイル自身の光沢と、その影の位置（2026-09-29）

[water-bottom-bump](../water-bottom-bump/README.md) の残る差「Cyclesの斑は内側にタイルの目地が透け、中央ほど白い。ブラウザの内側は一様な面のまま」を調べて直した。斑は水風呂の夕暮れ・夜に水面へ出る寝椅子灯（`V10 lounge dusk fill`）の像で、水の底面での部分反射（[water-bottom](../water-bottom/README.md)）。

## 原因の切り分け（Cycles）

`scripts/diagnose_water_bottom_gloss.py`（元blend、ブルーアワー、512サンプル・デノイズなし、読み取りのみ）で、斑の部分を寝椅子灯だけのライトグループ付きで4条件で描いた。斑（寝椅子灯の成分の上位20%の画素）の寝椅子灯の成分（線形）：

| 条件 | 見下ろし | 見出し2 |
| --- | ---: | ---: |
| そのまま | 0.371 | 0.360 |
| タイルの Specular IOR Level 0 | 0.295 | 0.289 |
| 水の底面をタイルの下へ（0.19m） | 0.011 | 0.011 |
| 両方 | 0.002 | 0.002 |

- タイルの光沢を0にすると、Cyclesでも斑の内側の目地と明暗が消えて一様になる（`review.png` の右端の列）。斑の光の約2割（0.076/0.371）は**タイル自身の光沢が映す寝椅子灯**で、残り8割が底面の反射（前回の「光沢0でも円盤の8割が残る」と一致）。
- この光沢は、タイルが水の底面の下の空気層にあるから強い。底面を下げてタイルが水中に入ると0.011まで落ちる（水中の相対IOR 1.5/1.333ではF0が約0.35%、空気中なら4%）。
- 目地はタイルの間の隙間（下の基壇が見える）で、光沢がないので暗い線になる。タイルは粗さ0.3のため、光沢はぼけた明るい部分として斑の中に重なる。

## ブラウザで出ていなかった理由

ブラウザには既に、空気層の中のタイルが映すV9・寝椅子灯の鏡面（`waterBottom.ts` の `suiWetSpecular`）がある。寝椅子灯の鏡面だけを外した一時ビルドとの差は、斑の中で表示値（8bit）0.8。影を無視した一時ビルドでは5.45で、**影で85%が消えていた**。

- 影は床の点から光源への直線で引いていた。実際の経路は空気層を空気中の向きで上り、水中では急に（IOR 1.333）上り、水面から先は再び空気中の向きで進む。床の中央から寝椅子灯（glTF (5.9, 2.8, 1.4)）への直線は、奥の縁石（1.035m）の手前で約0.93mにしか届かないが、屈折した経路は水面を出た時点で縁石を越える。
- 最初の修正（影を出口で引く）では変わらなかった。影の法線オフセット（寝椅子灯は1.5cm）でタイル上面の頂点（0.202m）が水の底面（0.215m）より上に出て、水中の床と判定されていなかった（目地だけが移っていた。影の値を2値で色にした診断ビルドで判明）。判定をオフセット前の位置で行うようにした。

床の格子（24×28）で、寝椅子灯が見えるかを元の形状で調べた平均（`gloss.json` の `visibility`）：

| 判定 | 平均 |
| --- | ---: |
| 厳密な屈折経路・円盤全体（216点） | 0.368 |
| 厳密な屈折経路・円盤の中心 | 0.504 |
| 製品の近似（直線の向きで出口を求め、中心へ直線） | 0.515 |
| 床からの直線（修正前） | 0.241 |

製品の近似は厳密な中心の判定と格子の99.0%で一致する。遮るのは水槽の側壁（`Plunge side basalt`）と縁石で、パーゴラなどではない。円盤の一部だけが見える半影はPCSSのぼけに任せる。

## 方式（`waterBottom.ts`）

- 水中の床（`SUI_WATER_BOTTOM` の材質で、法線オフセット前の位置が底面より下・水の箱のxz＋`SIDE_WALL_LAYER` の内）の頂点だけ、`shadowmap_vertex` のスポット光の影座標 `vSpotLightCoord` を、屈折した経路が水面を出る点に置き換える。光源の位置は `spotLightMatrix` の x・y・w 行が0になる点として求め（`shadowSource` がTS版）、床からその向き（空気中）で空気層・水を進んだ水平距離は `wetExitRun`。水中の床でスポット光の影を使うのはV9・寝椅子灯の鏡面だけなので、ほかの画素は変わらない。
- `suiWetSpecular` は同じ出口が水の箱の外なら（経路が先に側面に当たる）足さない。
- 近似：出口は直線の向き（厳密な経路より少し急）で求め、出口から光源の中心への影を引く。上の表のとおり中心の可視判定は厳密な経路とほぼ一致する。

Cyclesでタイルの光沢を0にした斑は、夕暮れで7.4／7.1（標準偏差）。

- 斑の内側に目地が透け、光源側の上部が明るくなり、斑の外にも光沢のにじみが出る。標準偏差と95%点はCyclesとほぼ一致し、平均は差が約半分になった（まだ2.5〜5低い）。
- 12視点のCyclesとの平均ΔE76（全画面）は悪化なし（夕暮れの見下ろし 5.901→5.859、見出し2 9.249→9.219、夜 5.919→5.895・9.693→9.673）。変わった画素の帯では夕暮れ・夜の見下ろしと見出し2で改善（例：夕暮れの見出し2 12.08→11.46、夜の見出し2 11.19→10.75）。昼（V9）の変化は729〜3,671画素で、帯のΔE76は同じか0.03以内の改善。夕暮れの見出し4だけ帯で+0.017。
- 比較画像（ローカル）：`review.png`（行：夕暮れ・夜 × 見下ろし・見出し2。列：変更前・変更後・Cycles・夕暮れはCyclesのタイル光沢0）。

残る差：

- 斑の平均がCyclesより2.5〜5低い。タイルの光沢の強さ（表示値でCycles約8.8、ブラウザ約5.5。Cyclesの値は環境の光沢も含む）と、円盤の一部だけが見える位置の扱い（ブラウザは中心の影＋PCSS）。
- 見下ろしの斑の位置・大きさのずれ（Cyclesは右に寄って大きい）と、見出し4の像の形は今回の対象外で、変わらない。
- 縁のほつれが1画素で硬いことは前回のまま。
