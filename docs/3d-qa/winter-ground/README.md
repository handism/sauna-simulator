# 冬の雪原の露出とデッキの縁の雪（2026-10-13）

## 課題

- 冬の昼、雪原がトーンカーブの肩に乗ってほぼ一様な白になり、地面の起伏や吹きだまりの濃淡（`winterSnow.ts`）が読めなかった。
- デッキは屋根の下として雪を除外していたが、屋根の端（z 0.74）より外の約2m（〜2.84）も同じ箱に入っていた。開けたデッキが板のまま白い庭と直線で接し、切り抜いたように見えた。デッキの板（`V7 | locally damp ash`）は雪の対象材質にも入っていなかった。

## 変更

- `lighting.ts`：`update()` に `groundSnow`（冬の季節のとき1）を加え、昼の重みで露出を `SNOW_GROUND_EXPOSURE`（−0.35段）絞る。雪景色にカメラ・目が順応する分。季節の材質と同じく即時に切り替わる。夕夜は変えない。
- `winterSnow.ts`：屋根の下の箱の中でも、y<0.5・z>1.7の開けたデッキに雪を置く。外縁（z 2.75）へ向けて増え、ノイズと吹きだまりの値でくっきりした縁（smoothstepの幅0.08）を持つ帯にする。`locally damp ash` を対象材質に加えた。

## 不採用

- 開けたデッキ全体（z>0.9）に薄く、外縁へ厚くした案（`rejected-first-try.jpg`、右）：雪のない斑が板の茶色い染みに見えた。

## 確認

`compare.jpg`（左が変更前・右が変更後、外気浴の冬の昼）。雪原の起伏が灰色の陰影で読め、デッキの外縁に板の目地が透ける雪の帯ができて、庭との境の直線がなくなった。夏など冬以外の画像は露出・雪とも変わらない。単体テスト（`lighting.test.ts`：冬の昼だけ絞る、`winterSnow.test.ts`：デッキの板が対象）。

## 範囲

デッキの雪はデッキの範囲を座標で決める近似で、足跡・雪かきの跡はない。パーゴラの格子の上の雪、雪の厚み、夕夜の雪原の見え方は変えていない。サウナ・水風呂の視点の冬は撮っていない。冬の雪のシェーダーは季節によらずデッキの板の材質にも入るため、夏の費用も測った（進捗記録）。
