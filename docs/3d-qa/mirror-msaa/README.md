# 水面の鏡像のMSAAを2倍に（2026-10-04、採用）

[GPUメモリ](../gpu-memory/README.md)の残件「残りの大きいもの」のうち、水面の鏡像（`planarReflection.ts`）の4倍MSAAの半精度ターゲット。描画バッファの0.5倍（標準）・1倍（高精細）の大きさで確保され、高精細・1280×800・DPR1で色だけ31MiBあった。

## 候補と判断

- **MSAAなし：不採用。** 鏡像に写る林のカードは `alphaToCoverage`（`leafCluster.ts`）で縁を標本の被覆として描くため、MSAAがないと硬い切り抜きになり、水面に映る葉の縁が段々になる（[拡大比較](crops.png)の右列。ローカルのみ）。差は葉の縁と柱・窓枠の輪郭に集中する。
- **2倍MSAA：採用。** 葉の柔らかい縁が残り、4倍との違いは拡大して少し粗い程度（同、中央列。左列が4倍）。

## 画像の差

`e2e/stage-compare.visual.ts` の水風呂12視点（4方向×昼夕夜）を `CAPTURE_PNG=1 CAPTURE_QUERY='&resolution=fixed'` で、標準・高精細ごとに4倍（HEAD `c005015` のworktree）と候補を交互に2回ずつ撮った。同じ版の2回は全画素一致。4倍に対するCIELAB ΔE76：

| | 平均 | ΔE>2の画素（最大） |
| --- | ---: | ---: |
| 標準・MSAAなし | 0.022〜0.109 | 1.14% |
| 標準・2倍 | 0.013〜0.054 | 0.55% |
| 高精細・MSAAなし | 0.012〜0.069 | 0.71% |
| 高精細・2倍 | 0.006〜0.030 | 0.33% |

最大の差は見下ろし（見出し1）の昼で、水面の占める割合が大きい視点。

## メモリ

`gpu-memory.e2e.ts`（1280×800・DPR1）の合計MiB：

| 画質 | 4倍 | 2倍 |
| --- | ---: | ---: |
| 軽量 | 129.7 | 129.7（鏡像なし） |
| 標準 | 195.0〜195.3 | 189.1〜189.4（−3%） |
| 高精細 | 344.2〜345.6 | 320.8〜322.1（−7%） |

減る量は画素数に比例するので、高精細のDPR 2の画面では約94MiB。周回・再生成をまたいだ一致の検査はそのまま通った。

## 範囲外

- GPU時間：鏡像はカメラ・解像度・照明が変わったフレームだけ描き直すので、静止中の費用は変わらない。見回し中の差は測っていない（鏡像パスは約55万三角形で頂点の費用が大きく、標本数による差は小さいと考えられるが未確認）。
- 見回し中・波で動く鏡像の見え方（静止画の比較のみ）、実機・他ブラウザ。
