# 3D庭の紅葉（2026-10-11）

表示設定に夏／秋（紅葉）を追加。未選択時は夏で、選択は `sui-season` に保存する。2Dの画像には反映しない。

`season.ts` が本体と庭の名前付き広葉樹・モミジ材質の色を変更する。赤・橙・黄褐色を材質ごとに割り当て、常緑樹・苔・シダ・樹皮は維持する。既存のcolor uniformを更新し、モデル再取得・canvas再生成・新しいテクスチャやシェーダーバリアントは不要。夏へ戻す際には保存した元色を正確に復元する。庭の遅着、準備中の選択変更は次の描画に最新の選択を反映する。

季節を鏡像キャッシュの状態に含め、材質色の変更時にはTAA履歴をリセットする。既存のベイク済み照度・反射プローブは再生成していないため、紅葉の間接光と軽量画質等のプローブ反射は夏のデータに基づく。落葉・積雪・花は含まない。
