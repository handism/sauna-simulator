# 高画質の水平8方向×上下3位置の静止画比較

既存の上下限見回し動画に続き、3ステージ×昼夕夜×8方向×上下3位置の216視点を、通常→分割→分割→通常のABBAで比較する。製品コード・配信物は変更しない。

```sh
SURROUND_QUALITY=high bun run test:browser:visual e2e/warmup-surround.visual.ts --reporter=json > /private/tmp/sauna-surround-high.json
python3 scripts/summarize_warmup_surround.py /private/tmp/sauna-surround-high.json docs/3d-qa/warmup-surround-high/summary.json --quality high
```

Google Chrome・1200×800・DPR1・高画質・固定解像度・full・動作抑制あり。高画質は入室前に保存する。庭ready後、各視点で70 rAF待ち、DOM演出を除いてcanvasを撮影する。水平は矢印10回ずつの0.8rad間隔（正確な45度ではない）、上下は製品制限±0.85radと中間約−0.01rad。サウナ入口から同一canvasで3ステージを巡る。連続した全角度の網羅ではない。

集計はABBA順・成功4件・再試行／skip／flakyなし・入力ハッシュ・画像ハッシュ／寸法・全216視点の順・画質・庭ready・分割完了／未描画0を照合する。通常／分割の2組と同方式再撮影差を分ける。画像と一覧はローカルのみ、集計JSONを追跡する。

静止画の確認であり、実時間自動照明・知覚的な連続映像・実Safari・Windows・モバイル・非HDR実機・GPU総メモリ・描画性能・音の実聴を検証しない。既定2D・明示3D・split試験オプションを維持する。
