# 遠い森の帯の高さとほつれた輪郭（2026-10-13）

## 課題

`../far-forest/`（10/12）の遠い森の帯は、上端がy=6〜13mで、デッキから見ると山並みの稜線（半径72m・高さ7〜11m）より高く、帯が空との境になっていた。照明を受けない一様な灰緑の滑らかな丸と円錐が、全周撮影（`../survey-20261013/`）の水風呂・外気浴・サウナのどの視点でも岩山の峰に見えた。54m先の樹冠は画面で約100画素あり、本物の木なら輪郭に葉の房の凹凸が見える大きさだった。

## 変更（`farForest.ts`）

- 上端をy=5〜9mに下げた（`stand` 7±1.8、各樹冠±0.8）。山並みが空との境になり、帯はその足元の暗い森になる。
- 常緑樹を細く低くした（半径1.3〜2.1m→1.1〜1.7m、高さは半径の2倍のまま）。
- 輪郭のほつれ：頂点属性 `gardenEdge`（その位置の輪郭の高さ。樹冠に覆われた下草の上端は無効）を持たせ、断片段で0.45m・0.2m周期の値ノイズから、輪郭から最大1.2mまで `discard` する。細かい方は画素より細かくなると平均へフェード。周期的な正弦ではないので、のこぎり状にならない。
- `discard` で抜いた所に深度プリパスの深度が残ると、空が描かれず黒い縁になった。材質に常に通るアルファテスト（0.01、アルファは1）を付けて `takesPrepassDepth` の対象から外す。

## 不採用

- 高さを変えずにほつれだけ足した案（`rejected-first-try.png`、上が変更前）：峰の形はそのままで、抜いた縁が黒くなった。

## 確認

- `compare-zoom.png`：水風呂の昼の右側（上が変更前）。峰が消え、山並みの手前に輪郭のほつれた森の帯が並ぶ。
- `stages-seasons.jpg`：サウナの昼、外気浴の夏・秋・冬・夕暮れ（左が変更前）。サウナからの奇岩のような峰が穏やかな丘になった。
- 単体テスト（`farForest.test.ts`：上端9.5m未満、`gardenEdge` が頂点の高さ以上、アルファテスト）。

## 範囲

帯が低くなったので、林の樹冠の間から空が見える所は10/12の変更前に近づいた（帯は林の足元を埋める）。帯の奥行き・照明・プローブ・鏡像の扱いは従来どおり。ほつれは `discard` の硬い縁で、見回し中のちらつきは測っていない。
