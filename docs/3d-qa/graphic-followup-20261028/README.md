# 奥の森の帯の境目・水面の灯りの三角形・湯気の前方散乱（2026-10-28）

利用者の依頼「3〜5の対応お願い」。進捗記録の未完了事項から挙げた3項目への対応。

1. 冬の奥の森で、常緑樹の間に帯の境目が残る（[forest-impostors](../forest-impostors/README.md)）
2. 水の反射像の形：夕夜の水底のクリーム色の三角形が、縁石の鏡像で鋭く切れたまま（[graphic-review-20261028](../graphic-review-20261028/README.md)）
3. ロウリュの湯気に光の筋がない（[steam-haze](../steam-haze/README.md)）

## 原因と変更

| 項目 | 原因 | 変更 |
| --- | --- | --- |
| 冬の奥の森の暗い四角 | 54mの帯は1,440区間ごとに、上にある樹冠の色と枯れ木の扱い（`gardenBroadleaf`）を区間全体で受け取っていた。冬は、霞へ寄せた淡い枯れ木と暗い常緑樹が隣り合う所で、帯の上から下まで縦の直線の段になり、常緑樹の間の暗いブロックに見えた | `farForest.ts` の `BAND_BLEND`。輪郭では上の樹冠の色とし、輪郭から2.5m下、および上の樹冠が替わる区間の境から1.5m以内では、周りの樹冠の平均（方位について幅2.5mのガウス重み）へ寄せる。枯れ木の扱いも同じ重みの小数にする。根元は常に平均 |
| 水底の三角形 | 鏡像の寝椅子灯・水底の部分反射の灯り・床のハイライトをそれぞれ0にして撮ると、鏡像の寝椅子灯を0にしたときだけ消えた。0.25倍に弱めた後も、水面の鏡像に写る寝椅子灯が縁石の像で鋭く切られ、止まった波でのこぎり状の縁になっていた | `waterEffects.ts` の `MIRROR_RIPPLE`（元にない補正）。鏡像を読む距離（縁石まで3cm〜縁石の先0.6m）が長いほど、鏡像を縦に13点で平均する。範囲は鏡像の高さの±1.5%、横は0.2倍で、ガウス重み。縁石の水際の像は鋭いまま |
| 湯気 | 一様な色へ寄せるだけで、平らな淡い膜だった | `steamHaze.ts` の `HAZE_FORWARD`。日光の筋は以前の検討どおり採らない（Cyclesのガラスは直接光を通さず、室内に日なたがない）。代わりに、湯気の水滴の前方散乱として扱う。湯気の割合の半分を、その画素の周りの景色を画面の高さの4.5%の円で24点（固定の螺旋、外ほど軽い）平均した色へ寄せ、残りの半分は従来の色とする。景色へ戻す分を補うため、減衰を1.6倍にする（床0.024〜天井下0.176/m） |

## 試して変えたもの

- 帯：最初は輪郭から下だけを平均へ寄せた。常緑樹の左の暗いブロックは消えたが、輪郭近くに短い縦の段が残った。そのため、樹冠が替わる境の左右1.5mも平均へ寄せた。
- 水面：最初は±3%・9点にしたが、点の間隔が広すぎて像が段々に重なり（二重写し）、昼の木立の映り込みもぼけすぎた。
- 湯気：最初は前方散乱の割合0.55で減衰を変えなかった。昼は湯気がほとんど見えなくなった（景色へ戻る分だけ霞が減った）。

## 確認

Chrome 156.0.8078.48、1280×800・標準DPR1・固定解像度・動作抑制。

- 静止画：`e2e/graphic-followup.visual.ts` の28視点を、変更前（`5c0703c`）・途中・最終で撮って並べ、目視した（画像はローカルのみ）。
  - 冬の水風呂の右60キー：常緑樹の左右にあった縦の直線の暗い四角は、周りとなじむ暗がりになった。
  - 夜の水風呂の左：のこぎり状の縁のクリーム色の三角形は、縁の柔らかい光のにじみになった。夕方の正面の左の扇形も、縁の段が消えた。
  - 昼の水面：木立の映り込みが少し柔らかくなった程度。
  - 湯気：昼の霞の濃さは以前に近く、見上げると窓際の天井の縁に空の光がにじむ。夕夜は灰色のベールが減り、景色の明暗が残ったまま、灯り・ベンチ下の帯・照らされた壁が湯気に柔らかくにじむ。
- 切り分け：水底の三角形は、`MIRROR_VIEW`・`BOTTOM_LIGHT_VIEW`・`WET_HIGHLIGHT_VIEW` をそれぞれ0にした一時ビルドで撮った（製品には残していない）。
- 描画費用：変更前は `5c0703c` のdistを別の作業ツリーでビルドし、変更後→前→前→後→後→前で測った。
  - 湯気（`steam-haze.gpu.ts`、3回描画）：湯気のある間（濃さ約0.65）の描画間隔は変更前の1.006〜1.011倍、湯気のない静止は1.003〜1.009倍。表示間隔に量子化されるため、これより小さい差は分からない。
  - 既定視点（`frame-cost.gpu.ts`、`FRAME_COST_REPEAT=3`）：2組目・3組目の比は0.987〜0.994倍・0.998〜1.005倍（水風呂は1.002〜1.005倍）。最初の回（A1）だけ、変更が届かない外気浴まで全視点が一様に1.03〜1.06倍遅かったので、起動直後の揺れとして除いた。
- ブラウザ回帰（`bun run test:browser`）：80/80件が成功。
- 単体テスト：
  - 帯：同じ位置の頂点が、隣り合う区間で同じ色・同じ枯れ木の扱いになること。変更前のコードでは失敗する。
  - タップの重み：前方散乱・鏡像の平均とも、重みの合計が1・中心に偏りがない・範囲内であること。GLSLへ展開した読み出しの数も確かめる。

## 範囲

- 静止画の目視で、ABBAの画素比較ではない。見回し中・波の動きの中の見え方、高画質、実機は未確認。
- 鏡像の縦の平均は鏡像全体に掛かる（縁石の水際を除く）。Cyclesの鋭い映り込みとの差は広がる。
- 湯気の前方散乱は画面上のぼかしの近似で、深度を見ない。湯気の手前にある物の明るさもにじむ。体積の描画・影ではない。
- 帯の境目は、輪郭そのものの形の違い（常緑の尖りと枯れ木）としては残る。
