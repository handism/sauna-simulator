# 水中の照度の受光球を水越しと同じバウンス位置で測る（2026-09-27）

[水中の反射プローブからV9を除く](../water-floor-gloss/README.md)の残件「Cyclesでは、カメラが水面越しにタイルを見るとV9の寄与が発光だけの透過率よりさらに約1割減る。照度プローブの拡散球はカメラから直接見ているので、V9の照度を約1割多く持つ可能性がある」を切り分けた。原因は**ロシアンルーレットと間接光クランプの組み合わせ**で、焼き込みの受光球を殻で1バウンスずらして直した。

## 切り分け

測定値は [measurements.json](measurements.json)。元blend（SHA-256 `f1ee4ddd…`）、Blender 4.5.11 LTS、昼のシーン。水風呂を真上から見る正投影（280×330・256サンプル・BOX・デノイズなし）で、ライトグループをV9単独と全メッシュの発光（水中の疑似コースティクス）に分け、タイルの画素（水を隠した描画のPositionでタイル面0.202mから6mm以内、浴槽の内側）の輝度の平均を比べた。「水越し」は水をカメラに見せた描画、「直視」は水をカメラからだけ隠した描画。

| 条件 | V9 水越し/直視 | 発光 水越し/直視 | V9/発光 |
| --- | ---: | ---: | ---: |
| 元の設定（間接クランプ10・Filter Glossy 1.0・バウンス10/4/4/8） | 0.825 | 0.925 | **0.892** |
| 間接クランプなし | 0.918 | 0.925 | 0.992 |
| Filter Glossyなし | 0.793 | 0.925 | 0.858 |
| バウンス上限をすべて64 | 0.826 | 0.925 | 0.893 |
| 水の体積吸収なし | 0.833 | 0.937 | 0.889 |
| ライトツリーなし | 0.804 | 0.925 | 0.870 |
| クランプ・Filter Glossyともなし | 0.928 | 0.925 | 1.003 |
| ロシアンルーレットなし（`min_light_bounces` 64） | 0.941 | 0.925 | 1.018 |
| ロシアンルーレットなし・クランプなし | 0.922 | 0.925 | 0.997 |

- 発光の比0.925がカメラから水を通ってタイルまでの透過率。V9はそれよりさらに約11%減る（前回の見下ろしでの約1割と同じ）。
- クランプを外すか、ロシアンルーレットを止めると差が消える。どちらか片方だけでは偏らず、組み合わせで偏る。水越しではタイルがカメラから2バウンス目になり、生き残った経路の重みの増幅（1/確率）とクランプ（アルベド×放射輝度の和が10まで）の掛かり方が直視と変わる。V9は水面の屈折を経てしか届かない（シャドウレイは水面で遮られ、BSDFサンプリングで当たるだけ）ため、1標本の値が大きくクランプに掛かりやすい。
- クランプはV9自体を大きく削っている（直視でもクランプなしの0.55倍、ロシアンルーレットなしなら0.72倍）。ブラウザが合わせるべきなのは、元の設定で水越しに見たCyclesの値。

### 焼き込みで水越しの状態を再現する

- 水の上にカメラ専用の板を置くのは無効：板を通過した後の光線は透過レイになり、カメラからだけ隠した水が再び見えるため、どの板でも水越しの描画そのものになった（Transparent BSDFの板は透過レイにならず、直視と同じ）。
- 板を水の底面の下（空気層、z 0.212m）に置き、水はカメラから隠したままにすると、V9は直視の0.880倍（白・IOR 1のRefraction BSDF、発光は1.000倍）。カメラ専用・透過レイ専用の2枚でも0.879倍で、1バウンスずらせば十分。目標（水越し÷透過率）0.892との差は水越しの経路のスループットの分で、板の色を0.925の灰色にすると水越しの**0.996倍**（発光0.9998倍）になった。

## 方式

`bake_irradiance_probes.py` の水中グリッドの受光球（半径4mm、タイルのアルベド）を、カメラにだけ見える半径4.4mmの殻（Refraction BSDF・IOR 1・粗さ0・色0.925）で囲む。受光球は殻を通過した透過レイに見えるようにする（ほかの光線には見えないまま）。

- 殻がPosition/Normalパスを取るので、受光球の法線は正投影カメラの画素中心から解析的に求める。Positionは「最初に当たったのが殻（殻なしでは球）か」の判定だけに使う（手前に他の物体があれば無効、今回0件）。
- 照度は Combined ÷（0.925×アルベド）×π。殻の光線は曲がらず、重みは色そのもの。
- `--probe-test N --probe-grid water` は同じ点で殻なし／殻ありの上向き照度を並べて出す。殻なしの値は配信中のグリッドと float16 の丸め（0.1%）以内で一致し、新しい読み方（解析的な法線・Combined÷アルベド）が従来の DiffDir+DiffInd と同じ値を返すことを確かめた。
- 焼き込みは昼夕で約6分（1点約2秒、無効0）。以前の記録の約2.3時間より大幅に速かった。同じ入力で2回焼くと平均は一致し、夕の一部の係数がGPUの非決定性でわずかに異なる。

殻ありの上向き照度は殻なしの0.80〜0.96倍（空気層の下の層で0.86〜0.96、水中0.66mの上の層で0.80〜0.87）。水中グリッド全体の上向き照度の平均は昼 (1.48, 1.38, 1.07)→**(1.24, 1.16, 0.91)**、夕は (0.136, 0.162, 0.191) でほぼ不変（夕の寝椅子灯は弱く、クランプにほとんど掛からない）。

## 残る差

- 昼の水越しのタイルが暗い（見下ろし全体 −1.6 L*）。照度は合ったので、残りは**水越しのタイルの光沢**（V9のハイライト、ブラウザは水中に光源を直接当てない `DRY_ONLY`）とアルベド（+6%、目地を含む）。光沢を足すとアルベドの過大が残るので、両方をそろえて扱う必要がある。
- 殻の色0.925は真下から見た透過率。斜めに見る視点では透過率が下がる（前回の見下ろしで0.877）が、クランプへの効果は二次（白い殻との差で1.3%）なので一律にした。
- パノラマで焼く水上のグリッド・反射プローブも、カメラから1バウンス早く面を見る点は同じ。ファイアフライ状の寄与（水越しのV9など）が少ない所では効かないと見て扱っていない。
