# 見出しの暗幕・夕暮れの遠景・接地の陰（2026-10-12）

## 課題

1. 晴れの水風呂の空が曇って暗く見えた。3Dの空は晴れていた（UIを除いた撮影で確認）。原因は3D表示中だけ画面上部270pxの全幅に敷いていた暗幕（`.scene-container::before`、上端の不透明度70%）で、空の上半分を0.44〜0.76倍に暗くしていた。
2. 夕暮れの遠景の山が、手前の暗い草地より明るい灰緑のまま浮いていた。山は照明を受けない色（`MeshBasicMaterial`）で、夕暮れは露出が+0.4段開くのに、色は昼と夜の中間（`timeOfDay / 2`）にしか下がっていなかった。
3. 庭に足した岩・低木・灯籠（`gardenDetails.ts`）の足元に陰がなく、地面から浮いて見えた。形は地面に少し埋まっており、ベイクした遮蔽がないことが原因。

## 変更

1. `index.css`：暗幕を見出し（`.stage-heading::before`）の周りだけの楕円のぼかし（幅 min(720px, 100%)、中心 `--scrim-mid` から縁で透明）にした。見出しと一緒に動くので、横長の低い画面で見出しを左に置く配置にも付いてくる。UI非表示では見出しと一緒に消える（不要になった `.ui-hidden .scene-container::before` を削除）。右上の「景色・音・表示」の文字は暗幕に頼っていたため、影を `--text-shadow-heading` にした。
   - 最初の案（`radial-gradient(ellipse min(320px, 50%) 50% …)`）はChromeが無効な値として捨て、背景がなかった。楕円の大きさの `min()` を擬似要素の幅へ移した。中心に `--scrim-top` を置く案は黒い円盤に見えたため不採用。
2. `gardenDetails.ts`：山の色を昼→夕（3層 `0x2b3340`／`0x384050`／`0x474e60`）→夜で補間し、夕の霞の色を `0x8d8f9f`→`0x5c5f72` にした。夜は変わらない。
3. `gardenDetails.ts`：岩（半径は大きさの1.5倍、中心の不透明度0.6）・低木の株（株の幅の1.25倍、0.5）・灯籠（0.38m、0.6）の足元に、地形へレイキャストした16角形の黒い円盤を置き、頂点アルファで縁を0にした。全体で1メッシュ（`Garden contact shade`）、深度を書かない半透明、影の投射・受けなし、ポリゴンオフセットで地形の手前に描く。乱数の列は変えないので、庭の配置は変わらない。
   - 飛び石・縁石（元GLBの `Foundation_floating_edge`、名前どおりの浮いた見せ方）と元GLBの大きな庭石は対象外。

- `garden-details.e2e.ts`（標準画質・1280×800・動作抑制）の撮影を `../crown-fill/` と比べた。夕暮れの山は暗い青灰色の影絵になり、夜は同じ。せせらぎの縁石・低木の株元・灯籠の足元が暗くなり、冬も雪の上に陰が出る。
- 一時的な撮影で、1280×800・390×844・1280×600（見出しが左の配置）の3ステージを確認した。空は晴れて見え、見出しは読める。
