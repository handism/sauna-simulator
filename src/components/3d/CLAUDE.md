# 3D描画（src/components/3d）

- `SaunaScene` のDOM `data-*` 属性に初回ロード時間、描画数、初期180フレームの間隔を記録する。Reactの毎フレーム更新は行わず、DOM属性も値が変わったときだけ書き込む。
- GLB読み込み後の材質拡張（葉・ノイズ色・画像ランプ・林のカード）と影・水形状の非表示は `modelMaterials.ts` の `prepareModel()`、解放は `disposeTree()`。
- 水は元GLBの閉じた水形状を非表示にし、`waterEffects.ts` の境界付き水面・波紋・注水に置き換える。元の水は透明（透過1・IOR 1.333）なので、水面はタイルに色を足さず、Fresnel反射（F0=0.02）で映り込みだけを重ねる：平面反射（下記 `planarReflection.ts`）があればその鏡像、なければ反射プローブ（下記 `reflection.ts`、粗さ0.018）。水面の高さはシーン定義の0.765m（元の水形状の上面の平均）。法線は元の水形状の波を当てはめた式（注水口中心の同心円波＋平面波、R² 0.986、`WAVES`）の解析的な勾配で、毛管重力波の位相速度で外へ進める（動きを減らす設定では元の形のまま）。元材質のバンプ（傾き約0.003）は省略。水面は影を投射しない（内壁まで暗くなるため）。水面下（`interiorLights.ts` の `WATER_BOX`、タイルと下の石板まで含むよう水形状より広い）には日光・スポット光を直接当てない（`lighting.ts` の `DRY_ONLY`）：元の日光は透過レイに不可視で影レイは水面で止まり、V9・夕暮れの暖色灯は屈折経路だけで届き、その光は水中プローブに入っている。動きを減らす設定では波紋・注水の時間更新を止める。最適化は未完了。
- 水越しの像は `refraction.ts`。水面を平面（シーン定義の水面の高さ）とみなし、`WATER_BOX` のxz内で水面より下の頂点を、カメラごとにスネルの法則（IOR 1.333、二分法16回）で解いた像（点の真上、見かけの深さ `b·cosθ1/(n·cosθ2)`）へ `project_vertex` の後で持ち上げる。照明・プローブ・影は真の位置のまま（影のパスは別の深度材質）。水中に0.3mより長い辺を持つメッシュは読み込み時に水面と0.1m格子の平面で分割する（共有辺を同じ点で切るので割れない、`sliceUnderwater`）。水中の三角形を持つ材質だけに `SUI_REFRACTION`（値は水面の高さ）を定義する。水越しの面の色には元の水の透過色と体積吸収（屈折経路長、頂点で計算して補間）を `opaque_fragment` の後で掛ける。屈折は平面のままで波による揺らぎはない。`data-refraction-materials`・`data-refraction-triangles` に数を記録する。
- 水の側面の全反射も `refraction.ts`（`addSideImages()`）。元の水形状（`WATER_VOLUME`、側面・底はフラット、外は空気）を平らな水面で屈折した視線は |d.y|≥0.66 なので底では全反射せず、側面では各軸1回まで全反射する。水中の三角形だけ（属性バッファを共有しインデックスだけ新規）を側面4面・角4つで鏡映した8つの複製を、鏡映した点の像の位置へ同じ頂点屈折で描く。照明・プローブ・影は真の位置のままで、視線方向だけ鏡映する（`SUI_SIDE_IMAGE`、1回の鏡映は巻き方向が逆なので `SUI_SIDE_FLIPPED` で面の向きと法線を戻す）。全水中フラグメントは `clipping_planes_fragment` の先頭で画素の視線を波の法線（`waterEffects.ts` の `WAVE_NORMAL`、時刻は水面と共有）で屈折させて箱を追い、全反射した側面の組と違う像・全反射した側面の裏の点を `discard` する（`keepsImage`／`sidePath`／`trueWeight` がTSの参照実装）。像の位置は平らな水面のまま。最初に当たる側面では必ず反射する経路とし、透過する視線（入射角41.4〜48.6°）はFresnel反射率Rで部分反射させる：その側面の裏5cm以内（`SIDE_WALL_LAYER`、内壁は6mm裏の1層だけ）の面を重み1−Rのアルファで像の上にブレンドし、それより奥は捨てる。2面目は全反射か透過の二値。複製はレイヤー2（水面の鏡像パスに写らない）・影なし・`renderOrder` 1（手前の縁石で深度により捨てる）。内壁は像の後に描く必要があるため、裏の層に角を持つ水中の三角形だけを属性共有の別メッシュ（`renderOrder` 2、ブレンドする材質の複製）へ移す。元メッシュごと後回しにすると床のタイルの下を深度で早期に捨てられず、GPU時間が水風呂で+25%前後になった。`material.clone()` は `onBeforeCompile`・`customProgramCacheKey` を引き継がないため、複製には両方を元に委ねる形で設定する（キーがないとコースティクスの有無など別材質のプログラムを取り違える）。`update(camera)` がカメラが水面下・水面が視野外・カメラがその側面の外側（屈折しても水平方向を保つので反射しない）の複製を隠す。`data-side-image-meshes`・`data-side-image-triangles`・`data-side-images-shown` に数を記録する。
- 水面の鏡像は `planarReflection.ts`。水面の高さで鏡映したカメラ（x反転で回転に戻す）から、近クリップ面を水面に置き換えた斜め投影（Lengyel法）で水面より上だけを半精度ターゲット（4倍MSAA、線形）へ描く。視錐台は水面の画面上の範囲＋余白0.08（NDC）に切り抜き、ターゲットの左下の同じ画素密度の部分に描く（`suiMirrorLimit` でサンプルを制限）。カメラ行列・解像度・呼び出し側の状態（照明の昼夕、画質）が同じフレームは描き直さない（映り込む注水の動きは視点が止まっている間は止まる）。蒸気はストーブ脇の室内にあり鏡像に写らないため、レイヤー1に置いて主カメラだけが描く（ロウリュ中に毎フレーム鏡像を描き直さない）。水面が視野外・カメラが水面以下・軽量画質・HDR出力なしの端末では描かず、水面は反射プローブを使う。軽量ではターゲットを解放する。鏡像のカメラだけがレイヤー3（`MIRROR_LAYER`）も描く。水面は鏡像を、反射方向に0.6m進んだ点の投影位置で参照し、波で像をずらす。`data-mirror-calls`・`data-mirror-triangles`（最後に描いた鏡像パスの値）・`data-mirror-size` を記録する。
- 光沢にだけ見える面光源は `glossyLights.ts`。元blendでカメラに不可視・光沢に可視の面光源13灯（`V7 water reflection soft strip`・V9・夕暮れの暖色灯・V8・デッキ端など、すべてspread 180°）を元の形・位置・向きの発光面（円盤は面積を保つ32角形、表は光が出る側）として1メッシュにまとめ、放射輝度 `P·color/(π·A)` の昼・ブルーアワーの値を頂点に持たせて照明の補間量で混ぜる。レイヤー3（`MIRROR_LAYER`）に置き、水面の鏡像にだけ写す（主カメラ・影のパスには写らない）。水面はブラウザの光源を受けず、鏡像があるときは反射プローブも使わないため、これがないとV7の帯・V9・寝椅子灯の形が水面に出ない。鏡像がない端末では従来どおりプローブだけ。
- 水の底面の部分反射は `waterBottom.ts`。元の水形状の底面（y=0.215）はタイルより1.3cm上で間は空気のため、床はその水→空気の境界越しに見える。床（水の箱のxz＋裏の内壁の足元5cm、底面より下）を描く材質に `SUI_WATER_BOTTOM` を定義し、`opaque_fragment` の水越しの色（`refraction.ts` の `VIEW_TINT`）の前で `(1−R)·透過色·床 + R·上へ反射した放射輝度` にする。視線は `refraction.ts` が屈折させた `suiWetView`（鏡映像では鏡映した方向）。反射した視線は側面で反射し（全反射／Fresnel、残りは壁へ抜ける）、水面で波の法線について屈折して出て、反射プローブ（粗さ0.018）と、透過レイに見える光沢専用の面光源（V9・`V10 lounge dusk fill`、元の形と交差、縁石の上面1.035mより低く側面を越える光線は届かない）を見る。`V7 water reflection soft strip` は元blendで透過レイに不可視なので含めず、プローブが含むそのぼけた分はプール中央上から見たL2係数（`sourceSH`）を引く。水面で下へ反射する分は床の色で代用。タイル自身の光沢による光源のぼけた像は省略（反射プローブだけ）。`bottomExit`／`upwardExit`／`clearsRim`／`lightCoverage` がTSの参照実装。`data-water-bottom-materials` に数を記録する。
- 水中の疑似コースティクスは `caustics.ts`。元の `V10 | submerged light` 2材質の発光強度（Voronoiの辺距離×ノイズ×水面下の箱）を、BlenderのハッシュとVoronoi・ノイズの色のGLSL移植で画素ごとに評価し `emissivemap_fragment` の後に足す（書き出しは接続された発光強度を落とす）。Perlin fBmは `noiseColor.ts` の `FBM_GLSL` を共用し、既に定義済みなら重ねない。移植は `caustics.e2e.ts` がBlender基準値（`scripts/blender_caustic_reference.py` → `e2e/fixtures/blender-caustic.json`）と照合する。`data-caustic-materials` に数を記録する。
- 昼／夕暮れ／自動は `lighting.ts` で管理。元Cyclesに合わせて霧はなく、空は元画像の表示色の単色（昼 `#4f616c`・夕暮れ `#283d54`）、カメラの描画距離は250m（地面は原点から100m）。`sui-lighting-mode` に保存し、3Dモデルを再ロードせずに反映する。自動は各周回でサウナ=昼、水風呂=中間、外気浴=夕暮れ。ステージ変更時は暗転中に適用し、手動変更は補間する。動きを減らす設定では即時適用。
- 描画は `hdrOutput.ts` で4倍MSAAの半精度レンダーターゲットへ線形のまま描き、全画面パスで一度だけトーンマッピングする（Cyclesと同じく、ガラス・水・蒸気の合成を線形で行う。three 0.186の `outputBufferType` は `renderer.dispose()` で解放されないため自前）。`EXT_color_buffer_float` がない端末は従来どおり材質ごとにトーンマッピングする。描画数・三角形数の計測値は全画面パスを含まない。空の背景色はトーンマッピングされるため、`agx.ts` の `agxInverse()` で元の表示色に戻る線形値にする。
- トーンマッピングは元blendと同じAgX（look None）。three内蔵の `AgXToneMapping` はBlender 4.xのAgX（E-Gamut・57³ LUT）と別の曲線で、同じ線形入力を平均約4 L*明るく表示するため、`agx.ts` がAgX関数を差し替える（行列・対数・32点の曲線・行列・2.4乗・行列。定数は `scripts/fit_blender_agx.py` でBlenderのOCIOに当てはめ、表示値の誤差平均0.001）。露出はBlenderの昼0.15・ブルーアワー0.55段を `2^EV` で使う。日光（向きは両シーン共通、強さは昼3.2・夕暮れ0.045の青。元の日光は光沢に不可視なので、`lights_fragment_begin` の平行光源ループで鏡面反射を戻して拡散だけにする）、寝椅子上のスポット光（元の `V9 lounge patch of sunlight`、950W円盤→軸上 `950/π` cd、夕暮れは0）、ブルーアワーの暖色灯5灯（`V10 lounge dusk fill` 42W・`V10 path grazing light 1/4/7` 各8W・`V10 specimen uplight` 35W、軸上 `P/π` cd・5灯すべてに影あり・昼は0）、サウナ室の面光源6灯（下記）は元blendの値。スポット光はすべて元の円盤光源の代わりで、90度の円錐とpenumbra 1のまま `lights_pars_begin` の減衰を smoothstep から線形へ差し替え、正確な余弦配光にする（`SPOT_COSINE`）。半球光はない。空・ブラウザで描かない面光源（Sky softbox・Sunlit courtyard・行灯など）・全光源の間接光は、元blendから焼き込んだ照度プローブ（下記 `irradiance.ts`）で与え、合わせ込みの係数はない。照明の確認はCycles同視点との比較（`scripts/cycles_tone_stats.py`、CIELABの明暗分布と彩度）で行う。夕暮れは06に加え、`scripts/blender_bluehour_reference.py` のブルーアワー参照画像（02〜05・07）とも比較する。照明を変えたら全周撮影の後にこのスクリプトで比較し、進捗記録へ値を残す。ブラウザで再現しないノイズ→ランプの基本色（漆喰・リネン・樹皮・砂利）は書き出し時にノイズ平均0.5のランプ色の単色にする（`procedural_flat_color`）。
- サウナ室の照明は `interiorLights.ts`。元の6灯（ベンチ下2・天井・壁・蒸気の逆光・背もたれ）を `RectAreaLight`（円盤は等面積の正方形、壁の灯は室内に出る帯だけ）で放射輝度 `P/(π·A)` にし、影がない分を光源ごとの見え率（02の視点でCycles直接光÷Web直接光）で掛ける。元の光源は光沢に映らないため拡散成分だけを、受光面の地平線で切り取った厳密な形状係数で計算する（LTCテーブルは読み込まない）。`lights_fragment_begin` を差し替え、室内の箱（ガラス面まで）の外では6灯を評価しない。同じ箱の判定で照度プローブの室内グリッドを選ぶ。Three.js更新時は `interiorLights.test.ts`・`agx.test.ts` と全周撮影で確認する。
- 間接光は `irradiance.ts`。`scripts/bake_irradiance_probes.py` が元blendの昼・ブルーアワーをCyclesで焼き込んだL2球面調和（SH）の照度プローブ（`public/models/irradiance.json`・`irradiance.bin`、float16）を、室内（0.5m・室内の箱の中の画素だけ）・中庭（1m）・外周（3m、中庭グリッドの端1.5mで混合）・水中（約0.5m・`WATER_BOX` の画素だけ）の4グリッドのRGBA半精度3Dテクスチャ（three の LightProbeGrid と同じ詰め方・余白付き）にし、`lights_pars_begin`・`lights_fragment_begin` に画素ごとの評価を足す。three の LightProbeGrid は物体ごとに1グリッドを選ぶが、モデルは材質ごとに結合されて室内と中庭にまたがるため使わない。昼夕は `suiIrradianceEvening` で係数を混ぜる。プローブには空・ブラウザで描かない面光源の直接光・全光源の間接光が入り、ブラウザで描く光源（日光・V9・室内6灯・夕暮れの暖色灯5灯）の直接光は入らない。GLBの `MeshStandardMaterial` に `SUI_IRRADIANCE` を定義し、uniformは全材質で共有する。照度と反射（下記）はグリッドごとに1枚のテクスチャ（照度の昼夕→反射の昼夕の28サブボリューム、`createProbeTextures`）にまとめる：フラグメントシェーダーのテクスチャユニットは16で、影マップ7枚と材質の画像が大半を使うため、別テクスチャを増やすと画像付きの材質がコンパイルに失敗して消える。読み込みはGLBと並行し、形式の不一致は3Dの読み込み失敗として扱う。Three.js更新時は `irradiance.test.ts` と全周撮影で確認する。`data-irradiance-probes`・`data-irradiance-materials` に数を記録する。
- 環境の鏡面反射は `reflection.ts`。`bake_irradiance_probes.py --reflection` が照度プローブと同じグリッドに、光沢レイに見えるもの（空・面・光沢に可視でブラウザがハイライトを描かない光源。日光・Sky softbox・Sunlit courtyard・行灯・室内6灯は元から光沢に不可視、V9・夕暮れの暖色灯5灯はブラウザが描く）の放射輝度をL2 SHで焼き込む（`public/models/reflection.json`・`reflection.bin`、グリッドは照度と一致必須で、照度と同じテクスチャの後半を使う）。粗さごとに帯域1・2をGGXと同じ幅のvMF（Λl≈exp(−l(l+1)α²/4)）で減衰し、threeの支配方向で評価して `lights_fragment_begin` の `radiance` に足す（Fresnelはthreeのsplit-sum）。照度プローブの材質（`SUI_IRRADIANCE`）に `SUI_REFLECTION` を定義する。L2なので鏡像は出ず、ガラス・水はぼけた映り込みになる。`data-reflection-materials` に数を記録する。
- ガラスは `glass.ts`。書き出しのガラス（12%不透明の拡散面）を元材質の厚さ18mmの透過ガラス（IOR 1.45・色で1回だけ着色）として描き直す：元のメッシュが透過率 `T=(1−F)²t/(1−F²t)` を乗算合成で掛け（影は従来どおり投射）、同じ形状の子メッシュがその直後（同じ深度・後のid）に反射率 `R=F+F·T` × 反射プローブを加算する。Fは誘電体の厳密なFresnel。Cyclesで元材質の板を測った値（垂直T=0.812/0.896/0.887・R=0.062、75°でT=0.525・R=0.373）に0.01以内で一致する（`glass.test.ts`）。プローブはカメラ側で参照し、室内から見るときは室内グリッドを使う。屈折のずれ・粗さ0.055は省略。`data-glass-meshes` に数を記録する。
- 3D画質は `quality.ts` の軽量／標準／高精細。`sui-quality` に保存し既定は標準。DPR上限は1／1.5／2、日光・V9スポット光・夕暮れの暖色灯5灯の影は無効／1024／2048px。夕暮れの暖色灯5灯は全画素のシェーダーに加わるため、軽量では非表示にする（ライト数の変更はシェーダー再コンパイルを伴うので、画質変更時だけ切り替える）。水面の鏡像の解像度は描画バッファの0／0.5／1倍。モデルを保持したまま反映し、画質変更時は180フレームの計測をリセットする。
- 影を描くのは日光・V9スポット光・`V10 lounge dusk fill`・`V10 specimen uplight`・通路の暖色灯3灯（室内の面光源は影なし）。Cyclesのガラスは直接光を通さないため、ガラスは影を投射する（受けない）。両面材質の裏面は反転した法線で陰影付けされるため、`softShadows.ts` が `shadowmap_vertex` で影の法線オフセット（normalBias）を頂点ごとに視点側へ反転する（下向きの遠景地形が自分の影に入っていた）。水・蒸気は影を投射しない。影を描く7灯は動かないため、影解像度の変更時だけシャドウマップを更新する（昼夕の補間中も再描画しない）。軽量切り替え・シーン解放時に7灯の影のGPUリソースを解放する。これはベイクではない。
- 影のぼけは `softShadows.ts` のPCSS。three 0.186の `shadowmap_pars_fragment` のBasicShadowMap分岐を差し替え（レンダラーはBasicShadowMap）、遮蔽物との深度差×係数kで半影幅を決める。kは `shadow.radius` で渡し、日光は角直径0.085rad（`directionalPenumbra`）、V9は直径1.25m、夕暮れの寝椅子灯は直径2m・モミジ灯は直径0.6m・通路灯3灯は直径0.28m（`spotPenumbra`）から計算する。日光の影の範囲は±30m（範囲外は影がつかない）。Three.js更新時は `softShadows.test.ts` と全周撮影で確認する。
- `SaunaScene` は描画数・三角形数・テクスチャ数・ジオメトリ数もDOM属性へ記録。描画数は最新フレームの値なので、照明補間中の影パスを含む値と、安定後の値を区別する。
- 蒸気の座標更新は `steam.ts`。動きを減らす設定では全軸を固定し、濃淡と6秒の表示時間は維持する。`scene-viewport.e2e.ts` は390×844の操作・キーボード見回し・844×390とのリサイズ・同一canvas保持を検証。Chromeの画面サイズとメディア設定のエミュレーションであり、モバイル実機の検証ではない。
- 見回しは `lookControls.ts`。終了は操作開始時のpointerIdに一致する場合だけ処理し、別の指の終了・キャンセル・キャプチャ喪失で中断しない。`scene-touch.e2e.ts` はChromeのCDPタッチ入力でスワイプ、2本目の指を離した後の操作継続、キャンセル後の再操作、タップでのUI復帰・ステージ一巡・2D復帰を検証する。モバイル実機やSafariの検証ではない。
- 林のカードは `leafCluster.ts`。20枚の菱形の葉のマスクを決定的に生成し（カードの半分を覆う）、アルファテストの被覆率を保つよう各ミップを自前で補正、`alphaToCoverage` で描く。マスクは枚数ごとに1枚を共有し、材質とともに解放する。`data-leaf-cluster-materials` に対象材質数を記録する。
- 葉は `foliage.ts`。名前が leaf／foliage／fern の `MeshStandardMaterial`（落ち葉 `leaves`・苔・樹皮は対象外）を両面にするだけで、裏面へ光を透過させない。元の葉はTranslucentもTransmissionもなくSubsurface Weight 0〜0.08で、Cyclesで背面から照らすと正面の0.1%未満しか返さない（以前の0.6倍の透過は元データに根拠がなく、林・草を明るく鮮やかにしていた）。視点側の面は照度プローブが照らす。`data-foliage-materials` に対象材質数を記録する。
- 地面の苔・シダの色は `noiseColor.ts`。`export_web_glb.py` が元材質のワールド／オブジェクト座標fBmノイズ→線形カラーランプの設定を材質 `extras.suiNoiseColor` に記録し、BlenderのPerlin（Jenkinsハッシュ）とfBmのGLSL移植で画素ごとに評価する。画素より細かいオクターブは平均へフェード。バンプは省略。Three.jsの `common`・`project_vertex`・`color_fragment` チャンクに依存。移植は `noise-color.e2e.ts` がBlender基準値（`scripts/blender_noise_reference.py` → `e2e/fixtures/blender-noise.json`）と比較する。名前による苔・シダの単色上書きはBase Colorが接続された材質だけ。
- 石・布・木材の色は `imageRamp.ts`。`export_web_glb.py` の `base_color_image_ramp()` が「画像→RGBのBW化→線形ランプ × Object Info Randomのランプ（→一定色へ混合）」を材質 `extras.suiImageRamp` に記録し、結合前のオブジェクトごとの乱数を色属性 `SuiObjectRandom`→`COLOR_0` で渡す（名前seedの一様乱数でCyclesの値ではない）。濡れ跡のノイズは省略。輝度係数はBlenderのOCIO設定の `luma`。Three.jsの `common`・`map_fragment`・`color_fragment` チャンクに依存。`data-image-ramp-materials` に対象材質数を記録する。書き出しはUVの最下位ビットが実行ごとに揺らぐため、GLBのハッシュは再実行で変わる。
- `SaunaScene` 内で `meshoptimizer/decoder` をGLTFLoaderへ渡す。WASMは3Dの遅延JS内に含まれ、CDNや別のデコーダーURLへ依存しない。圧縮ストリームの破損時も2Dを継続し、手動再試行できることを `scene-lifecycle.e2e.ts` で検証する。圧縮は転送量を減らすもので、描画三角形数やGPUメモリは減らさない。
